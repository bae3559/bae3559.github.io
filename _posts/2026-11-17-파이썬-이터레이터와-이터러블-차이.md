# 파이썬 이터러블(Iterable)과 이터레이터(Iterator): 헷갈리지 마세요!

안녕하세요, 파이썬 개발 블로그 독자 여러분! 오늘은 파이썬을 사용하면서 너무나도 익숙하게 사용하지만, 그 이면에 숨겨진 중요한 개념인 '이터러블(Iterable)'과 '이터레이터(Iterator)'에 대해 이야기해보려고 합니다. `for` 루프를 사용해 본 사람이라면 누구나 이 개념들을 알게 모르게 사용해왔을 텐데요, 이 둘의 정확한 차이점을 알고 있다면 파이썬 코드를 더 효율적이고 강력하게 만들 수 있습니다.

특히 데이터 처리나 대용량 파일 작업 등에서 메모리 효율성을 극대화할 수 있는 핵심 아이디어이기도 하니, 오늘 저와 함께 친절하고 명확하게 파헤쳐 봅시다!

## 1. 이터러블(Iterable)이란 무엇일까요?

가장 먼저 '이터러블'부터 알아보겠습니다. 이름 그대로 "반복(iterate)할 수 있는" 객체를 의미합니다. 쉽게 말해, `for` 루프를 돌릴 수 있는 모든 객체들이 이터러블입니다.

우리가 파이썬에서 흔히 사용하는 리스트(List), 튜플(Tuple), 문자열(String), 딕셔너리(Dictionary), 세트(Set) 등이 모두 이터러블에 해당합니다.

**핵심 특징:**
*   내부에 `__iter__()`라는 특별한 메서드를 가지고 있습니다.
*   `iter()` 내장 함수를 호출하면, 이터레이터(Iterator) 객체를 반환합니다.

**비유:** 이터러블은 마치 여러 권의 책이 담긴 '책장'과 같습니다. 책장 자체는 많은 책을 담고 있지만, 그 책들을 한 권씩 꺼내 읽기 위한 직접적인 도구는 아닙니다.

**코드 예제:**

```python
# 리스트는 이터러블입니다.
my_list = [1, 2, 3, 4, 5]
for item in my_list:
    print(f"리스트 요소: {item}")

print("-" * 20)

# 문자열도 이터러블입니다.
my_string = "Hello Python"
for char in my_string:
    print(f"문자열 문자: {char}")

print("-" * 20)

# 이터러블 객체는 __iter__ 메서드를 가지고 있습니다.
print(f"my_list가 __iter__ 메서드를 가지고 있는가? {hasattr(my_list, '__iter__')}")
print(f"my_string이 __iter__ 메서드를 가지고 있는가? {hasattr(my_string, '__iter__')}")
```

위 코드에서 `my_list`와 `my_string`은 모두 `for` 루프를 통해 요소를 하나씩 반복할 수 있었죠? 이것이 바로 이터러블의 역할입니다.

## 2. 이터레이터(Iterator)란 무엇일까요?

그렇다면 이터레이터는 무엇일까요? 이터레이터는 이터러블 객체의 요소를 "하나씩 차례대로 꺼내주는" 역할을 하는 객체입니다. 이터레이터는 자신이 어느 위치까지 반복했는지 '상태'를 기억하고 있으며, 다음 요소를 요청할 때마다 다음 값을 반환해줍니다.

**핵심 특징:**
*   내부에 `__next__()` 메서드와 `__iter__()` 메서드를 모두 가지고 있습니다.
*   `__next__()` 메서드가 호출될 때마다 다음 요소를 반환하고, 더 이상 요소가 없으면 `StopIteration` 예외를 발생시킵니다.
*   `__iter__()` 메서드는 자기 자신(self)을 반환합니다. (이터레이터도 이터러블이기 때문입니다.)

**비유:** 이터레이터는 책장에서 책을 한 권씩 꺼내주는 '사서' 또는 '집게'와 같습니다. 이 사서(이터레이터)는 "다음 책 주세요!"라고 요청하면 다음 책을 건네주고, 더 이상 책이 없으면 "더 이상 책이 없습니다!"라고 알려주는 역할을 합니다.

**코드 예제:**

```python
my_list = [10, 20, 30]

# 이터러블(my_list)에서 이터레이터(my_iterator)를 얻습니다.
my_iterator = iter(my_list)

print(f"my_iterator는 이터레이터인가? {hasattr(my_iterator, '__next__')}")
print(f"my_iterator는 이터러블인가? {hasattr(my_iterator, '__iter__')}") # True, 자신을 반환하기 때문

# next() 함수를 사용하여 요소를 하나씩 가져옵니다.
print(f"첫 번째 요소: {next(my_iterator)}") # 10
print(f"두 번째 요소: {next(my_iterator)}") # 20
print(f"세 번째 요소: {next(my_iterator)}") # 30

# 더 이상 요소가 없으면 StopIteration 예외가 발생합니다.
try:
    print(f"네 번째 요소: {next(my_iterator)}")
except StopIteration:
    print("더 이상 가져올 요소가 없습니다! (StopIteration 발생)")

# 한번 소진된 이터레이터는 다시 시작할 수 없습니다.
# 새로운 이터레이터를 얻으려면 다시 iter(my_list)를 호출해야 합니다.
```

## 3. 이터러블과 이터레이터의 관계 및 `for` 루프 동작 방식

이터러블은 '무엇을' 반복할 수 있는지 정의하고, 이터레이터는 '어떻게' 반복할지 그리고 현재 어디까지 반복했는지 상태를 기억하며 실제로 값을 하나씩 '생성' 또는 '제공'하는 역할을 합니다.

우리가 파이썬에서 사용하는 `for` 루프는 내부적으로 다음과 같이 동작합니다.

```python
# for item in iterable:
# 위 코드는 내부적으로 다음과 같이 동작합니다.

# 1. iter() 함수를 호출하여 이터러블에서 이터레이터를 얻습니다.
_iterator = iter(iterable)

while True:
    try:
        # 2. 이터레이터의 next() 메서드를 호출하여 다음 요소를 얻습니다.
        item = next(_iterator)
        
        # 3. 얻은 item으로 필요한 작업을 수행합니다.
        #    (for 루프 본문의 코드가 여기에 해당합니다.)
        print(item) # 예시

    except StopIteration:
        # 4. 더 이상 요소가 없으면 StopIteration 예외가 발생하고 루프를 종료합니다.
        break
```

## 4. 왜 이터러블과 이터레이터를 이해해야 할까요? (중요성)

이 개념들을 이해하는 것은 단순히 지식을 늘리는 것을 넘어, 실제 파이썬 프로그래밍에 큰 이점을 제공합니다.

1.  **메모리 효율성 (Lazy Evaluation):** 이터레이터는 모든 데이터를 한꺼번에 메모리에 로드하지 않고, `next()` 메서드가 호출될 때마다 필요한 데이터를 하나씩 생성하거나 가져옵니다. 이는 특히 대용량 데이터(파일, 네트워크 스트림 등)를 다룰 때 메모리 사용량을 획기적으로 줄여줍니다. 필요한 시점에만 값을 평가하는 '게으른(lazy) 평가' 방식입니다.

2.  **무한 시퀀스 처리:** 모든 값을 미리 생성할 수 없는 무한한 시퀀스(예: 피보나치 수열, 무한 카운터)를 이터레이터를 통해 효율적으로 다룰 수 있습니다.

3.  **코드의 재사용성 및 유연성:** 이터레이터 프로토콜을 따름으로써 다양한 데이터 소스에 대해 동일한 반복 인터페이스를 제공할 수 있습니다.

4.  **제너레이터(Generator)의 기반:** 파이썬의 강력한 기능인 제너레이터는 이터레이터를 더 쉽게 만들 수 있도록 해주는 특별한 함수(또는 표현식)입니다. 이터레이터 개념을 이해하면 제너레이터도 훨씬 쉽게 이해하고 활용할 수 있습니다.

## 5. 나만의 이터러블과 이터레이터 만들기

이해를 돕기 위해 간단한 숫자 카운터 이터러블/이터레이터를 직접 만들어 봅시다. 이 객체는 지정된 범위 내의 숫자를 하나씩 반환할 것입니다.

```python
class MyCounter:
    def __init__(self, low, high):
        self.current = low  # 현재 값
        self.high = high    # 상한 값 (이 값 미만까지 반복)

    def __iter__(self):
        # 이터러블이 iter() 호출을 받으면, 이터레이터를 반환해야 합니다.
        # 여기서는 MyCounter 객체 자체가 __next__ 메서드도 가지고 있으므로,
        # 자신(self)을 이터레이터로 반환합니다.
        return self

    def __next__(self):
        # next() 호출 시 다음 값을 반환합니다.
        if self.current < self.high:
            num = self.current
            self.current += 1
            return num
        # 더 이상 반환할 값이 없으면 StopIteration을 발생시켜야 합니다.
        raise StopIteration

# MyCounter 객체 사용 예시
print("MyCounter를 사용한 for 루프:")
for i in MyCounter(1, 6): # 1부터 5까지 반복
    print(i) # 출력: 1, 2, 3, 4, 5

print("-" * 20)

# 수동으로 이터레이터 사용 예시
counter_iter = iter(MyCounter(10, 13)) # 10, 11, 12
print(f"첫 번째: {next(counter_iter)}")
print(f"두 번째: {next(counter_iter)}")
print(f"세 번째: {next(counter_iter)}")
try:
    print(f"네 번째: {next(counter_iter)}")
except StopIteration:
    print("더 이상 숫자가 없습니다!")
```

위 `MyCounter` 클래스는 `__iter__`와 `__next__` 메서드를 모두 구현하여 이터러블이면서 동시에 이터레이터 역할도 수행합니다. `for` 루프가 `iter(MyCounter(1, 6))`을 호출하면 `self` (즉, `MyCounter` 인스턴스)가 반환되고, 이후 `next()`가 반복적으로 호출되어 숫자를 하나씩 얻게 되는 것이죠.

## 마무리하며

오늘은 파이썬 이터러블과 이터레이터의 차이점, 그리고 그들의 동작 방식과 중요성에 대해 알아보았습니다.
*   **이터러블(Iterable)**은 `for` 루프에 사용될 수 있는 "반복 가능한" 객체이며, `__iter__()` 메서드를 가집니다. (예: 리스트, 튜플, 문자열)
*   **이터레이터(Iterator)**는 이터러블의 요소를 "하나씩 꺼내주는" 역할을 하는 객체이며, `__iter__()`와 `__next__()` 메서드를 모두 가집니다. 상태를 기억하며, 더 이상 요소가 없으면 `StopIteration`을 발생시킵니다.

이 두 개념을 명확히 이해하면 파이썬의 `for` 루프가 어떻게 작동하는지 깊이 있게 알 수 있고, 메모리 효율적인 코드를 작성하며, 나아가 제너레이터와 같은 고급 기능을 이해하는 데 튼튼한 기반을 마련할 수 있습니다.

이제 여러분도 파이썬에서 `for` 루프를 만날 때마다 "아, 이건 이터러블이고, 내부적으로 이터레이터가 작동하는구나!"라고 생각하며 더 스마트하게 코딩할 수 있을 거예요! 다음 글에서는 이터러블과 이터레이터를 더욱 쉽고 간결하게 만들어주는 '제너레이터'에 대해 다루어보겠습니다.
