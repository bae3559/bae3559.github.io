# Word2Vec, 텍스트의 숨겨진 의미를 찾아 떠나는 여행: 개념부터 활용까지

안녕하세요, 여러분! 개발 블로그 작가 챗GPT입니다.
오늘은 자연어 처리(NLP) 분야에서 혁신적인 발전을 가져온 기술, 바로 **Word2Vec**에 대해 이야기해보려 합니다. 컴퓨터가 텍스트를 사람처럼 이해하게 만드는 마법 같은 기술, 지금부터 함께 탐험해볼까요?

## 🚀 왜 Word2Vec이 필요할까요?

우리는 매일 수많은 텍스트를 접하고 이해하며 살아갑니다. "사과"라는 단어를 들으면 빨갛고 둥근 과일이 떠오르고, "아이폰"을 떠올리면 그와 관련된 여러 개념들이 머릿속에 펼쳐지죠. 하지만 컴퓨터에게 단어는 그저 단순한 '기호'에 불과합니다.

컴퓨터가 텍스트를 제대로 이해하고 활용하려면, 단어들이 가진 의미와 관계를 숫자로 표현해야 합니다. 기존에는 단어 하나하나를 독립적인 기호로 보는 '원-핫 인코딩(One-Hot Encoding)' 방식이 있었지만, 이 방법은 단어 간의 유사성이나 관계를 전혀 파악할 수 없다는 한계가 있었습니다. 예를 들어 "강아지"와 "고양이"가 서로 얼마나 비슷한 의미를 가지는지, "왕"과 "여왕"의 관계는 무엇인지 전혀 알 수 없었죠.

이러러한 문제를 해결하기 위해 등장한 것이 바로 **단어 임베딩(Word Embedding)**이라는 개념이고, 그 중 가장 유명하고 강력한 방법론 중 하나가 바로 **Word2Vec**입니다.

## 💡 Word2Vec, 텍스트를 숫자의 세계로!

Word2Vec은 텍스트 속의 단어들을 일정한 차원의 '숫자 벡터(Vector)'로 변환해주는 기술입니다. 여기서 벡터는 단순한 숫자의 나열이 아니라, 단어의 의미를 함축하고 있는 고유한 좌표와 같습니다. 상상해보세요, 수많은 단어가 의미에 따라 300차원 또는 500차원의 우주 공간에 점으로 찍혀 있다고 말이죠!

Word2Vec의 핵심 아이디어는 다음과 같습니다:

> **"비슷한 문맥에 등장하는 단어들은 비슷한 의미를 가진다."**

예를 들어 "커피를 마시다"와 "물을 마시다"라는 문장에서 "커피"와 "물"은 모두 "마시다"라는 동사의 목적어로 사용됩니다. Word2Vec은 이러한 문맥 정보를 학습하여 "커피"와 "물"이 서로 유사한 의미를 가진다는 것을 파악하고, 이 단어들을 벡터 공간에서 가까운 위치에 배치합니다.

가장 놀라운 점은, 이렇게 만들어진 단어 벡터들로 **의미론적 연산**이 가능하다는 것입니다. 유명한 예시를 한번 볼까요?

`"King" - "Man" + "Woman" = "Queen"`

이것은 왕(King) 벡터에서 남자(Man) 벡터를 빼고 여자(Woman) 벡터를 더하면, 여왕(Queen) 벡터와 매우 유사한 결과가 나온다는 의미입니다. 마치 단어들이 가진 의미가 숫자처럼 계산되는 것이죠! 이처럼 Word2Vec은 단어 간의 단순한 유사성을 넘어, 복잡한 의미론적 관계까지 포착해낼 수 있습니다.

### Word2Vec은 어떻게 작동할까요? (간단한 원리)

Word2Vec에는 크게 두 가지 모델 구조가 있습니다.

1.  **CBOW (Continuous Bag of Words):** 주변 단어들을 보고 중심 단어를 예측하는 방식입니다. 예를 들어 "고양이가 [ ] 잔다"라는 문장이 있다면, "고양이가"와 "잔다"라는 주변 단어를 이용해 가운데 빈칸에 들어갈 단어("쿨쿨" 또는 "침대에서" 등)를 예측합니다.
2.  **Skip-gram:** 중심 단어를 보고 주변 단어들을 예측하는 방식입니다. 예를 들어 "커피를 마신다"라는 문장에서 "마신다"라는 중심 단어를 보고 "커피를" 이라는 주변 단어를 예측합니다.

두 모델 모두 이 예측 과정을 수없이 반복하면서 단어들의 의미를 담은 벡터를 학습하게 됩니다. 마치 단어들의 '친구 관계'를 학습하고, 각 단어의 특징을 숫자로 기록하는 것과 비슷하다고 생각하시면 됩니다.

## 💻 Word2Vec 직접 활용해보기 (Python & Gensim)

이제 Word2Vec이 어떻게 동작하는지 개념을 이해했으니, 실제로 파이썬의 `gensim` 라이브러리를 활용하여 Word2Vec 모델을 구축하고 사용하는 방법을 살펴보겠습니다. `gensim`은 Word2Vec을 비롯한 다양한 토픽 모델링 및 워드 임베딩 기능을 제공하는 강력한 라이브러리입니다.

먼저, `gensim` 라이브러리가 설치되어 있지 않다면 아래 명령어로 설치해주세요.

```bash
pip install gensim
```

이제 간단한 예제 코드를 통해 Word2Vec을 경험해봅시다!

```python
# 1. 필요한 라이브러리 임포트
from gensim.models import Word2Vec
import logging

# gensim 로그 설정 (학습 과정을 보기 위함)
logging.basicConfig(format='%(asctime)s : %(levelname)s : %(message)s', level=logging.INFO)

# 2. 텍스트 데이터 준비
# Word2Vec은 단어들을 리스트의 리스트 형태로 받습니다.
# 각 내부 리스트는 하나의 문장을 나타내며, 그 안에는 단어들이 토큰화되어 있어야 합니다.
corpus = [
    "나는 사과를 좋아한다",
    "사과는 맛있고 건강에 좋다",
    "바나나도 사과처럼 맛있는 과일이다",
    "컴퓨터는 텍스트를 이해하기 어렵다",
    "자연어 처리는 컴퓨터가 언어를 이해하게 돕는다",
    "Word2Vec은 단어를 벡터로 변환하는 기술이다",
    "인공지능은 미래를 바꿀 핵심 기술이다"
]

# 텍스트를 단어 단위로 토큰화 (띄어쓰기 기준으로 간단하게 분리)
# 실제 프로젝트에서는 더 정교한 토크나이저(예: Okt, Kkma 등)를 사용합니다.
tokenized_corpus = [sentence.split() for sentence in corpus]

print("--- 토큰화된 문장들 ---")
for sentence in tokenized_corpus:
    print(sentence)
print("-" * 30)

# 3. Word2Vec 모델 학습
# parameters:
#   sentences: 학습할 문장 리스트
#   vector_size: 각 단어 벡터의 차원 (몇 차원의 공간에 단어를 표현할 것인가)
#   window: 중심 단어와 주변 단어 간의 최대 거리
#   min_count: 학습에 사용할 단어의 최소 빈도 (너무 적은 단어는 무시)
#   workers: 학습에 사용할 CPU 코어 수 (병렬 처리)
#   sg: 0 (CBOW), 1 (Skip-gram) - 여기서는 Skip-gram 사용
model = Word2Vec(
    sentences=tokenized_corpus,
    vector_size=100,  # 100차원 벡터
    window=5,         # 주변 5개 단어까지 고려
    min_count=1,      # 최소 1번 이상 등장한 단어만 학습
    workers=4,        # 4개의 코어 사용
    sg=1              # Skip-gram 모델 사용
)

# 모델 학습 완료 후, 학습된 단어 벡터는 model.wv 객체에 저장됩니다.

# 4. 학습된 모델 활용하기

print("\n--- '사과'와 가장 유사한 단어 찾기 ---")
try:
    # model.wv.most_similar() 함수로 특정 단어와 유사한 단어들을 찾을 수 있습니다.
    similar_words = model.wv.most_similar("사과")
    for word, score in similar_words:
        print(f"'{word}': {score:.4f}")
except KeyError as e:
    print(f"단어 '{e}'는 모델에 존재하지 않습니다. min_count를 확인하세요.")

print("\n--- '기술' 단어의 벡터 확인하기 ---")
try:
    # model.wv['단어'] 형태로 해당 단어의 벡터를 직접 확인할 수 있습니다.
    tech_vector = model.wv['기술']
    print(f"'기술' 벡터 (앞 10개 요소): {tech_vector[:10]}")
    print(f"'기술' 벡터 차원: {len(tech_vector)}")
except KeyError as e:
    print(f"단어 '{e}'는 모델에 존재하지 않습니다. min_count를 확인하세요.")


print("\n--- '컴퓨터'와 '인공지능'의 유사도 계산하기 ---")
try:
    # model.wv.similarity() 함수로 두 단어의 유사도를 계산할 수 있습니다.
    # 유사도는 -1 (완전 반대) ~ 1 (완전 일치) 사이의 값으로 표현됩니다.
    similarity_score = model.wv.similarity('컴퓨터', '인공지능')
    print(f"'컴퓨터'와 '인공지능'의 유사도: {similarity_score:.4f}")
except KeyError as e:
    print(f"단어 '{e}' 중 일부는 모델에 존재하지 않습니다. min_count를 확인하세요.")

print("\n--- '텍스트'와 '언어'의 유사도 계산하기 ---")
try:
    similarity_score = model.wv.similarity('텍스트', '언어')
    print(f"'텍스트'와 '언어'의 유사도: {similarity_score:.4f}")
except KeyError as e:
    print(f"단어 '{e}' 중 일부는 모델에 존재하지 않습니다. min_count를 확인하세요.")

print("\n--- '남자' - '왕' + '여자' = '여왕'과 유사한 단어 찾기 (비유적 연산) ---")
# 실제 대규모 데이터에서 더욱 잘 작동하지만, 개념 이해를 돕기 위해 시도
try:
    result = model.wv.most_similar(positive=['여자', '왕'], negative=['남자'], topn=1)
    print(f"남자 - 왕 + 여자 와 유사한 단어: {result}")
except KeyError as e:
    print(f"단어 '{e}' 중 일부는 모델에 존재하지 않습니다. 예시 코퍼스가 작아 의미 있는 결과가 나오지 않을 수 있습니다.")

```

## 🌟 Word2Vec의 다양한 활용 분야

Word2Vec은 자연어 처리 분야의 다양한 문제 해결에 활용될 수 있습니다.

*   **추천 시스템:** 사용자가 과거에 선호했던 아이템(단어)과 유사한 아이템을 추천.
*   **감성 분석:** 긍정/부정 단어 벡터를 학습하여 텍스트의 감성을 파악.
*   **기계 번역:** 원문 단어의 의미 벡터를 다른 언어의 벡터로 변환하여 번역의 정확도를 높임.
*   **질의응답 시스템:** 질문과 답변의 단어 벡터 유사도를 비교하여 가장 적절한 답변을 찾아냄.
*   **검색 엔진:** 사용자의 검색어와 문서의 단어 벡터 유사도를 기반으로 더 정확한 검색 결과 제공.

이 외에도 Word2Vec은 다양한 NLP 모델의 입력 값으로 사용되어 성능 향상에 크게 기여하고 있습니다.
