# 길 찾기의 마법사, 다익스트라(Dijkstra) 알고리즘 파이썬으로 정복하기

안녕하세요, 여러분!
우리가 일상생활에서 가장 흔하게 사용하는 기능 중 하나는 바로 '길 찾기' 아닐까요? 목적지까지 가장 빠른 길, 가장 짧은 길을 찾아주는 내비게이션이나 지도 앱 없이는 이제 어디를 가기도 힘들 정도입니다. 그런데 이런 길 찾기 서비스 뒤에는 아주 똑똑한 알고리즘이 숨어있다는 사실, 알고 계셨나요?

바로 오늘 우리가 파헤쳐 볼 **다익스트라(Dijkstra) 알고리즘**이 그 주인공입니다! 다익스트라 알고리즘은 그래프에서 '출발점으로부터 다른 모든 정점(노드)까지의 최단 경로'를 찾아주는 매우 유명하고 강력한 알고리즘입니다. 코딩 테스트부터 실제 서비스 구현까지, 개발자라면 반드시 알아야 할 필수 개념이죠.

이 글에서는 다익스트라 알고리즘의 기본 개념부터 단계별 작동 방식, 그리고 파이썬으로 직접 구현하는 방법까지 초보자 눈높이에 맞춰 친절하게 설명해 드릴게요. 자, 그럼 길 찾기의 마법 속으로 함께 떠나볼까요?

---

## 1. 다익스트라 알고리즘은 무엇인가요? (개념 이해)

### 최단 경로 문제, 그게 뭔데?
우리가 살아가는 세상은 수많은 연결로 이루어져 있습니다. 도시와 도시를 잇는 도로, 컴퓨터 네트워크상의 서버들, 지하철 노선도 등이 모두 '그래프(Graph)'라는 형태로 표현될 수 있어요. 그래프는 **정점(Vertex 또는 Node)**과 정점들을 연결하는 **간선(Edge)**으로 구성됩니다.

여기에 각 간선마다 이동하는 데 드는 비용이나 시간 같은 **가중치(Weight)**가 부여될 수 있습니다. 예를 들어, 도시 A에서 B로 가는 데 2시간이 걸리고, B에서 C로 가는 데 1시간이 걸린다면, 2시간과 1시간이 각각 간선의 가중치가 됩니다.

`최단 경로 문제(Shortest Path Problem)`는 말 그대로 특정 출발 정점에서 다른 모든 정점까지의 가중치 합이 가장 작은 경로를 찾는 문제입니다. 그리고 다익스트라 알고리즘은 이 최단 경로 문제를 해결하는 대표적인 방법 중 하나입니다.

### 다익스트라 알고리즘의 핵심 아이디어
다익스트라 알고리즘은 '탐욕적인(Greedy)' 방식으로 작동합니다. 즉, 현재 시점에서 가장 최적의 선택을 반복함으로써 최종적으로 최단 경로를 찾아냅니다. 그 핵심 아이디어는 다음과 같습니다:

1.  **출발 정점 설정:** 특정 정점을 출발점으로 정합니다. 출발점에서 자기 자신까지의 거리는 0, 다른 모든 정점까지의 거리는 '무한대'로 초기화합니다.
2.  **가장 가까운 정점 선택:** 아직 방문하지 않은 정점들 중에서 출발점으로부터의 거리가 가장 짧은 정점을 선택합니다.
3.  **거리 정보 갱신 (Relaxation):** 선택된 정점을 통해 갈 수 있는 이웃 정점들의 거리를 계산하여, 현재 알려진 거리보다 더 짧으면 그 거리를 갱신합니다.
4.  **반복:** 모든 정점을 방문하거나, 더 이상 갱신할 수 있는 경로가 없을 때까지 2단계와 3단계를 반복합니다.

이때 '가장 가까운 정점'을 효율적으로 선택하기 위해 **우선순위 큐(Priority Queue)**라는 자료구조를 사용합니다. 우선순위 큐는 가장 작은(혹은 큰) 값을 항상 맨 앞에 유지하는 자료구조로, 힙(Heap)으로 구현됩니다.

**중요한 전제 조건:** 다익스트라 알고리즘은 간선의 가중치가 **음수**인 경우에는 올바르게 작동하지 않습니다. 음수 가중치가 있을 경우 벨만-포드(Bellman-Ford) 알고리즘 등을 사용해야 합니다.

## 2. 다익스트라 알고리즘 작동 원리 (단계별 예시)

말로만 들으면 어려울 수 있으니, 간단한 그래프를 예시로 들어 다익스트라 알고리즘이 어떻게 작동하는지 살펴봅시다.

**그래프 예시:**

```
  (A) --2-- (B) --1-- (D)
   |        |        /
   3        4       5
   |        |      /
  (C) --6-- (E) --/
```

*   **정점:** A, B, C, D, E
*   **간선과 가중치:** (A,B)=2, (A,C)=3, (B,D)=1, (B,E)=4, (C,E)=6, (D,E)=5
*   **출발 정점:** A

**단계별 진행:**

| 단계 | 방문 예정 정점 (거리, 정점) (우선순위 큐) | 확정된 최단 거리 | 방문 완료 정점 | 설명 |
| :--- | :---------------------------------- | :---------------- | :------------- | :--- |
| **초기** | `[(0, 'A')]`                        | `A: 0, B:∞, C:∞, D:∞, E:∞` | `[]`           | 출발점 A는 0, 나머지는 무한대 |
| **1단계** | (0, A) 추출. 인접 노드 갱신 | `A: 0, B:2, C:3, D:∞, E:∞` | `[A]`          | B(0+2=2), C(0+3=3) 갱신 후 큐에 삽입. 큐: `[(2, 'B'), (3, 'C')]` |
| **2단계** | (2, B) 추출. 인접 노드 갱신 | `A: 0, B:2, C:3, D:3, E:6` | `[A, B]`       | B를 통해 D(2+1=3), E(2+4=6) 갱신 후 큐에 삽입. 큐: `[(3, 'C'), (3, 'D'), (6, 'E')]` |
| **3단계** | (3, C) 추출. 인접 노드 갱신 | `A: 0, B:2, C:3, D:3, E:6` | `[A, B, C]`    | C를 통해 E(3+6=9) 갱신 시도. 현재 E는 6이므로 갱신 안 함. 큐: `[(3, 'D'), (6, 'E')]` |
| **4단계** | (3, D) 추출. 인접 노드 갱신 | `A: 0, B:2, C:3, D:3, E:6` | `[A, B, C, D]` | D를 통해 E(3+5=8) 갱신 시도. 현재 E는 6이므로 갱신 안 함. 큐: `[(6, 'E')]` |
| **5단계** | (6, E) 추출. 인접 노드 없음 | `A: 0, B:2, C:3, D:3, E:6` | `[A, B, C, D, E]` | 모든 노드 방문 완료. 큐: `[]` |

**최종 결과:**
*   A -> A: 0
*   A -> B: 2 (A-B)
*   A -> C: 3 (A-C)
*   A -> D: 3 (A-B-D)
*   A -> E: 6 (A-B-E)

## 3. 파이썬으로 다익스트라 알고리즘 구현하기

이제 위에서 살펴본 개념과 작동 방식을 바탕으로 파이썬 코드를 작성해봅시다.

### 필요한 자료구조
1.  **그래프 표현:** `딕셔너리(Dictionary)`와 `중첩 딕셔너리`를 활용하여 인접 리스트(Adjacency List) 방식으로 그래프를 표현합니다.
    *   `graph = {'A': {'B': 2, 'C': 3}, 'B': {'D': 1, 'E': 4}, ...}`
2.  **거리 정보 저장:** 각 정점까지의 최단 거리를 저장할 딕셔너리가 필요합니다. 초기에는 출발점은 0, 나머지는 `float('inf')` (무한대)로 설정합니다.
    *   `distances = {'A': 0, 'B': float('inf'), ...}`
3.  **우선순위 큐:** 파이썬의 `heapq` 모듈을 사용하여 최소 힙(Min-Heap)을 구현합니다. `heapq`는 `(거리, 정점)` 튜플 형태로 데이터를 저장하여 거리가 가장 짧은 정점이 항상 먼저 추출되도록 합니다.

```python
import heapq

def dijkstra(graph, start_node):
    # 1. 거리 정보 초기화
    # 모든 노드에 대한 최단 거리를 무한대로 초기화하고, 출발 노드는 0으로 설정
    distances = {node: float('inf') for node in graph}
    distances[start_node] = 0

    # 2. 우선순위 큐 생성
    # (거리, 노드) 형태의 튜플을 저장하며, 거리가 짧은 노드가 우선적으로 처리됨
    priority_queue = [(0, start_node)]

    # 3. 우선순위 큐가 빌 때까지 반복
    while priority_queue:
        # 가장 거리가 짧은 노드를 큐에서 추출
        # current_distance: 현재 노드까지의 거리
        # current_node: 현재 탐색 중인 노드
        current_distance, current_node = heapq.heappop(priority_queue)

        # 이미 처리된 노드이거나, 현재 큐에서 꺼낸 거리가 이미 저장된 거리보다 길다면
        # 이 경로는 최단 경로가 아니므로 무시하고 다음 노드로 넘어감
        if current_distance > distances[current_node]:
            continue

        # 현재 노드와 연결된 이웃 노드들을 탐색
        for neighbor, weight in graph[current_node].items():
            # 현재 노드를 거쳐 이웃 노드로 가는 새로운 거리 계산
            new_distance = current_distance + weight

            # 새로운 거리가 이웃 노드에 저장된 현재 최단 거리보다 짧으면 갱신
            if new_distance < distances[neighbor]:
                distances[neighbor] = new_distance
                # 갱신된 이웃 노드를 우선순위 큐에 추가
                heapq.heappush(priority_queue, (new_distance, neighbor))

    return distances

# 그래프 정의 (위 예시와 동일)
# 각 노드를 키로 갖고, 이웃 노드와 해당 노드까지의 가중치를 딕셔너리 형태로 저장
graph = {
    'A': {'B': 2, 'C': 3},
    'B': {'A': 2, 'D': 1, 'E': 4}, # 양방향 그래프이므로 A->B와 B->A 모두 추가
    'C': {'A': 3, 'E': 6},
    'D': {'B': 1, 'E': 5},
    'E': {'B': 4, 'C': 6, 'D': 5}
}

# 출발 노드 설정
start_node = 'A'

# 다익스트라 알고리즘 실행
shortest_paths = dijkstra(graph, start_node)

# 결과 출력
print(f"출발 노드 '{start_node}'로부터의 최단 경로:")
for node, distance in shortest_paths.items():
    print(f"  {node}: {distance}")

```

**코드 설명:**

1.  **`dijkstra(graph, start_node)` 함수:**
    *   `distances`: 각 노드까지의 최단 거리를 저장하는 딕셔너리입니다. `start_node`는 0으로, 나머지는 `float('inf')`로 초기화합니다.
    *   `priority_queue`: 우선순위 큐로 사용할 리스트입니다. `heapq` 모듈의 함수를 사용합니다. 초기에는 `(0, start_node)`만 들어있습니다.
    *   **`while priority_queue:`**: 큐가 비어있지 않은 동안 반복합니다.
    *   **`current_distance, current_node = heapq.heappop(priority_queue)`**: 큐에서 가장 거리가 짧은 노드와 그 거리를 추출합니다.
    *   **`if current_distance > distances[current_node]: continue`**: 이 조건은 중요한 최적화입니다. 우선순위 큐에는 같은 노드에 대한 여러 경로 정보가 들어갈 수 있는데, 이미 더 짧은 경로가 `distances`에 기록되어 있다면 현재 추출한 경로는 무시하고 넘어갑니다.
    *   **`for neighbor, weight in graph[current_node].items():`**: 현재 노드와 연결된 모든 이웃 노드를 탐색합니다.
    *   **`new_distance = current_distance + weight`**: 현재 노드를 거쳐 이웃 노드로 가는 새로운 경로의 총 거리를 계산합니다.
    *   **`if new_distance < distances[neighbor]:`**: 만약 새로 계산한 거리가 이웃 노드에 현재 기록된 최단 거리보다 짧다면, 거리를 갱신하고 이웃 노드를 우선순위 큐에 추가합니다.

### 출력 결과:
```
출발 노드 'A'로부터의 최단 경로:
  A: 0
  B: 2
  C: 3
  D: 3
  E: 6
```

## 4. 다익스트라 알고리즘의 시간 복잡도

다익스트라 알고리즘의 시간 복잡도는 구현 방식에 따라 달라집니다.
우선순위 큐(Min-Heap)를 사용하는 경우, 일반적인 그래프에서 **O(E log V)** 또는 **O((V+E) log V)**로 표현됩니다.

*   **V (Vertices):** 정점의 개수
*   **E (Edges):** 간선의 개수

`heapq` 모듈의 `heappush`와 `heappop` 연산이 `O(log N)`의 시간을 소요하기 때문에, 효율적인 최단 경로 탐색이 가능합니다. 이는 간선이 많지 않은 희소 그래프(Sparse Graph)에서 특히 효율적입니다.
