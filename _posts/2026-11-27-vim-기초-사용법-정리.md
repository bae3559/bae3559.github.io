# Vim, 개발 생산성의 마법: 초보자를 위한 Vim 기초 사용법 완벽 정리

안녕하세요, 개발 블로그 작가 얄코입니다!

개발자라면 한 번쯤 "Vim"이라는 이름을 들어보셨을 겁니다. 처음 마주하면 낯설고 불편하게 느껴질 수 있지만, 일단 익숙해지면 마우스를 거의 사용하지 않고 키보드만으로 빛의 속도로 코드를 편집하는 자신을 발견하게 될 겁니다. 리눅스 서버에서 작업할 때, 터미널 환경에서 코드를 빠르게 수정해야 할 때, Vim은 여러분의 강력한 동반자가 되어줄 것입니다.

이번 글에서는 Vim이 무엇인지부터 시작하여, Vim의 핵심 개념인 '모드'를 이해하고, 자주 사용되는 기본 명령어들을 하나씩 살펴보겠습니다. 이 글을 통해 Vim의 첫걸음을 떼고, 생산성 향상의 첫 단추를 채우실 수 있기를 바랍니다!

---

## 1. Vim, 그게 뭔가요?

Vim은 "Vi IMproved"의 줄임말로, 유닉스 계열 시스템에서 주로 사용되는 텍스트 편집기 Vi의 강력한 기능을 개선하고 확장한 버전입니다. Vim의 가장 큰 특징은 마우스 없이 키보드만으로 모든 텍스트 편집 작업을 수행할 수 있다는 점입니다. 명령어를 조합하여 텍스트를 탐색하고, 수정하고, 삭제하는 방식은 처음에는 다소 진입 장벽이 높게 느껴질 수 있지만, 숙련되면 어떤 에디터보다 빠르고 효율적인 작업이 가능해집니다.

**왜 Vim을 배워야 할까요?**

*   **생산성 향상**: 키보드만으로 모든 작업을 처리하여 작업 흐름이 끊기지 않습니다.
*   **어디서나 사용 가능**: 대부분의 유닉스/리눅스 시스템에 기본적으로 설치되어 있어, 원격 서버 작업 시 필수적입니다.
*   **자원 효율성**: 가볍고 빠르며, 시스템 자원을 적게 사용합니다.
*   **강력한 기능**: 매크로, 플러그인 등 다양한 기능을 통해 작업을 자동화하고 확장할 수 있습니다.

## 2. Vim의 핵심, '모드(Mode)' 이해하기

Vim이 다른 텍스트 에디터와 가장 다른 점은 바로 '모드' 개념입니다. Vim은 상황에 따라 다른 작업을 수행하기 위해 여러 가지 모드를 가지고 있습니다. 초보자들이 가장 혼란스러워하는 부분이기도 하지만, 이것만 이해하면 Vim 사용의 절반은 성공입니다!

주요 모드는 다음과 같습니다:

1.  **일반 모드 (Normal Mode)**:
    *   Vim을 실행하면 가장 먼저 진입하는 모드입니다.
    *   텍스트를 입력하는 것이 아니라, 텍스트를 탐색하거나, 복사/삭제/붙여넣기 등의 조작 명령어를 실행하는 데 사용됩니다.
    *   거의 모든 명령의 시작점이 됩니다.

2.  **입력 모드 (Insert Mode)**:
    *   텍스트를 직접 입력할 때 사용하는 모드입니다.
    *   일반적인 텍스트 에디터처럼 자유롭게 글자를 타이핑할 수 있습니다.

3.  **비주얼 모드 (Visual Mode)**:
    *   텍스트 블록을 시각적으로 선택할 때 사용합니다. 선택된 텍스트에 대해 복사, 삭제 등의 작업을 수행할 수 있습니다.

4.  **명령 모드 (Command-Line Mode / Ex Mode)**:
    *   파일 저장, 종료, 검색 및 치환, 외부 명령어 실행 등 특정 명령을 입력할 때 사용합니다.
    *   일반 모드에서 `:`를 누르면 진입합니다.

### 모드 전환 방법

*   **`Esc`**: 입력 모드, 비주얼 모드, 명령 모드에서 **일반 모드**로 돌아갈 때 사용합니다. 가장 중요하니 꼭 기억하세요!
*   **`i` (insert)**: 일반 모드에서 **입력 모드**로 진입합니다. (커서 위치에서 입력)
*   **`v` (visual)**: 일반 모드에서 **비주얼 모드**로 진입합니다. (문자 단위 선택)
*   **`:` (콜론)**: 일반 모드에서 **명령 모드**로 진입합니다.

## 3. Vim으로 파일 다루기: 열고, 저장하고, 닫기

가장 기본적인 파일 작업 방법입니다.

```python
# 'filename.py' 파일을 Vim으로 엽니다.
# 파일이 없으면 새로 생성됩니다.
# vim filename.py

# 현재 파일을 저장합니다. (일반 모드 또는 명령 모드에서 ':w' 입력 후 Enter)
# :w

# 현재 파일을 저장하고 종료합니다.
# :wq

# 현재 파일을 저장하지 않고 강제로 종료합니다. (수정 내용을 버릴 때)
# :q!

# 현재 파일을 저장하고 종료합니다. (:wq와 동일)
# :x
```

## 4. 텍스트 입력의 시작, '입력 모드'

일반 모드에서 특정 키를 누르면 입력 모드로 진입하여 텍스트를 입력할 수 있습니다. 입력 모드에서는 일반적인 텍스트 에디터처럼 동작하며, `Esc` 키를 누르면 다시 일반 모드로 돌아갑니다.

```python
# 일반 모드에서 입력 모드로 진입하는 주요 명령어들:

# i (insert): 현재 커서 위치 앞에서 입력 시작
# a (append): 현재 커서 위치 뒤에서 입력 시작
# o (open line below): 현재 줄 아래에 새 줄을 만들고 입력 시작
# O (open line above): 현재 줄 위에 새 줄을 만들고 입력 시작
# I (insert at beginning of line): 현재 줄의 맨 앞에서 입력 시작
# A (append at end of line): 현재 줄의 맨 뒤에서 입력 시작

# Tip: 입력 모드 진입 후에는 마음껏 타이핑하세요!
#      입력을 마치면 반드시 'Esc'를 눌러 일반 모드로 돌아와야 합니다.
```

## 5. 자유로운 탐색, '일반 모드' (커서 이동)

일반 모드에서는 마우스 없이 키보드만으로 커서를 자유롭게 이동할 수 있습니다.

```python
# 기본 커서 이동 (Vim의 핵심! 손가락에 익숙해지도록 연습하세요.)
# h: 왼쪽으로 한 칸 이동
# j: 아래로 한 줄 이동
# k: 위로 한 줄 이동
# l: 오른쪽으로 한 칸 이동

# 단어 단위 이동
# w (word): 다음 단어의 시작으로 이동
# b (back): 이전 단어의 시작으로 이동
# e (end): 현재 단어의 끝으로 이동
# ge (go end of previous word): 이전 단어의 끝으로 이동

# 줄 단위 이동
# 0 (zero): 현재 줄의 맨 처음으로 이동 (공백 포함)
# ^ (caret): 현재 줄의 첫 번째 비어있지 않은 문자(non-blank character)로 이동
# $ (dollar): 현재 줄의 맨 끝으로 이동

# 파일 단위 이동
# gg: 파일의 맨 처음으로 이동
# G: 파일의 맨 끝으로 이동
# Ngg 또는 NG: N번째 줄로 이동 (예: 10gg 또는 10G는 10번째 줄로 이동)
```

## 6. 텍스트 조작의 달인, '일반 모드' (삭제, 복사, 붙여넣기, 실행 취소)

이 명령어들을 조합하면 매우 빠르게 텍스트를 편집할 수 있습니다.

```python
# 삭제 (Delete)
# x: 현재 커서가 있는 문자 한 개 삭제 (Delete Char)
# dw: 커서 위치부터 다음 단어 끝까지 삭제 (Delete Word)
# dd: 현재 줄 전체를 삭제 (Delete Line)
# D: 커서 위치부터 현재 줄의 끝까지 삭제

# 복사 (Yank - Vim에서는 'yank'라고 부릅니다)
# yy: 현재 줄 전체를 복사 (Yank Line)
# yw: 커서 위치부터 다음 단어 끝까지 복사 (Yank Word)

# 붙여넣기 (Paste)
# p (paste after): 커서 뒤에 붙여넣기 (줄 복사 시에는 다음 줄에 붙여넣기)
# P (paste before): 커서 앞에 붙여넣기 (줄 복사 시에는 이전 줄에 붙여넣기)

# 실행 취소 (Undo) / 다시 실행 (Redo)
# u: 마지막 명령을 취소 (Undo)
# Ctrl+r: 취소한 명령을 다시 실행 (Redo)
```

## 7. 블록 선택의 마법, '비주얼 모드'

특정 범위의 텍스트를 선택하여 조작하고 싶을 때 비주얼 모드를 사용합니다. `v`, `V`, `Ctrl+v`로 비주얼 모드에 진입한 후, `h`, `j`, `k`, `l` 등의 이동 키로 범위를 지정합니다. 범위 지정 후에는 `d` (삭제), `y` (복사), `>` (들여쓰기) 등의 명령을 적용할 수 있습니다.

```python
# 비주얼 모드 진입 및 활용
# v (visual): 문자 단위로 블록 선택 (일반 모드에서 'v' 입력 후 이동)
# V (visual line): 줄 단위로 블록 선택 (일반 모드에서 'V' 입력 후 이동)
# Ctrl+v (visual block): 사각형 블록 선택 (일반 모드에서 'Ctrl+v' 입력 후 이동)

# 선택 후 작업 예시:
# 1. 'v'를 눌러 비주얼 모드 진입
# 2. 'l'이나 'w' 등으로 원하는 텍스트를 선택
# 3. 'd'를 눌러 선택된 텍스트 삭제
# 4. 'y'를 눌러 선택된 텍스트 복사
# 5. '>'를 눌러 선택된 줄 들여쓰기
```

## 8. Vim, 더 깊이 들어가기 (명령 모드 활용)

명령 모드(`:`)는 Vim의 강력한 기능을 사용하는 또 다른 창구입니다.

```python
# 텍스트 검색
# /pattern: 현재 커서부터 아래 방향으로 'pattern' 검색
# ?pattern: 현재 커서부터 위 방향으로 'pattern' 검색
# n: 다음 검색 결과로 이동
# N: 이전 검색 결과로 이동

# 텍스트 치환 (Replace)
# :%s/old/new/g
#   %: 전체 파일
#   s: substitute (치환)
#   old: 찾을 문자열
#   new: 바꿀 문자열
#   g (global): 한 줄에 여러 개의 'old'가 있을 경우 모두 치환 (없으면 첫 번째만 치환)
#   (예: :%s/apple/banana/g - 파일 전체의 모든 'apple'을 'banana'로 변경)

# :N,Ms/old/new/g
#   N,M: N번째 줄부터 M번째 줄까지 범위 지정
#   (예: :10,20s/error/warning/g - 10줄부터 20줄까지 'error'를 'warning'으로 변경)
```
