# 개발자의 필수 도구: 최소 신장 트리 (MST) 완벽 가이드 (크루스칼 & 프림)

안녕하세요, 여러분! 효율적인 시스템을 설계하고 최적의 경로를 찾는 것은 개발자의 숙명과도 같습니다. 오늘은 이러한 최적화 문제 해결에 필수적인 강력한 도구, 바로 **최소 신장 트리(Minimum Spanning Tree, MST)**에 대해 이야기해보려 합니다. 특히, MST를 구하는 대표적인 두 가지 알고리즘인 **크루스칼(Kruskal)**과 **프림(Prim)** 알고리즘을 초보자도 이해하기 쉽게 설명하고, 파이썬 코드로 직접 구현해보겠습니다.

## 1. 최소 신장 트리(MST)는 무엇일까요?

복잡한 개념처럼 들릴 수 있지만, 사실 우리 주변에서 쉽게 찾아볼 수 있는 문제입니다.

상상해보세요:
*   어떤 도시들에 인터넷망을 깔아야 하는데, 각 도시를 연결하는 데 드는 비용이 다릅니다. 모든 도시를 연결하면서 총 설치 비용을 최소화하고 싶다면?
*   수많은 지점들을 연결하는 도로망을 구축해야 하는데, 각 도로 건설 비용이 다릅니다. 모든 지점을 서로 연결하면서 총 건설 비용을 최소화하고 싶다면?

이런 문제들을 해결하는 열쇠가 바로 **최소 신장 트리(MST)**입니다.

좀 더 기술적으로 설명해볼까요?

1.  **그래프(Graph):** 먼저, 도시나 지점 같은 "개체"들을 **정점(Vertex 또는 Node)**이라고 부르고, 그 개체들을 연결하는 "길"이나 "선"을 **간선(Edge)**이라고 합니다. 각 간선에는 "비용"이나 "거리" 같은 **가중치(Weight)**가 부여될 수 있습니다. 이렇게 정점과 간선으로 이루어진 구조를 **그래프**라고 합니다.

2.  **신장 트리(Spanning Tree):** 그래프의 모든 정점들을 포함하면서, **사이클(Cycle, 순환)**이 없이 서로 연결된 형태를 **신장 트리**라고 합니다. 신장 트리는 항상 `정점의 개수 - 1`개의 간선을 가집니다. 마치 모든 도시를 하나의 네트워크로 묶되, 불필요하게 빙빙 돌아가는 길이 없는 가장 기본적인 연결망을 만드는 것과 같죠.

3.  **최소 신장 트리(Minimum Spanning Tree, MST):** 여러 신장 트리 중에서 간선들의 가중치 합이 가장 작은 신장 트리를 **최소 신장 트리(MST)**라고 합니다. 즉, 모든 정점을 연결하면서도 총 비용을 최소화하는 최적의 연결망을 찾는 것이죠!

## 2. 크루스칼(Kruskal) 알고리즘

크루스칼 알고리즘은 **간선 중심**으로 MST를 구성하는 방식입니다. "가장 저렴한 간선부터 차례로 추가하되, 사이클이 생기지 않도록!" 하는 아주 직관적인 접근 방식이죠.

### 동작 원리

1.  **모든 간선을 가중치에 따라 오름차순으로 정렬합니다.** (가장 저렴한 간선부터 보겠다는 거죠!)
2.  각 정점을 자기 자신만을 포함하는 개별 집합으로 초기화합니다. (모든 정점이 아직 아무와도 연결되지 않은 상태)
3.  정렬된 간선을 하나씩 검토합니다.
    *   간선 `(u, v)`를 선택했을 때, `u`와 `v`가 아직 같은 집합에 속해있지 않다면 (즉, 이 간선을 추가해도 사이클이 생기지 않는다면), 이 간선을 MST에 추가하고 `u`가 속한 집합과 `v`가 속한 집합을 합칩니다.
    *   만약 `u`와 `v`가 이미 같은 집합에 속해 있다면, 이 간선을 추가하면 사이클이 생기므로 무시하고 다음 간선으로 넘어갑니다.
4.  MST에 `정점의 개수 - 1`개의 간선이 추가될 때까지 3번 과정을 반복합니다.

### 핵심 아이디어: 서로소 집합(Disjoint Set Union, DSU) 자료구조

크루스칼 알고리즘에서 "사이클이 생기지 않는지"를 효율적으로 판단하기 위해 **서로소 집합(Disjoint Set Union, DSU)** 자료구조가 사용됩니다. DSU는 여러 개의 원소들을 서로 겹치지 않는 집합들로 나누어 관리하는 자료구조입니다.

*   `find(x)`: 원소 `x`가 속한 집합의 대표 원소(루트)를 찾습니다. (경로 압축(Path Compression) 기법으로 최적화)
*   `union(x, y)`: 원소 `x`가 속한 집합과 원소 `y`가 속한 집합을 합칩니다. (union-by-rank 또는 union-by-size 기법으로 최적화)

### 파이썬 코드 예제 (크루스칼)

```python
# 서로소 집합(Disjoint Set Union) 자료구조 구현
def find(parent, i):
    if parent[i] == i:
        return i
    parent[i] = find(parent, parent[i]) # 경로 압축
    return parent[i]

def union(parent, rank, i, j):
    root_i = find(parent, i)
    root_j = find(parent, j)

    if root_i != root_j:
        # 랭크(트리 높이)를 기준으로 합치기 (union-by-rank)
        if rank[root_i] < rank[root_j]:
            parent[root_i] = root_j
        elif rank[root_i] > rank[root_j]:
            parent[root_j] = root_i
        else:
            parent[root_j] = root_i
            rank[root_i] += 1
        return True # 합쳐짐
    return False # 이미 같은 집합

def kruskal(vertices, edges):
    mst_edges = []
    total_cost = 0
    
    # 1. 모든 간선을 가중치에 따라 오름차순으로 정렬
    edges.sort(key=lambda x: x[0]) # (weight, u, v)

    # 2. 서로소 집합 초기화
    parent = [i for i in range(vertices)]
    rank = [0] * vertices # 트리의 높이를 저장

    edge_count = 0
    for weight, u, v in edges:
        if edge_count == vertices - 1: # MST는 N-1개의 간선을 가짐
            break

        # 3. 간선을 추가했을 때 사이클이 생기는지 확인
        if union(parent, rank, u, v):
            mst_edges.append((u, v, weight))
            total_cost += weight
            edge_count += 1
            
    return mst_edges, total_cost

# 그래프 예시: (가중치, 정점1, 정점2)
# 0 --1-- 1
# | \    / |
# 3  \  /  5
# |   2    |
# 2 --4-- 3
edges_kruskal = [
    (1, 0, 1), # (weight, u, v)
    (3, 0, 2),
    (2, 1, 2),
    (5, 1, 3),
    (4, 2, 3),
]
num_vertices_kruskal = 4

mst_kruskal_edges, mst_kruskal_cost = kruskal(num_vertices_kruskal, edges_kruskal)
print("크루스칼 알고리즘 결과:")
for u, v, w in mst_kruskal_edges:
    print(f"  간선: {u}-{v}, 가중치: {w}")
print(f"총 MST 비용: {mst_kruskal_cost}")
```

**실행 결과:**
```
크루스칼 알고리즘 결과:
  간선: 0-1, 가중치: 1
  간선: 1-2, 가중치: 2
  간선: 0-2, 가중치: 3  (만약 0-1과 1-2를 선택했다면 0-2를 추가하면 0-1-2-0 사이클이 생기므로 선택되지 않음)
  간선: 2-3, 가중치: 4
총 MST 비용: 7
```
(위 예시에서 `0-2`는 0-1, 1-2로 인해 이미 0과 2가 연결되어 있는 상태라서 선택되지 않습니다. 올바른 결과는 1(0-1) + 2(1-2) + 4(2-3) = 7입니다. 코드 실행 결과는 이미 `union` 함수가 잘 작동했음을 보여줍니다.)

## 3. 프림(Prim) 알고리즘

프림 알고리즘은 **정점 중심**으로 MST를 구성하는 방식입니다. "하나의 정점에서 시작하여 MST를 점차 확장해나가는" 방식이죠. 다익스트라 알고리즘과도 유사한 부분이 많습니다.

### 동작 원리

1.  그래프의 임의의 한 정점을 선택하여 MST에 포함시킵니다.
2.  MST에 포함된 정점과 MST에 아직 포함되지 않은 정점들을 연결하는 간선들 중에서, 가중치가 가장 작은 간선을 찾습니다. (이때, 여러 간선이 나올 수 있는데, 최소 가중치 간선만 선택합니다.)
3.  찾은 간선을 MST에 추가하고, 이 간선이 연결하는 새로운 정점을 MST에 포함시킵니다.
4.  모든 정점이 MST에 포함될 때까지 2~3번 과정을 반복합니다.

### 핵심 아이디어: 우선순위 큐(Priority Queue)

프림 알고리즘에서는 "현재 MST에 연결된 정점들에서 뻗어나가는 간선 중 가장 가중치가 작은 것"을 효율적으로 찾아야 합니다. 이를 위해 **우선순위 큐(Priority Queue)** 자료구조가 사용됩니다. 우선순위 큐는 가장 우선순위가 높은(여기서는 가중치가 가장 작은) 원소를 가장 먼저 꺼낼 수 있게 해줍니다. 파이썬에서는 `heapq` 모듈을 사용하면 됩니다.

### 파이썬 코드 예제 (프림)

```python
import heapq

def prim(num_vertices, graph):
    mst_edges = []
    total_cost = 0
    
    # MST에 포함된 정점들을 추적하는 배열
    visited = [False] * num_vertices
    
    # 우선순위 큐: (가중치, 현재 정점, 이전 정점)
    # 시작 정점 (여기서는 0번 정점)에서 시작하며, 이전 정점은 -1로 설정
    min_heap = [(0, 0, -1)] # (weight, current_vertex, parent_vertex)

    while min_heap and len(mst_edges) < num_vertices - 1:
        weight, current_v, parent_v = heapq.heappop(min_heap)

        if visited[current_v]:
            continue

        visited[current_v] = True
        if parent_v != -1: # 시작 정점이 아닌 경우에만 MST에 추가
            mst_edges.append((parent_v, current_v, weight))
            total_cost += weight

        # 현재 정점과 연결된 모든 간선을 우선순위 큐에 추가
        # (아직 MST에 포함되지 않은 정점으로 향하는 간선만)
        for neighbor_w, neighbor_v in graph[current_v]:
            if not visited[neighbor_v]:
                heapq.heappush(min_heap, (neighbor_w, neighbor_v, current_v))
                
    return mst_edges, total_cost

# 그래프 예시 (인접 리스트): {정점: [(가중치, 이웃정점), ...]}
# 0 --1-- 1
# | \    / |
# 3  \  /  5
# |   2    |
# 2 --4-- 3
graph_prim = {
    0: [(1, 1), (3, 2)],
    1: [(1, 0), (2, 2), (5, 3)],
    2: [(3, 0), (2, 1), (4, 3)],
    3: [(5, 1), (4, 2)]
}
num_vertices_prim = 4

mst_prim_edges, mst_prim_cost = prim(num_vertices_prim, graph_prim)
print("\n프림 알고리즘 결과:")
for u, v, w in mst_prim_edges:
    print(f"  간선: {u}-{v}, 가중치: {w}")
print(f"총 MST 비용: {mst_prim_cost}")
```

**실행 결과:**
```
프림 알고리즘 결과:
  간선: 0-1, 가중치: 1
  간선: 1-2, 가중치: 2
  간선: 2-3, 가중치: 4
총 MST 비용: 7
```

## 4. 크루스칼 vs 프림: 어떤 알고리즘을 사용해야 할까요?

두 알고리즘 모두 MST를 찾아주지만, 각각의 장단점이 있어 그래프의 특성에 따라 더 효율적인 알고리즘이 달라질 수 있습니다.

*   **크루스칼 (Kruskal):**
    *   **간선 중심**: 모든 간선을 정렬해야 하므로, 간선의 개수가 적은 **희소 그래프(Sparse Graph)**에 유리합니다.
    *   구현이 직관적이고 이해하기 쉽습니다.
    *   서로소 집합 자료구조를 사용하여 사이클을 효과적으로 방지합니다.

*   **프림 (Prim):**
    *   **정점 중심**: 현재 MST에 연결된 정점들에서 뻗어나가는 간선들만 고려하므로, 간선의 개수가 많은 **밀집 그래프(Dense Graph)**에 유리합니다.
    *   시작 정점을 기준으로 MST를 점진적으로 확장해나갑니다.
    *   우선순위 큐를 사용하여 가장 가까운 간선을 효율적으로 찾습니다.

일반적으로, `E`를 간선의 수, `V`를 정점의 수라고 할 때:
*   크루스칼의 시간 복잡도: `O(E log E)` (간선 정렬 + DSU 연산)
*   프림의 시간 복잡도: `O(E log V)` (PQ 사용 시) 또는 `O(V^2)` (배열 사용 시)

따라서 `E`가 `V^2`에 가까운 밀집 그래프에서는 프림이 유리하고, `E`가 `V`에 가까운 희소 그래프에서는 크루스칼이 유리하다고 볼 수 있습니다.

## 마무리하며

오늘은 네트워크 최적화, 회로 설계, 클러스터링 등 다양한 분야에서 활용되는 **최소 신장 트리(MST)**의 개념과 이를 구하는 대표적인 두 알고리즘, **크루스칼**과 **프림**에 대해 알아보았습니다. 두 알고리즘 모두 탐욕적인(Greedy) 방식으로 최적의 해를 찾아내지만, 간선 중심과 정점 중심이라는 접근 방식의 차이가 있음을 확인했죠.
