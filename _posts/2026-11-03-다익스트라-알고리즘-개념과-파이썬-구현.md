# 미로를 탈출하는 가장 빠른 길: 다익스트라 알고리즘 파이썬으로 정복하기

안녕하세요, 여러분! 개발 블로그 작가 **코드 탐험가**입니다. 오늘은 컴퓨터 과학의 꽃이라고 할 수 있는 '알고리즘' 중에서도 실생활에서 정말 많이 활용되는 **최단 경로(Shortest Path)** 문제 해결의 대명사, 바로 **다익스트라(Dijkstra) 알고리즘**에 대해 이야기해보려 합니다.

내비게이션 앱이 최단 경로를 찾아주고, 네트워크 라우터가 가장 효율적인 데이터 전송 경로를 결정할 때, 그 뒤에는 다익스트라 알고리즘 같은 최단 경로 알고리즘이 숨어있습니다. 언뜻 복잡해 보일 수 있지만, 차근차근 개념을 이해하고 파이썬으로 직접 구현해보면 "아, 이런 원리였구나!" 하고 무릎을 탁 치게 되실 거예요. 초보 개발자분들도 쉽게 따라오실 수 있도록 친절하게 설명해 드릴 테니, 함께 떠나볼까요?

---

## 1. 다익스트라 알고리즘, 왜 필요할까요? (문제 정의)

우리가 다루는 세상은 복잡한 연결망으로 이루어져 있습니다. 친구 관계, 도로망, 인터넷 네트워크 등 모두 노드(점)와 간선(선)으로 표현되는 **그래프(Graph)** 구조를 가집니다.

*   **노드(Node) 또는 정점(Vertex):** 지점, 사람, 서버 등 그래프의 구성 요소.
*   **간선(Edge):** 노드들을 연결하는 선. 간선은 방향을 가질 수도 있고(단방향), 가지지 않을 수도 있습니다(양방향).
*   **가중치(Weight):** 간선에 부여된 값. 예를 들어, 도로망에서는 거리나 시간, 네트워크에서는 전송 비용 등이 가중치가 됩니다.

다익스트라 알고리즘은 이렇게 가중치가 있는 그래프에서 **특정 시작 노드로부터 다른 모든 노드까지의 최단 경로**를 찾는 알고리즘입니다. 여기서 중요한 조건은 **가중치가 음수가 아니어야 한다**는 점입니다. (음수 가중치를 처리하는 알고리즘은 벨만-포드(Bellman-Ford) 같은 다른 알고리즘이 사용됩니다.)

---

## 2. 다익스트라 알고리즘의 핵심 개념 (직관적 이해)

다익스트라 알고리즘은 마치 미로 속에서 물이 퍼져나가는 모습, 혹은 풍선이 부풀어 오르는 모습과 비슷합니다. 시작 지점에서부터 가장 가까운 곳부터 하나씩 "최단 거리가 확정된" 노드를 찾아나가며, 그 주변 노드들의 거리를 갱신하는 방식입니다.

이 알고리즘은 **그리디(Greedy) 알고리즘**의 한 종류입니다. 매 순간 "지금까지 발견된 경로 중 가장 짧은 경로"를 택하는 탐욕적인 선택을 합니다. 이 선택이 최종적으로도 최적임을 보장하는 것이 바로 다익스트라의 힘이죠.

핵심 요소를 살펴볼까요?

1.  **`distances` (최단 거리 저장):** 각 노드까지의 최단 거리를 저장하는 딕셔너리(또는 배열)입니다. 처음에는 시작 노드만 0이고, 나머지는 무한대(`float('inf')`)로 초기화합니다.
2.  **`priority_queue` (우선순위 큐):** 다음으로 탐색할 노드들을 저장하는 큐입니다. 이 큐는 **가장 짧은 거리를 가진 노드를 우선적으로** 뽑아낼 수 있도록 구현됩니다. 파이썬에서는 `heapq` 모듈을 사용하여 힙(Heap) 자료구조로 구현할 수 있습니다.

### 작동 방식 요약:

1.  시작 노드의 거리는 0, 나머지 노드는 무한대로 설정합니다.
2.  (거리, 노드) 형태의 튜플을 우선순위 큐에 추가합니다. (시작 노드의 경우 (0, 시작 노드))
3.  우선순위 큐가 빌 때까지 다음을 반복합니다:
    *   큐에서 **가장 거리가 짧은 노드(current_node)**를 꺼냅니다.
    *   만약 꺼낸 노드의 거리가 이미 `distances`에 저장된 거리보다 길다면, 이 경로는 최단 경로가 아니므로 무시합니다. (이 노드는 이미 더 짧은 경로로 처리되었음을 의미)
    *   `current_node`의 모든 이웃 노드들을 살펴봅니다.
    *   `current_node`를 거쳐 이웃 노드로 가는 새로운 경로(`current_node`까지의 거리 + 간선 가중치)를 계산합니다.
    *   만약 이 새로운 경로가 기존에 `distances`에 저장된 이웃 노드까지의 거리보다 짧다면, `distances`를 갱신하고 **(새로운 거리, 이웃 노드)**를 우선순위 큐에 추가합니다.

## 3. 파이썬으로 다익스트라 알고리즘 구현하기

이제 위에서 설명한 개념을 파이썬 코드로 옮겨보겠습니다. `heapq` 모듈을 사용하여 우선순위 큐를 구현하는 것이 핵심입니다.

```python
import heapq

def dijkstra(graph, start):
    # 1. 거리 정보 초기화
    # 모든 노드에 대한 최단 거리를 무한대로 설정합니다.
    # 시작 노드의 거리는 0으로 설정합니다.
    distances = {node: float('inf') for node in graph}
    distances[start] = 0

    # 2. 우선순위 큐 초기화
    # (거리, 노드) 튜플을 원소로 가집니다.
    # 힙(heap)은 가장 작은 원소를 가장 먼저 뽑아냅니다.
    priority_queue = [(0, start)] # (거리, 시작 노드)

    while priority_queue:
        # 3. 우선순위 큐에서 가장 거리가 짧은 노드를 꺼냅니다.
        current_distance, current_node = heapq.heappop(priority_queue)

        # 4. 이미 처리된 노드이거나, 더 짧은 경로를 찾은 경우 무시
        # 현재 꺼낸 거리가 이미 distances에 기록된 거리보다 길다면,
        # 이는 이미 더 짧은 경로로 해당 노드에 도달했음을 의미합니다.
        # 따라서 이 경로는 더 이상 탐색할 필요가 없습니다.
        if current_distance > distances[current_node]:
            continue

        # 5. 현재 노드의 인접 노드들을 탐색합니다.
        for neighbor, weight in graph[current_node].items():
            # 현재 노드를 거쳐 인접 노드로 가는 새로운 경로의 거리를 계산합니다.
            new_distance = current_distance + weight

            # 6. 새로운 경로가 기존 경로보다 짧으면 거리 갱신 및 큐에 추가
            if new_distance < distances[neighbor]:
                distances[neighbor] = new_distance
                heapq.heappush(priority_queue, (new_distance, neighbor))
    
    return distances

# --- 사용 예시 ---
# 그래프 정의: 인접 리스트(딕셔너리) 형태로 표현
# 'A': {'B': 1, 'C': 4} -> A에서 B까지 거리는 1, A에서 C까지 거리는 4
graph = {
    'A': {'B': 1, 'C': 4},
    'B': {'A': 1, 'C': 2, 'D': 5},
    'C': {'A': 4, 'B': 2, 'D': 1},
    'D': {'B': 5, 'C': 1, 'E': 3},
    'E': {'D': 3}
}

start_node = 'A'
shortest_paths = dijkstra(graph, start_node)

print(f"'{start_node}'로부터의 최단 경로:")
for node, distance in shortest_paths.items():
    print(f"  '{node}': {distance}")

# 예상 출력:
# 'A'로부터의 최단 경로:
#   'A': 0
#   'B': 1
#   'C': 3 (A->B->C)
#   'D': 4 (A->B->C->D)
#   'E': 7 (A->B->C->D->E)
```

## 4. 코드 설명 자세히 들여다보기

1.  **`import heapq`**: 파이썬의 `heapq` 모듈은 리스트를 힙처럼 동작하도록 만들어줍니다. `heapq.heappush()`는 원소를 힙에 추가하고, `heapq.heappop()`은 힙에서 가장 작은 원소를 제거하고 반환합니다.
2.  **`distances = {node: float('inf') for node in graph}`**: `graph` 딕셔너리의 키(노드 이름)를 사용하여 모든 노드를 순회하고, 각 노드까지의 거리를 `float('inf')` (무한대)로 초기화합니다. `float('inf')`는 어떤 숫자보다도 큰 값을 의미합니다.
3.  **`distances[start] = 0`**: 시작 노드 자신까지의 거리는 0입니다.
4.  **`priority_queue = [(0, start)]`**: 우선순위 큐에 시작 노드를 추가합니다. 튜플 `(거리, 노드)` 형태로 저장하는데, `heapq`는 튜플의 첫 번째 요소를 기준으로 우선순위를 판단하기 때문에 거리를 먼저 넣습니다.
5.  **`while priority_queue:`**: 큐가 비어있지 않은 동안 반복합니다. 즉, 아직 탐색할 노드가 남아있으면 계속 진행합니다.
6.  **`current_distance, current_node = heapq.heappop(priority_queue)`**: 큐에서 현재까지 발견된 노드 중 `start` 노드로부터 가장 짧은 거리에 있는 노드를 꺼냅니다.
7.  **`if current_distance > distances[current_node]: continue`**: 이 조건문은 매우 중요합니다! 우선순위 큐에는 같은 노드에 대한 여러 경로가 들어갈 수 있습니다. 예를 들어, A->B->C와 A->X->C 경로가 모두 큐에 들어갈 수 있는데, 이때 A->X->C 경로가 먼저 큐에서 나왔지만 이미 A->B->C가 더 짧은 경로로 `distances`가 갱신되어 있다면, A->X->C 경로는 무시해도 됩니다. 이미 더 짧은 경로가 확정되었기 때문이죠.
8.  **`for neighbor, weight in graph[current_node].items():`**: 현재 노드에 연결된 모든 이웃 노드를 순회합니다.
9.  **`new_distance = current_distance + weight`**: 현재 노드를 거쳐 이웃 노드까지 가는 새로운 총 거리를 계산합니다.
10. **`if new_distance < distances[neighbor]:`**: 만약 새로 계산된 `new_distance`가 기존에 `distances`에 저장되어 있던 `neighbor`까지의 거리보다 짧다면, `distances`를 갱신하고 이 새로운 경로를 우선순위 큐에 추가합니다. 이렇게 하면 나중에 이 이웃 노드를 최단 거리로 다시 탐색할 수 있게 됩니다.

## 5. 다익스트라 알고리즘의 제한과 중요성

앞서 잠깐 언급했듯이, 다익스트라 알고리즘은 간선의 가중치가 **음수가 아니어야** 올바른 결과를 보장합니다. 만약 음수 가중치가 있다면, 이미 최단 거리로 확정했다고 생각했던 노드도 음수 가중치 간선을 통해 더 짧은 경로가 생길 수 있기 때문에 그리디 방식이 깨지게 됩니다. 이런 경우에는 **벨만-포드(Bellman-Ford) 알고리즘**을 사용해야 합니다.

하지만 대부분의 실생활 최단 경로 문제는 거리, 시간, 비용 등 양수의 가중치를 가지므로, 다익스트라 알고리즘은 광범위하게 사용됩니다. 그 효율성 덕분에 네트워크 라우팅, 지도 앱의 길 찾기, 게임 인공지능 등 다양한 분야에서 없어서는 안 될 중요한 알고리즘으로 자리매김하고 있습니다.
