# Word2Vec, 단어를 숫자로! 자연어 처리의 마법을 파헤치다

안녕하세요! 개발 블로그 독자 여러분. 오늘은 자연어 처리(NLP) 분야의 혁명적인 기술 중 하나인 **Word2Vec**에 대해 이야기해보려 합니다. 컴퓨터는 텍스트를 직접 이해하지 못하기 때문에, 우리가 일상적으로 사용하는 단어들을 컴퓨터가 알아들을 수 있는 형태로 변환하는 과정이 필수적인데요. Word2Vec은 이 과정을 마법처럼 수행해주는 놀라운 도구입니다.

초보자분들도 쉽게 이해할 수 있도록, Word2Vec의 개념부터 실제 코드를 통한 활용까지 차근차근 살펴보겠습니다. 자, 그럼 단어를 숫자의 세계로 여행 보내는 Word2Vec의 비밀을 함께 파헤쳐 볼까요?

## 1. 왜 Word2Vec이 필요할까요? - 단어의 표현 방식

컴퓨터에게 단어를 이해시키는 가장 기본적인 방법 중 하나는 **원-핫 인코딩(One-Hot Encoding)**입니다. 예를 들어, 우리에게 '사과', '바나나', '딸기' 세 단어가 있다면,
- 사과: `[1, 0, 0]`
- 바나나: `[0, 1, 0]`
- 딸기: `[0, 0, 1]`
과 같이 표현하는 방식이죠.

하지만 이 방식에는 치명적인 단점이 있습니다.
1.  **희소성(Sparsity)**: 단어가 많아질수록 벡터의 차원도 늘어나 대부분이 0으로 채워진 거대한 벡터가 됩니다. 이는 메모리 낭비와 계산 효율 저하를 초래합니다.
2.  **의미 미반영**: '사과'와 '딸기'는 둘 다 과일이라는 공통점이 있지만, 원-핫 인코딩 벡터는 이들 사이의 유사성을 전혀 나타내지 못합니다. 모든 단어는 서로 완전히 독립적인 존재로 간주됩니다.

우리는 '사과'와 '배'가 '자동차'보다는 훨씬 더 유사한 단어라고 생각합니다. Word2Vec은 이러한 단어 간의 **의미적, 문법적 유사성**을 숫자로 표현해주는 기술입니다.

## 2. Word2Vec이란 무엇일까요? - 단어 임베딩의 마법

Word2Vec은 "단어의 의미는 주변 단어에 의해 결정된다"는 아이디어에서 출발합니다. 예를 들어 "고양이가 **담장** 위에 앉아 있다"와 "새가 **담장** 위에 앉아 있다"라는 문장에서 '담장'이라는 단어는 유사한 맥락에서 사용되었으므로, 두 문장의 '담장'은 비슷한 의미를 가진다고 추론할 수 있습니다.

Word2Vec은 이 아이디어를 바탕으로 단어를 밀집된(dense), 저차원(low-dimensional)의 **벡터(vector)**로 변환합니다. 이 벡터를 **단어 임베딩(Word Embedding)**이라고 부릅니다. 각 단어는 수십~수백 차원의 실수 벡터로 표현되며, 의미적으로 유사한 단어들은 벡터 공간에서 서로 가까운 거리에 위치하게 됩니다. 마치 지리적인 지도를 펼쳤을 때, 가까운 도시들이 실제 지리상으로도 가까운 것처럼 말이죠!

Word2Vec 모델은 크게 두 가지 방식이 있습니다.

1.  **CBOW (Continuous Bag of Words)**: 주변 단어들을 이용해 특정 단어를 예측합니다. 예를 들어, "나는 [ ]를 먹었다"라는 문장에서 주변 단어('나는', '먹었다')를 보고 빈칸에 들어갈 단어('사과')를 예측하는 방식입니다.
2.  **Skip-gram**: 특정 단어를 이용해 주변 단어들을 예측합니다. 예를 들어, '사과'라는 단어를 보고 주변에 '나는', '먹었다'와 같은 단어들이 나올 것이라고 예측하는 방식입니다. 일반적으로 Skip-gram이 희귀 단어를 더 잘 처리하고 성능이 좋은 경향이 있어 많이 사용됩니다.

두 모델 모두 결국 단어와 주변 단어 간의 관계를 학습하여 단어 임베딩을 만들어냅니다. 이렇게 학습된 단어 벡터는 놀라운 특징을 가집니다. 예를 들어,
`vec(왕) - vec(남자) + vec(여자) ≈ vec(여왕)`
과 같은 관계가 성립하기도 합니다. 단어들 사이의 의미론적, 문법적 연산을 수행할 수 있게 되는 것이죠!

## 3. Word2Vec 활용 예제 - `gensim` 라이브러리

파이썬에서 Word2Vec을 가장 쉽게 사용할 수 있는 라이브러리 중 하나는 `gensim`입니다. 간단한 예제를 통해 Word2Vec 모델을 학습하고 활용하는 방법을 살펴보겠습니다.

먼저, `gensim` 라이브러리가 설치되어 있지 않다면 아래 명령어로 설치해주세요.
```bash
pip install gensim
```

이제 코드를 작성해 보겠습니다.

```python
from gensim.models import Word2Vec
from konlpy.tag import Okt # 한글 텍스트 처리를 위한 형태소 분석기

# 1. 샘플 텍스트 데이터 준비 (한국어 예제)
# 이 문장들을 통해 단어들의 관계를 학습할 것입니다.
corpus = [
    "나는 사과를 좋아한다",
    "사과는 맛있고 건강에 좋다",
    "바나나도 과일이다",
    "나는 바나나를 매일 먹는다",
    "강아지가 공원에서 뛰어놀고 있다",
    "고양이는 강아지보다 조용하다",
    "사람은 동물과 함께 산다",
    "왕이 나라를 다스린다",
    "여왕은 왕과 함께 나라를 다스린다",
    "남자는 일을 한다",
    "여자는 남자를 돕는다"
]

# 2. 텍스트 전처리: 형태소 분석 및 토큰화
# Word2Vec은 단어 단위로 학습하므로, 문장을 단어 리스트로 분리해야 합니다.
# 한국어는 띄어쓰기만으로는 단어 구분이 어렵기 때문에 형태소 분석기가 필요합니다.
okt = Okt()
tokenized_data = []
for sentence in corpus:
    # 형태소 분석을 통해 명사, 동사 등을 추출하고 불필요한 태그 제거
    # 여기서는 간단하게 모든 형태소를 단어로 사용합니다.
    tokenized_sentence = okt.morphs(sentence)
    tokenized_data.append(tokenized_sentence)

print("토큰화된 데이터:")
for tokens in tokenized_data:
    print(tokens)
print("-" * 30)

# 3. Word2Vec 모델 학습
# parameters:
#   sentences: 학습할 문장 리스트 (각 문장은 단어 리스트여야 함)
#   vector_size: 임베딩 벡터의 차원 (단어를 표현할 숫자의 개수)
#   window: 주변 단어를 고려할 범위
#   min_count: 학습에 사용할 단어의 최소 빈도 (너무 적게 등장하는 단어는 무시)
#   sg: 0이면 CBOW, 1이면 Skip-gram (여기서는 Skip-gram 사용)
#   epochs: 학습 반복 횟수
model = Word2Vec(sentences=tokenized_data, vector_size=100, window=5, min_count=1, sg=1, epochs=100)

# 4. 학습된 모델 활용
print("모델 학습 완료!")
print("-" * 30)

# 4-1. 특정 단어의 임베딩 벡터 확인
print("사과 단어의 벡터 (첫 5개 요소):")
print(model.wv['사과'][:5])
print("-" * 30)

# 4-2. 가장 유사한 단어 찾기
print("'사과'와 가장 유사한 단어들:")
print(model.wv.most_similar('사과'))
print("-" * 30)

print("'왕'과 가장 유사한 단어들:")
print(model.wv.most_similar('왕'))
print("-" * 30)

# 4-3. 단어 벡터 연산 (예: 왕 - 남자 + 여자 = 여왕)
# 모델이 작은 데이터셋으로 학습되었기 때문에 완벽한 결과를 기대하기는 어렵지만,
# 이런 방식으로 단어 간의 관계를 추론할 수 있다는 것을 보여줍니다.
try:
    vector_king = model.wv['왕']
    vector_man = model.wv['남자']
    vector_woman = model.wv['여자']

    # '왕' - '남자' + '여자' 연산
    result_vector = vector_king - vector_man + vector_woman
    print("vec(왕) - vec(남자) + vec(여자) 결과와 가장 유사한 단어들:")
    print(model.wv.most_similar(positive=[result_vector], topn=3))
except KeyError as e:
    print(f"오류: '{e.args[0]}' 단어가 모델에 없습니다. 단어 리스트를 확인해주세요.")
```

**코드 설명:**

1.  **데이터 준비**: Word2Vec 모델을 학습시키기 위한 문장들을 리스트 형태로 준비합니다.
2.  **전처리 (토큰화)**: `konlpy` 라이브러리의 `Okt` 형태소 분석기를 사용하여 문장을 단어 단위로 쪼갭니다. 한국어는 '나는 사과를'과 같이 조사가 붙는 경우가 많아 단순 띄어쓰기로는 단어를 분리하기 어렵기 때문에 형태소 분석이 필수적입니다.
3.  **모델 학습**: `Word2Vec` 클래스의 인스턴스를 생성하고, `sentences` 인자에 토큰화된 데이터를 전달하여 학습을 시작합니다. `vector_size`는 각 단어를 몇 차원의 벡터로 표현할지, `window`는 주변 몇 개의 단어를 볼 것인지, `sg=1`은 Skip-gram 모델을 사용하겠다는 의미입니다.
4.  **모델 활용**:
    *   `model.wv['단어']`를 통해 특정 단어의 임베딩 벡터를 얻을 수 있습니다.
    *   `model.wv.most_similar('단어')`를 사용하면 입력 단어와 의미적으로 가장 유사한 단어들을 찾아줍니다.
    *   `model.wv.most_similar(positive=[vec1, vec2], negative=[vec3])`와 같이 벡터를 직접 전달하여 단어 간의 연산을 수행하고 그 결과와 가장 유사한 단어를 찾을 수도 있습니다. 예제에서는 '왕 - 남자 + 여자' 연산을 통해 '여왕'과 유사한 단어를 찾는 과정을 시도합니다. (데이터셋이 작을수록 완벽한 결과는 어려울 수 있습니다.)

## 4. Word2Vec의 활용 분야

Word2Vec으로 생성된 단어 임베딩은 다양한 자연어 처리 문제 해결에 활용됩니다.
*   **텍스트 유사도 측정**: 두 텍스트의 유사성을 계산하여 추천 시스템, 검색 엔진 등에 활용.
*   **정보 검색 및 추천 시스템**: 사용자가 검색한 키워드와 의미적으로 유사한 문서를 찾아주거나, 사용자가 본 상품과 유사한 상품을 추천.
*   **감성 분석**: 단어의 긍정/부정 감성을 벡터 공간에서 파악하여 텍스트의 전반적인 감성을 분석.
*   **기계 번역**: 서로 다른 언어 간의 단어 유사성을 학습하여 번역 품질 향상.
*   **챗봇 및 질의응답**: 사용자의 질문 의도를 파악하고 적절한 답변을 생성하는 데 기여.
