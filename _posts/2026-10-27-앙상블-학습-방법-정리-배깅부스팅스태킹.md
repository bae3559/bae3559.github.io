# 머신러닝 성능을 최대로! 앙상블 학습의 모든 것 (배깅, 부스팅, 스태킹)

안녕하세요, 개발자 여러분! 여러분의 머신러닝 모델이 더 똑똑하고 강력해지기를 바라시나요? 그렇다면 오늘 다룰 '앙상블 학습(Ensemble Learning)'에 주목해주세요. 앙상블 학습은 단 하나의 모델로는 달성하기 어려운 뛰어난 성능을 여러 모델의 조합을 통해 이끌어내는 강력한 기법입니다. 마치 여러 전문가의 의견을 종합하여 최종 결정을 내리는 것과 같죠!

이번 글에서는 앙상블 학습의 핵심 개념부터 가장 대표적인 세 가지 방법인 배깅(Bagging), 부스팅(Boosting), 스태킹(Stacking)까지, 초보자도 이해하기 쉽게 설명하고 간단한 파이썬 코드 예제와 함께 살펴보겠습니다. 자, 그럼 시작해볼까요?

## 앙상블 학습이란?

앙상블 학습은 여러 개의 약한 학습기(Weak Learner)를 결합하여 하나의 강력한 학습기(Strong Learner)를 만드는 방법입니다. 여기서 '약한 학습기'란 단일 모델(예: 결정 트리, 로지스틱 회귀 등)을 의미하며, 이 모델들은 각각 특정 부분에서 약점을 가질 수 있습니다. 앙상블 학습의 핵심 아이디어는 이 모델들의 약점을 서로 보완하고, 강점을 결합하여 전체적인 예측 성능을 향상시키는 것입니다.

주요 목표는 다음과 같습니다:
*   **편향(Bias) 감소:** 모델이 데이터의 패턴을 제대로 학습하지 못하는 경향을 줄입니다.
*   **분산(Variance) 감소:** 모델이 훈련 데이터의 작은 변화에도 크게 영향을 받는 경향을 줄입니다. (과적합 방지)
*   **예측 정확도 향상:** 전반적인 모델의 성능을 높입니다.

이러한 목표를 달성하기 위해 앙상블 학습은 크게 병렬 방식과 순차 방식으로 나뉘며, 이제 각각의 대표적인 기법들을 자세히 알아보겠습니다.

---

## 1. 배깅 (Bagging: Bootstrap Aggregating)

배깅은 **병렬(Parallel)** 방식으로 여러 모델을 학습시키는 대표적인 앙상블 기법입니다. 'Bootstrap Aggregating'의 줄임말로, 데이터셋에서 **부트스트랩(Bootstrap)** 샘플링을 통해 여러 개의 서브셋을 만들고, 각 서브셋으로 독립적인 모델을 학습시킨 후, 이 모델들의 예측을 **집계(Aggregating)**하여 최종 예측을 수행합니다.

**작동 방식:**
1.  **부트스트랩 샘플링:** 원본 데이터셋에서 중복을 허용하여 여러 개의 샘플셋을 만듭니다. 각 샘플셋은 원본 데이터셋과 동일한 크기를 가집니다.
2.  **개별 모델 학습:** 각 샘플셋으로 독립적인 학습기(보통 결정 트리)를 학습시킵니다.
3.  **예측 집계:** 회귀 문제의 경우 각 모델의 예측값들을 평균하여 최종 예측값을 얻고, 분류 문제의 경우 다수결 투표(Majority Voting)를 통해 최종 클래스를 결정합니다.

**특징:**
*   **분산 감소 효과:** 다양한 데이터 샘플로 학습된 모델들의 예측을 종합함으로써 모델의 과적합을 줄이고 예측의 안정성을 높입니다.
*   가장 대표적인 배깅 알고리즘은 `랜덤 포레스트(Random Forest)`입니다.

**코드 예제 (BaggingClassifier):**

```python
import numpy as np
from sklearn.datasets import make_classification
from sklearn.tree import DecisionTreeClassifier
from sklearn.ensemble import BaggingClassifier
from sklearn.model_selection import train_test_split
from sklearn.metrics import accuracy_score

# 1. 예제 데이터 생성
# 200개의 샘플, 20개의 특성, 2개의 클래스를 가진 분류 데이터 생성
X, y = make_classification(n_samples=200, n_features=20, n_informative=10, n_redundant=10,
                           random_state=42, n_clusters_per_class=1)

# 훈련 세트와 테스트 세트 분리
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

print(f"훈련 데이터 크기: {X_train.shape}")
print(f"테스트 데이터 크기: {X_test.shape}\n")

# 2. 배깅 분류기 모델 생성 및 학습
# 기본 학습기로 결정 트리를 사용하고, 10개의 결정 트리를 앙상블합니다.
base_estimator = DecisionTreeClassifier(random_state=42)
bagging_model = BaggingClassifier(base_estimator=base_estimator,
                                  n_estimators=10, # 10개의 기본 모델 사용
                                  random_state=42,
                                  n_jobs=-1) # 모든 CPU 코어 사용 (병렬 처리)

bagging_model.fit(X_train, y_train)

# 3. 예측 및 평가
y_pred = bagging_model.predict(X_test)
accuracy = accuracy_score(y_test, y_pred)

print(f"Bagging 분류기의 정확도: {accuracy:.4f}")

# 단일 결정 트리 모델과 비교 (성능 향상 확인)
single_tree_model = DecisionTreeClassifier(random_state=42)
single_tree_model.fit(X_train, y_train)
single_tree_pred = single_tree_model.predict(X_test)
single_tree_accuracy = accuracy_score(y_test, single_tree_pred)
print(f"단일 결정 트리의 정확도: {single_tree_accuracy:.4f}")
```
위 코드를 실행해보시면, 단일 결정 트리보다 `BaggingClassifier`가 더 높은 정확도를 보이는 것을 확인할 수 있습니다. 이는 여러 모델의 예측을 종합하여 분산을 줄이고 안정적인 성능을 확보했기 때문입니다.

## 2. 부스팅 (Boosting)

부스팅은 **순차적(Sequential)** 방식으로 모델을 학습시키는 앙상블 기법입니다. 배깅과 달리, 부스팅은 이전 모델이 **잘못 예측한 데이터**에 더 가중치를 부여하거나, 이전 모델의 예측 오류를 보완하는 방향으로 다음 모델을 학습시킵니다. 즉, '실수를 통해 배우는' 방식입니다.

**작동 방식:**
1.  **초기 모델 학습:** 첫 번째 모델을 전체 데이터셋으로 학습시킵니다.
2.  **오류 가중치 부여:** 첫 번째 모델이 잘못 예측한 데이터에 더 높은 가중치를 부여하거나, 오류 자체를 예측하도록 다음 모델의 목표를 설정합니다.
3.  **다음 모델 학습:** 가중치가 부여된 데이터 또는 오류 정보를 사용하여 다음 모델을 학습시킵니다.
4.  **반복:** 이 과정을 정해진 횟수만큼 반복하며, 각 모델은 이전 모델의 약점을 보완하도록 학습됩니다.
5.  **최종 예측:** 모든 모델의 예측 결과를 가중 평균하여 최종 예측값을 얻습니다.

**특징:**
*   **편향 감소 효과:** 이전 모델의 오류를 지속적으로 보완함으로써 모델의 편향을 줄이고 복잡한 패턴을 학습하는 능력이 뛰어납니다.
*   **과적합 위험:** 순차적으로 오류를 보완하는 과정에서 자칫 과적합될 위험도 있습니다.
*   대표적인 알고리즘으로 `AdaBoost`, `Gradient Boosting Machine (GBM)`, `XGBoost`, `LightGBM`, `CatBoost` 등이 있습니다. 특히 XGBoost 등은 캐글(Kaggle) 같은 데이터 과학 대회에서 많이 사용될 정도로 강력한 성능을 자랑합니다.

**코드 예제 (GradientBoostingClassifier):**

```python
from sklearn.ensemble import GradientBoostingClassifier

# X_train, y_train, X_test, y_test는 위에서 생성한 데이터를 그대로 사용

# 1. 그래디언트 부스팅 분류기 모델 생성 및 학습
# n_estimators: 부스팅 단계 수 (생성할 기본 모델의 수)
# learning_rate: 각 단계에서 이전 모델의 오류를 얼마나 강하게 보정할지 (작을수록 신중하게 학습)
gradient_boosting_model = GradientBoostingClassifier(n_estimators=100,
                                                   learning_rate=0.1,
                                                   random_state=42)

gradient_boosting_model.fit(X_train, y_train)

# 2. 예측 및 평가
y_pred_gb = gradient_boosting_model.predict(X_test)
accuracy_gb = accuracy_score(y_test, y_pred_gb)

print(f"Gradient Boosting 분류기의 정확도: {accuracy_gb:.4f}")
```
부스팅 계열 모델은 일반적으로 높은 성능을 보여주며, 적절한 하이퍼파라미터 튜닝을 통해 더욱 강력해질 수 있습니다.

## 3. 스태킹 (Stacking: Stacked Generalization)

스태킹은 앞서 살펴본 배깅이나 부스팅보다 한 단계 더 복잡한 형태의 앙상블 기법입니다. 여러 모델의 예측 결과를 **다른 모델(메타 모델 또는 메타 학습기)**의 입력으로 사용하여 최종 예측을 수행하는 방식입니다. 마치 여러 전문가의 의견을 종합한 후, 그 의견들을 바탕으로 최종 결정을 내리는 '최고 전문가'가 있는 것과 같습니다.

**작동 방식:**
1.  **기본 모델(Base Models) 학습:** 여러 개의 다양한 모델(예: 로지스틱 회귀, SVM, 결정 트리 등)을 훈련 데이터로 학습시킵니다. 이때 각 모델은 서로 다른 알고리즘을 사용하거나, 동일한 알고리즘이라도 다른 하이퍼파라미터를 사용하여 다양성을 확보하는 것이 중요합니다.
2.  **예측 결과 생성:** 각 기본 모델은 검증 세트(또는 교차 검증을 통해 얻은 OOF: Out-Of-Fold 예측)에 대한 예측값을 생성합니다. 이 예측값들이 메타 모델의 새로운 특성(Feature)이 됩니다.
3.  **메타 모델(Meta Model) 학습:** 기본 모델들이 생성한 예측값들을 새로운 입력 데이터로 사용하여 최종 예측을 수행할 메타 모델을 학습시킵니다. (예: 로지스틱 회귀, 랜덤 포레스트 등)
4.  **최종 예측:** 테스트 데이터에 대해 기본 모델들이 예측을 수행하고, 이 예측값을 메타 모델이 받아 최종 예측을 생성합니다.

**특징:**
*   **최고 성능 가능성:** 다양한 모델의 장점을 조합하여 매우 높은 예측 성능을 달성할 수 있습니다.
*   **복잡성 증가:** 모델의 구조가 복잡해지고, 학습 시간이 오래 걸릴 수 있습니다. 또한, 기본 모델들의 예측 결과를 메타 모델에 전달하는 과정이 중요합니다. (과적합 방지를 위해 교차 검증을 통한 OOF 예측 사용 권장)

**코드 예제 (StackingClassifier):**

```python
from sklearn.linear_model import LogisticRegression
from sklearn.neighbors import KNeighborsClassifier
from sklearn.svm import SVC
from sklearn.ensemble import StackingClassifier

# X_train, y_train, X_test, y_test는 위에서 생성한 데이터를 그대로 사용

# 1. 기본 모델(Base Models) 정의
# 서로 다른 알고리즘을 사용하는 것이 스태킹의 효과를 극대화합니다.
estimators = [
    ('lr', LogisticRegression(random_state=42)),
    ('knn', KNeighborsClassifier(n_neighbors=5)),
    ('svc', SVC(probability=True, random_state=42)) # probability=True는 predict_proba()를 위해 필요
]

# 2. 메타 모델(Meta Model) 정의
# 기본 모델들의 예측 결과를 최종적으로 학습할 모델입니다.
final_estimator = RandomForestClassifier(n_estimators=100, random_state=42)

# 3. 스태킹 분류기 모델 생성 및 학습
# cv: 교차 검증 폴드 수 (메타 모델 학습을 위한 예측 데이터 생성에 사용)
stacking_model = StackingClassifier(estimators=estimators,
                                    final_estimator=final_estimator,
                                    cv=5, # 5-fold 교차 검증 사용
                                    n_jobs=-1)

stacking_model.fit(X_train, y_train)

# 4. 예측 및 평가
y_pred_stack = stacking_model.predict(X_test)
accuracy_stack = accuracy_score(y_test, y_pred_stack)

print(f"Stacking 분류기의 정확도: {accuracy_stack:.4f}")
```
스태킹은 여러 모델의 강점을 영리하게 결합하여 가장 최적의 예측을 도출하려는 시도이며, 때로는 다른 어떤 방법보다도 뛰어난 성능을 보여줄 수 있습니다.

## 마무리하며: 언제 어떤 방법을 사용할까?

지금까지 앙상블 학습의 세 가지 주요 기법인 배깅, 부스팅, 스태킹을 살펴보았습니다. 각 방법은 고유한 작동 원리와 장단점을 가지고 있습니다.

*   **배깅 (Bagging):** 주로 모델의 **분산(Variance)을 줄이는** 데 효과적입니다. 과적합을 방지하고 안정적인 성능을 원할 때 좋습니다. (`RandomForest`가 대표적)
*   **부스팅 (Boosting):** 주로 모델의 **편향(Bias)을 줄이는** 데 효과적이며, 매우 높은 예측 성능을 보여줍니다. 복잡한 패턴 학습에 유리하지만, 과적합에 유의해야 합니다. (`XGBoost`, `LightGBM` 등)
*   **스태킹 (Stacking):** 다양한 모델의 장점을 최대한 활용하여 **최고의 예측 성능**을 목표로 할 때 사용합니다. 다른 방법으로도 만족스러운 성능을 얻지 못했을 때 시도해볼 수 있는 고급 기법입니다.

어떤 방법이 가장 좋다고 단정할 수는 없습니다. 데이터의 특성, 문제의 종류, 그리고 여러분이 가진 컴퓨팅 자원 등 여러 요소를 고려하여 가장 적합한 방법을 선택하고, 하이퍼파라미터 튜닝을 통해 최적의 모델을 찾아가는 과정이 중요합니다.

앙상블 학습은 여러분의 머신러닝 모델을 한 단계 더 성장시킬 강력한 도구입니다. 오늘 배운 내용을 바탕으로 여러분의 프로젝트에 적극적으로 적용해보시고, 더 나은 성능을 경험하시길 바랍니다! 궁금한 점이 있다면 언제든지 댓글로 남겨주세요. 다음에도 유익한 글로 찾아뵙겠습니다!
