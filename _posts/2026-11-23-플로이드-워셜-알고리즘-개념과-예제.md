# 플로이드-워셜 알고리즘, 초보자도 이해할 수 있는 친절한 설명과 예제

안녕하세요, 개발 블로그 독자 여러분! 🚀
오늘 우리는 그래프 알고리즘의 세계에서 아주 중요한 역할을 하는 `플로이드-워셜(Floyd-Warshall)` 알고리즘에 대해 함께 파헤쳐 볼 시간입니다. "최단 경로"라는 말만 들어도 뭔가 복잡하고 어렵게 느껴지시나요? 걱정 마세요! 초보자분들도 쉽게 이해할 수 있도록 친절하게, 그리고 명확하게 설명해 드릴게요.

## 🏃‍♂️ 최단 경로 문제, 왜 중요할까요?

우리가 일상생활에서 가장 빠른 길을 찾거나, 내비게이션 앱이 최적의 경로를 알려주는 것도 모두 "최단 경로" 문제를 해결하는 과정입니다. 컴퓨터 과학에서도 이는 매우 중요한 문제이며, 다양한 알고리즘들이 이 문제 해결을 위해 존재합니다. 그중 플로이드-워셜 알고리즘은 **"모든 정점 쌍(All-Pairs)에 대한 최단 경로"**를 찾는 데 특화된 알고리즘입니다.

## 💡 플로이드-워셜 알고리즘이란?

플로이드-워셜 알고리즘은 그래프 내의 **모든 정점 쌍에 대한 최단 경로**를 찾는 동적 프로그래밍(Dynamic Programming) 기반의 알고리즘입니다. 다른 최단 경로 알고리즘인 다익스트라(Dijkstra)나 벨만-포드(Bellman-Ford)가 특정 한 출발점에서 다른 모든 정점까지의 최단 경로를 찾는 것과 달리, 플로이드-워셜은 '모든 정점에서 모든 정점까지'의 최단 경로를 한 번에 계산합니다.

가장 큰 특징 중 하나는 **음수 가중치 간선**을 포함하는 그래프에서도 최단 경로를 찾을 수 있다는 점입니다. 단, 음수 사이클(Negative Cycle)이 존재하면 올바른 결과를 보장할 수 없습니다. (음수 사이클이 있다면 경로의 길이가 계속 줄어들 수 있어 최단 경로를 정의할 수 없게 됩니다.)

## ✨ 어떻게 동작할까요? (핵심 아이디어)

플로이드-워셜 알고리즘의 핵심 아이디어는 매우 직관적입니다. "경유지"를 하나씩 늘려가면서 최단 경로를 업데이트하는 방식입니다.

1.  **초기 상태:**
    *   `dist[i][j]` : `i`에서 `j`로 가는 직접적인 경로의 길이를 저장하는 2차원 배열을 만듭니다.
    *   만약 `i`에서 `j`로 직접 가는 간선이 없다면 `무한대(INF)`로 설정합니다.
    *   `i`에서 `i`로 가는 경로는 `0`으로 설정합니다.

2.  **경유지를 이용한 업데이트:**
    *   이제 우리는 그래프의 모든 정점 `k`를 "경유지"로 사용해 봅니다.
    *   `k = 0`부터 `N-1`까지 순서대로 `k`를 경유지로 선택합니다.
    *   **핵심 로직:** `dist[i][j]` 값을 `dist[i][k] + dist[k][j]` 값과 비교하여 더 작은 값으로 업데이트합니다.
        *   `dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`
    *   이것이 의미하는 바는 이렇습니다: "현재 `i`에서 `j`로 가는 최단 경로(기존 `dist[i][j]`)가, `i`에서 `k`를 거쳐 `j`로 가는 경로(`dist[i][k] + dist[k][j]`)보다 짧은가?" 만약 `k`를 경유하는 것이 더 짧다면, 새로운 최단 경로로 업데이트하는 것입니다.

이 과정을 모든 정점 `k`에 대해 반복하면, `dist` 배열에는 모든 정점 쌍에 대한 최단 경로가 저장됩니다. 왜 `k`가 가장 바깥쪽 루프여야 할까요? `k`번째 정점까지를 경유지로 허용했을 때의 모든 최단 경로가 계산되어야, `(k+1)`번째 정점을 경유지로 고려할 때 올바른 계산이 가능하기 때문입니다.

## ⏳ 시간 복잡도

정점의 개수를 `N`이라고 할 때, 플로이드-워셜 알고리즘은 3개의 중첩된 반복문(`k`, `i`, `j`)을 사용합니다. 따라서 시간 복잡도는 **O(N^3)**입니다. 정점의 개수가 너무 많아지면 효율성이 떨어지므로, `N`이 100~500 정도일 때 주로 사용됩니다.

## 💻 파이썬으로 구현하는 플로이드-워셜 (예제)

이제 실제 코드를 통해 플로이드-워셜 알고리즘을 이해해 볼까요?

**예제 시나리오:**
다음과 같은 방향성 그래프가 있다고 가정해 봅시다.
*   정점: 4개 (0, 1, 2, 3)
*   간선:
    *   0 -> 1 : 비용 3
    *   0 -> 3 : 비용 7
    *   1 -> 0 : 비용 8
    *   1 -> 2 : 비용 2
    *   2 -> 0 : 비용 5
    *   2 -> 3 : 비용 1
    *   3 -> 0 : 비용 2

이 그래프에서 모든 정점 쌍에 대한 최단 경로를 찾아보겠습니다.

```python
import sys

# 무한대를 정의합니다. 보통 충분히 큰 수를 사용합니다.
# sys.maxsize를 사용해도 되지만, 여기서는 가독성을 위해 상수를 정의합니다.
INF = int(1e9) # 10억, 충분히 큰 수로 간주합니다.

# 정점의 개수 (예제에서는 4개)
n = 4

# 그래프를 나타내는 2차원 리스트를 초기화합니다.
# 초기에는 직접적인 간선의 비용만 저장하고, 없는 경로는 INF로 표시합니다.
# graph[i][j]는 i에서 j로 가는 직접적인 간선 비용입니다.
graph = [
    [0, 3, INF, 7],    # 0 -> 1 (3), 0 -> 3 (7)
    [8, 0, 2, INF],    # 1 -> 0 (8), 1 -> 2 (2)
    [5, INF, 0, 1],    # 2 -> 0 (5), 2 -> 3 (1)
    [2, INF, INF, 0]   # 3 -> 0 (2)
]

# 플로이드-워셜 알고리즘을 수행할 dist 배열을 초기화합니다.
# 초기에는 graph 배열과 동일하게 설정합니다.
dist = [[0] * n for _ in range(n)]
for i in range(n):
    for j in range(n):
        dist[i][j] = graph[i][j]

# ----------------- 플로이드-워셜 알고리즘 핵심 로직 -----------------
# k: 경유지 (intermediate node)
for k in range(n):
    # i: 출발 정점 (source node)
    for i in range(n):
        # j: 도착 정점 (destination node)
        for j in range(n):
            # 현재 i에서 j로 가는 최단 경로(dist[i][j])와
            # i에서 k를 거쳐 j로 가는 경로(dist[i][k] + dist[k][j]) 중
            # 더 짧은 경로로 업데이트합니다.
            if dist[i][k] != INF and dist[k][j] != INF: # INF와 INF를 더하면 오버플로우나 의미 없는 값이 될 수 있으므로 체크
                dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
# -----------------------------------------------------------------

# 결과 출력
print("모든 정점 쌍에 대한 최단 경로:")
for i in range(n):
    for j in range(n):
        if dist[i][j] == INF:
            print("INF", end=" ") # 경로가 없으면 INF로 표시
        else:
            print(dist[i][j], end="   ")
    print()
```

**코드 실행 결과:**
```
모든 정점 쌍에 대한 최단 경로:
0   3   5   6   
5   0   2   3   
3   6   0   1   
2   5   7   0
```

### 코드 해설

1.  **`INF` (무한대) 정의:** 연결되지 않은 간선을 표현하기 위해 사용합니다. 경로가 매우 길거나 없음을 의미합니다.
2.  **`n` (정점 개수) 정의:** 그래프의 정점 수를 나타냅니다.
3.  **`graph` 초기화:**
    *   `graph[i][j]`는 `i`에서 `j`로 직접 가는 간선의 비용을 나타냅니다.
    *   `i`에서 `i`로 가는 경로는 비용이 `0`입니다.
    *   직접적인 간선이 없는 경우는 `INF`로 초기화합니다.
4.  **`dist` 배열 복사:** 플로이드-워셜 알고리즘은 기존 `graph` 배열을 계속 업데이트하므로, 원본 `graph`를 보존하면서 계산하기 위해 `dist` 배열을 만들어 복사합니다. 이 `dist` 배열이 최종 최단 경로를 저장하게 됩니다.
5.  **삼중 반복문 (핵심):**
    *   `for k in range(n)`: **경유지 `k`**를 0번 정점부터 `n-1`번 정점까지 순서대로 고려합니다. 이 `k`가 가장 바깥 루프인 것이 핵심입니다.
    *   `for i in range(n)`: **출발 정점 `i`**를 0번부터 `n-1`번까지 순서대로 고려합니다.
    *   `for j in range(n)`: **도착 정점 `j`**를 0번부터 `n-1`번까지 순서대로 고려합니다.
    *   `if dist[i][k] != INF and dist[k][j] != INF:`: `i`에서 `k`로 가는 경로, 그리고 `k`에서 `j`로 가는 경로가 모두 존재할 때만 비교를 수행합니다. (INF인 경우를 더하면 의미 없는 큰 값이 될 수 있기 때문)
    *   `dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`: 현재 `i`에서 `j`로 가는 최단 경로(현재 `dist[i][j]`)와 `i`에서 `k`를 거쳐 `j`로 가는 경로(`dist[i][k] + dist[k][j]`) 중 더 작은 값을 `dist[i][j]`에 저장하여 업데이트합니다.

이 과정을 모두 마치면 `dist` 배열에는 모든 정점 쌍에 대한 최단 경로 값이 저장되어 있습니다.

##  언제 플로이드-워셜을 사용할까요?

*   **모든 정점 쌍의 최단 경로를 찾아야 할 때:** 다익스트라를 N번 수행하는 것보다 효율적일 수 있습니다 (간선이 많은 경우).
*   **음수 가중치 간선이 허용될 때:** 벨만-포드처럼 음수 가중치 간선도 처리할 수 있습니다. 단, 음수 사이클이 없어야 합니다.
*   **정점의 개수가 비교적 적을 때:** O(N^3)의 시간 복잡도 때문에 N이 수백 개 이내일 때 주로 효과적입니다. (N이 1000 이상이면 시간이 오래 걸릴 수 있습니다.)
