# 효율적인 구간 쿼리를 위한 세그먼트 트리(Segment Tree): 개념부터 파이썬 구현까지

안녕하세요, 개발 블로그 독자 여러분!

개발을 하다 보면 특정 범위(구간) 내의 데이터를 빠르게 조회하거나 업데이트해야 할 때가 종종 있습니다. 예를 들어, "주어진 숫자 배열에서 3번째부터 7번째까지의 합은 얼마인가?" 또는 "특정 구간에서 가장 작은 값은 무엇인가?"와 같은 질문에 답해야 할 때 말이죠. 이런 '구간 쿼리(Range Query)' 문제에 효과적으로 대응하기 위한 강력한 자료구조 중 하나가 바로 **세그먼트 트리(Segment Tree)** 입니다.

처음 접하면 다소 복잡해 보일 수 있지만, 세그먼트 트리는 한 번 익혀두면 수많은 알고리즘 문제와 실제 서비스 개발에 유용하게 활용될 수 있습니다. 오늘은 세그먼트 트리가 무엇인지 그 개념부터 파이썬으로 직접 구현하는 방법까지, 초보자도 이해하기 쉽게 차근차근 설명해 드리겠습니다.

---

## 1. 세그먼트 트리(Segment Tree)란 무엇일까요?

세그먼트 트리는 이름 그대로 '구간(Segment)'들의 정보를 담고 있는 '트리(Tree)' 형태의 자료구조입니다. 특정 범위에 대한 질의를 매우 효율적으로 처리하기 위해 고안된 이진 트리(Binary Tree)의 일종이죠.

쉽게 비유하자면, 커다란 책꽂이에 책이 쭉 꽂혀 있다고 상상해 보세요. "1번부터 100번 책까지 제목을 모두 알려줘!"라고 하면 처음부터 끝까지 다 봐야 합니다. 하지만 "컴퓨터 공학" 코너에 "자료구조" 섹션이 있고, 그 안에 또 "트리" 파트가 나눠져 있다면? 훨씬 빠르게 특정 범위의 책들을 찾아낼 수 있겠죠.

세그먼트 트리는 이러한 계층적인 구조를 데이터에 적용합니다.

*   **리프 노드(Leaf Node):** 원본 배열의 개별 요소를 나타냅니다. (예: `arr[0]`, `arr[1]`, ...)
*   **내부 노드(Internal Node):** 자식 노드들이 나타내는 구간의 정보를 합쳐서 저장합니다. 예를 들어, 구간 합 세그먼트 트리라면 두 자식 노드 구간의 합을 저장합니다.

이런 방식으로 트리를 구성하면, 특정 구간에 대한 질의가 들어왔을 때, 해당 구간을 이루는 노드들을 빠르게 찾아 합산함으로써 `O(log N)`의 시간 복잡도로 결과를 얻을 수 있습니다.

---

## 2. 왜 세그먼트 트리를 사용해야 할까요?

*   **빠른 구간 질의:** 일반적인 배열에서 구간 합이나 최솟값을 구하려면 `O(N)`의 시간이 걸립니다. 하지만 세그먼트 트리를 사용하면 `O(log N)` 시간에 처리할 수 있습니다.
*   **빠른 값 업데이트:** 특정 배열 요소의 값이 변경되었을 때, 관련 구간의 정보만 `O(log N)` 시간에 갱신할 수 있습니다.
*   **다양한 연산 적용:** 구간 합(sum), 구간 최솟값(min), 구간 최댓값(max), 구간 XOR 등 다양한 종류의 구간 연산에 적용할 수 있습니다.

**단점으로는** 원본 배열 크기 `N`에 비해 약 `4N` 정도의 추가적인 저장 공간이 필요하다는 점과, 초기 구현이 다소 복잡하다는 점이 있습니다. 하지만 그 효율성 때문에 복잡성을 감수할 가치가 충분합니다.

---

## 3. 세그먼트 트리 파이썬 구현 (구간 합 예제)

가장 흔하게 사용되는 '구간 합(Range Sum)' 세그먼트 트리를 파이썬으로 구현해 보겠습니다.

### 3.1. 기본 구조 및 배열 표현

세그먼트 트리를 구현할 때, 실제 트리 형태의 노드를 클래스로 만들 수도 있지만, 파이썬 리스트(배열)를 이용하여 완전 이진 트리(Complete Binary Tree) 형태로 표현하는 것이 일반적입니다.

*   `tree` 리스트의 인덱스 `1`을 루트 노드로 사용합니다.
*   어떤 노드의 인덱스가 `node`일 때, 왼쪽 자식은 `2 * node`, 오른쪽 자식은 `2 * node + 1`이 됩니다.
*   원본 배열의 크기가 `N`일 때, 세그먼트 트리는 대략 `4 * N` 크기의 리스트가 필요합니다.

```python
# 원본 배열
arr = [1, 3, 5, 7, 9, 11]
N = len(arr)

# 세그먼트 트리를 저장할 리스트 (충분한 크기로 초기화)
# 보통 N * 4 크기로 잡으면 안전합니다.
tree = [0] * (4 * N)
```

### 3.2. 트리 구축 (build)

`build` 함수는 원본 배열의 값을 바탕으로 세그먼트 트리를 재귀적으로 구축합니다.

*   **`node`**: 현재 트리의 노드 번호
*   **`start`**: 현재 노드가 담당하는 구간의 시작 인덱스 (원본 배열 기준)
*   **`end`**: 현재 노드가 담당하는 구간의 끝 인덱스 (원본 배열 기준)

```python
def build(node, start, end):
    """
    세그먼트 트리를 구축하는 함수
    :param node: 현재 트리의 노드 번호
    :param start: 현재 노드가 담당하는 구간의 시작 인덱스 (원본 배열 기준)
    :param end: 현재 노드가 담당하는 구간의 끝 인덱스 (원본 배열 기준)
    """
    # 1. 리프 노드인 경우 (더 이상 쪼갤 수 없는 구간)
    if start == end:
        tree[node] = arr[start] # 원본 배열의 값을 트리에 저장
        return

    # 2. 리프 노드가 아닌 경우, 구간을 절반으로 나누어 자식 노드 구축
    mid = (start + end) // 2
    build(2 * node, start, mid)         # 왼쪽 자식 (왼쪽 절반 구간 담당)
    build(2 * node + 1, mid + 1, end)   # 오른쪽 자식 (오른쪽 절반 구간 담당)

    # 3. 자식 노드들의 정보(구간 합)를 합쳐서 현재 노드에 저장
    tree[node] = tree[2 * node] + tree[2 * node + 1]
```

### 3.3. 값 업데이트 (update)

`update` 함수는 원본 배열의 특정 인덱스 `idx`의 값이 `val`로 변경되었을 때, 세그먼트 트리의 관련 노드들을 재귀적으로 업데이트합니다.

*   **`idx`**: 값을 변경할 원본 배열의 인덱스
*   **`val`**: 새로 업데이트할 값

```python
def update(node, start, end, idx, val):
    """
    세그먼트 트리의 특정 인덱스 값을 업데이트하는 함수
    :param node: 현재 트리의 노드 번호
    :param start: 현재 노드가 담당하는 구간의 시작 인덱스
    :param end: 현재 노드가 담당하는 구간의 끝 인덱스
    :param idx: 값을 변경할 원본 배열의 인덱스
    :param val: 새로 업데이트할 값
    """
    # 1. 변경하려는 인덱스가 현재 노드의 담당 구간을 벗어난 경우 (재귀 종료)
    if not (start <= idx <= end):
        return

    # 2. 리프 노드인 경우 (변경 대상 인덱스에 도달)
    if start == end:
        tree[node] = val # 직접 값을 업데이트
        return

    # 3. 리프 노드가 아닌 경우, 구간을 절반으로 나누어 자식 노드로 재귀 호출
    mid = (start + end) // 2
    update(2 * node, start, mid, idx, val)         # 왼쪽 자식 탐색
    update(2 * node + 1, mid + 1, end, idx, val)   # 오른쪽 자식 탐색

    # 4. 자식 노드들의 업데이트가 완료되면, 현재 노드의 값 갱신
    tree[node] = tree[2 * node] + tree[2 * node + 1]
```

### 3.4. 구간 질의 (query)

`query` 함수는 `left`부터 `right`까지의 구간 합을 재귀적으로 계산합니다.

*   **`left`**: 질의하려는 구간의 시작 인덱스 (원본 배열 기준)
*   **`right`**: 질의하려는 구간의 끝 인덱스 (원본 배열 기준)

```python
def query(node, start, end, left, right):
    """
    특정 구간 (left ~ right)의 합을 질의하는 함수
    :param node: 현재 트리의 노드 번호
    :param start: 현재 노드가 담당하는 구간의 시작 인덱스
    :param end: 현재 노드가 담당하는 구간의 끝 인덱스
    :param left: 질의하려는 구간의 시작 인덱스
    :param right: 질의하려는 구간의 끝 인덱스
    :return: 해당 구간의 합
    """
    # 1. 현재 노드의 담당 구간이 질의 구간과 전혀 겹치지 않는 경우
    #    (예: [2,3] 질의인데 현재 노드가 [5,6]을 담당)
    if right < start or end < left:
        return 0 # 합 연산이므로 영향을 주지 않는 0을 반환

    # 2. 현재 노드의 담당 구간이 질의 구간에 완전히 포함되는 경우
    #    (예: [2,7] 질의인데 현재 노드가 [3,5]를 담당)
    if left <= start and end <= right:
        return tree[node] # 현재 노드의 값을 바로 반환

    # 3. 현재 노드의 담당 구간이 질의 구간과 부분적으로 겹치는 경우
    #    (예: [2,7] 질의인데 현재 노드가 [0,5]를 담당)
    mid = (start + end) // 2
    # 왼쪽 자식과 오른쪽 자식에게 질의를 나눠서 보냄
    p1 = query(2 * node, start, mid, left, right)
    p2 = query(2 * node + 1, mid + 1, end, left, right)
    return p1 + p2 # 자식 노드들의 결과를 합산하여 반환
```

### 3.5. 전체 코드 및 사용 예시

```python
# 원본 배열
arr = [1, 3, 5, 7, 9, 11]
N = len(arr)

# 세그먼트 트리를 저장할 리스트 (충분한 크기로 초기화)
# 보통 N * 4 크기로 잡으면 안전합니다.
tree = [0] * (4 * N)

# --- 세그먼트 트리 함수 정의 ---

def build(node, start, end):
    """세그먼트 트리를 구축하는 함수"""
    if start == end:
        tree[node] = arr[start]
        return

    mid = (start + end) // 2
    build(2 * node, start, mid)
    build(2 * node + 1, mid + 1, end)
    tree[node] = tree[2 * node] + tree[2 * node + 1]

def update(node, start, end, idx, val):
    """세그먼트 트리의 특정 인덱스 값을 업데이트하는 함수"""
    if not (start <= idx <= end): # 변경하려는 인덱스가 현재 노드의 담당 구간을 벗어난 경우
        return

    if start == end: # 리프 노드인 경우 (변경 대상 인덱스에 도달)
        tree[node] = val
        arr[idx] = val # 원본 배열도 업데이트
        return

    mid = (start + end) // 2
    update(2 * node, start, mid, idx, val)
    update(2 * node + 1, mid + 1, end, idx, val)
    tree[node] = tree[2 * node] + tree[2 * node + 1]

def query(node, start, end, left, right):
    """특정 구간 (left ~ right)의 합을 질의하는 함수"""
    if right < start or end < left: # 현재 노드의 담당 구간이 질의 구간과 전혀 겹치지 않는 경우
        return 0

    if left <= start and end <= right: # 현재 노드의 담당 구간이 질의 구간에 완전히 포함되는 경우
        return tree[node]

    # 현재 노드의 담당 구간이 질의 구간과 부분적으로 겹치는 경우
    mid = (start + end) // 2
    p1 = query(2 * node, start, mid, left, right)
    p2 = query(2 * node + 1, mid + 1, end, left, right)
    return p1 + p2

# --- 세그먼트 트리 사용 예시 ---

# 1. 세그먼트 트리 구축
build(1, 0, N - 1)
print(f"세그먼트 트리 구축 완료: {tree}")
# 예시: [0, 5] 구간 (전체 배열) 합은 1+3+5+7+9+11 = 36
print(f"전체 구간 [0, {N-1}] 합: {query(1, 0, N - 1, 0, N - 1)}") # 예상: 36

# 2. 특정 구간 질의
# 인덱스 1부터 4까지의 합 (arr[1] + arr[2] + arr[3] + arr[4] = 3 + 5 + 7 + 9 = 24)
range_sum = query(1, 0, N - 1, 1, 4)
print(f"구간 [1, 4]의 합: {range_sum}") # 예상: 24

# 3. 값 업데이트
# arr[3]의 값을 7에서 10으로 변경
print(f"\n원본 배열: {arr}")
update(1, 0, N - 1, 3, 10) # 인덱스 3의 값을 10으로 변경
print(f"arr[3]을 10으로 업데이트 후 원본 배열: {arr}")
print(f"업데이트 후 세그먼트 트리: {tree}")

# 4. 업데이트된 값으로 다시 구간 질의
# 인덱스 1부터 4까지의 합 (arr[1] + arr[2] + arr[3] + arr[4] = 3 + 5 + 10 + 9 = 27)
updated_range_sum = query(1, 0, N - 1, 1, 4)
print(f"업데이트 후 구간 [1, 4]의 합: {updated_range_sum}") # 예상: 27

# 전체 구간 합 다시 확인
print(f"업데이트 후 전체 구간 [0, {N-1}] 합: {query(1, 0, N - 1, 0, N - 1)}") # 예상: 39 (36 - 7 + 10)
```

## 4. 실생활 및 코딩 테스트에서의 활용

세그먼트 트리는 코딩 테스트에서 빈번하게 출제되는 유형 중 하나입니다. 특히 다음과 같은 문제에서 빛을 발합니다.

*   **구간 최솟값/최댓값 질의:** 주어진 구간에서 가장 작은/큰 값을 찾는 문제
*   **구간 합 질의:** 주어진 구간의 모든 요소의 합을 찾는 문제
*   **Lazy Propagation (지연 전파):** 특정 구간 전체를 한 번에 업데이트해야 할 때 사용하는 고급 기법 (예: "3번부터 7번까지의 모든 숫자에 5를 더해라")

실제 개발 환경에서는 데이터베이스 쿼리 최적화, 게임 개발에서의 충돌 감지, 실시간 데이터 분석 시스템 등 다양한 분야에서 응용될 수 있습니다.
