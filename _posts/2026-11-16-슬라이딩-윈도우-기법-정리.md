## 1. 슬라이딩 윈도우(Sliding Window)란 무엇일까요?

슬라이딩 윈도우는 말 그대로 **'미끄러지듯 움직이는 창문'**을 의미합니다. 데이터의 배열이나 문자열 위에서 고정된(Fixed) 또는 가변적인(Variable) 크기의 '윈도우(Window)'를 이동시키면서 필요한 연산을 수행하는 기법입니다.

조금 더 쉽게 비유하자면, 긴 기차의 객실(윈도우)이 철로(데이터 배열) 위를 한 칸씩 이동하며 그 객실 안에 있는 승객들(데이터)만 확인하는 것과 비슷하다고 할 수 있습니다. 매번 기차 전체를 새로 만들 필요 없이, 기존 객실에서 한 명 내리고 새로운 한 명을 태우면서 효율적으로 승객 구성을 바꾸는 것이죠.

### 왜 슬라이딩 윈도우를 사용할까요?

가장 큰 이유는 **'효율성'** 때문입니다. 일반적으로 연속된 부분 배열이나 부분 문자열의 합, 평균, 최댓값 등을 구할 때는 중첩 반복문(Brute-Force)을 사용하여 모든 가능한 부분 집합을 계산하곤 합니다. 예를 들어, `N`개의 데이터가 있을 때 `K` 크기의 부분 집합을 모두 확인하려면 O(N*K) 또는 O(N^2)의 시간 복잡도가 발생합니다.

하지만 슬라이딩 윈도우 기법을 사용하면, 이전에 계산한 결과를 재활용하면서 불필요한 중복 계산을 줄일 수 있습니다. 윈도우가 한 칸 이동할 때마다, 가장 오래된 데이터는 빼고 새로운 데이터는 더하는 방식으로 O(1)의 연산만으로 윈도우의 상태를 갱신할 수 있기 때문에, 전체적인 시간 복잡도를 **O(N)**으로 크게 개선할 수 있습니다.

---

## 2. 언제 슬라이딩 윈도우를 사용할까요?

슬라이딩 윈도우는 주로 다음과 같은 문제 유형에서 효과적입니다.

*   **연속된 부분 배열(Subarray), 부분 문자열(Substring), 부분 수열(Subsequence) 등 '연속된' 데이터 덩어리를 다루는 문제.**
*   **고정된 크기의 윈도우:** 특정 크기 `K`의 부분 배열/문자열에서 최대/최소 합, 평균, 빈도 등을 찾는 문제.
*   **가변적인 크기의 윈도우:** 특정 조건을 만족하는 가장 짧거나 가장 긴 부분 배열/문자열을 찾는 문제. (예: 합이 S 이상이 되는 가장 짧은 부분 배열)

## 3. 코드 예제로 이해하기: 고정 크기 윈도우

가장 기본적인 예제를 통해 슬라이딩 윈도우의 동작 방식을 코드로 살펴보겠습니다.

**문제:** 주어진 정수 배열(`arr`)에서 `k` 크기의 부분 배열(Subarray) 중 가장 큰 합을 구하는 문제를 풀어봅시다.

**예시:** `arr = [1, 4, 2, 10, 2, 3, 1, 0, 20]`, `k = 3`

### 3.1. 비효율적인 방법 (Brute-Force)

먼저 슬라이딩 윈도우를 사용하지 않고 중첩 반복문으로 풀면 어떻게 될까요?

```python
def max_subarray_sum_brute_force(arr, k):
    """
    주어진 배열에서 k 크기의 부분 배열 중 가장 큰 합을 브루트 포스 방식으로 찾습니다.
    시간 복잡도: O(N*K)
    """
    if not arr or k <= 0 or k > len(arr):
        return 0 # 또는 적절한 에러 처리

    max_sum = -float('inf') # 음수가 될 수도 있으므로 -무한대로 초기화

    # 가능한 모든 k 크기의 부분 배열을 순회
    for i in range(len(arr) - k + 1):
        current_sum = 0
        for j in range(i, i + k):
            current_sum += arr[j]
        max_sum = max(max_sum, current_sum)

    return max_sum

# 예제 실행
arr = [1, 4, 2, 10, 2, 3, 1, 0, 20]
k = 3
print(f"Brute-Force 결과: {max_subarray_sum_brute_force(arr, k)}")
# 예상 출력: Brute-Force 결과: 22 (부분 배열 [0, 2, 20]의 합)
```

이 방법은 `N`이 커질수록, `K`가 커질수록 계산량이 급격히 늘어납니다. `N`이 10만, `K`가 1000이라면 1억 번의 연산이 넘어갈 수 있습니다. 😱

### 3.2. 슬라이딩 윈도우를 이용한 효율적인 방법

이제 슬라이딩 윈도우 기법을 적용해 봅시다.

```python
def max_subarray_sum_sliding_window(arr, k):
    """
    주어진 배열에서 k 크기의 부분 배열 중 가장 큰 합을 슬라이딩 윈도우 방식으로 찾습니다.
    시간 복잡도: O(N)
    """
    if not arr or k <= 0 or k > len(arr):
        return 0 # 또는 적절한 에러 처리

    # 1. 초기 윈도우 설정: 첫 k개의 요소로 윈도우의 합을 계산합니다.
    window_sum = sum(arr[:k])
    max_sum = window_sum # 현재까지의 최대 합을 저장

    # 2. 윈도우 슬라이딩: 배열의 나머지 부분을 순회하면서 윈도우를 이동합니다.
    # i는 윈도우의 '새로운' 오른쪽 끝을 가리킵니다.
    for i in range(k, len(arr)):
        # 윈도우 이동:
        # 새로운 요소(arr[i])를 더하고, 가장 오래된 요소(arr[i-k])를 뺍니다.
        # 이 한 줄이 O(1)의 마법입니다!
        window_sum += arr[i] - arr[i - k]

        # 최대 합 갱신
        max_sum = max(max_sum, window_sum)

    return max_sum

# 예제 실행
arr = [1, 4, 2, 10, 2, 3, 1, 0, 20]
k = 3
print(f"Sliding Window 결과: {max_subarray_sum_sliding_window(arr, k)}")
```

**코드 설명:**

1.  **초기 윈도우 설정:** 먼저 배열의 첫 `k`개의 요소(`arr[0]`부터 `arr[k-1]`)를 사용하여 `window_sum`을 계산합니다. 이 값이 `max_sum`의 초기값이 됩니다.
    *   예시: `[1, 4, 2]` -> `window_sum = 7`, `max_sum = 7`
2.  **윈도우 슬라이딩:** `k` 인덱스부터 배열의 끝까지 반복문을 돌립니다.
    *   `i`가 `k`일 때: `arr[k]` (즉, `arr[3]`인 `10`)을 윈도우에 추가하고, `arr[i-k]` (즉, `arr[0]`인 `1`)을 윈도우에서 제거합니다.
        *   `window_sum = 7 + 10 - 1 = 16`
        *   `max_sum = max(7, 16) = 16` (현재 윈도우: `[4, 2, 10]`)
    *   `i`가 `k+1`일 때: `arr[k+1]` (즉, `arr[4]`인 `2`)를 윈도우에 추가하고, `arr[i-k]` (즉, `arr[1]`인 `4`)를 윈도우에서 제거합니다.
        *   `window_sum = 16 + 2 - 4 = 14`
        *   `max_sum = max(16, 14) = 16` (현재 윈도우: `[2, 10, 2]`)
    *   ... 이런 식으로 윈도우가 배열의 끝까지 이동하며 `max_sum`을 갱신합니다.
    *   최종적으로 `[0, 2, 20]`일 때 `window_sum = 22`가 되며 `max_sum = 22`로 업데이트 됩니다.

결과적으로 단 한 번의 순회(O(N))만으로 문제를 해결할 수 있게 됩니다. 정말 놀랍지 않나요?

## 4. 더 나아가기: 가변 크기 윈도우

오늘 예제는 고정된 `k` 크기의 윈도우를 사용했지만, 슬라이딩 윈도우는 윈도우의 크기가 가변적인 문제에도 활용될 수 있습니다. 예를 들어, "합이 특정 값 S 이상이 되는 가장 짧은 부분 배열의 길이를 구하라" 같은 문제가 여기에 해당합니다. 이런 문제에서는 윈도우의 합이 S보다 작으면 오른쪽 끝을 늘려 윈도우를 확장하고, S보다 크거나 같으면 왼쪽 끝을 줄여 윈도우를 축소하는 방식으로 윈도우의 크기를 동적으로 조절하게 됩니다. 이는 다음 기회에 더 깊이 다뤄보도록 할게요!
