# 파이썬 이터러블(Iterable)과 이터레이터(Iterator) 완벽 이해하기: 초보 개발자를 위한 가이드

안녕하세요, 개발자 친구들! 🧑‍💻

파이썬을 공부하다 보면 `for` 루프를 정말 많이 사용하게 됩니다. 리스트, 튜플, 문자열 등 다양한 데이터들을 반복하면서 처리하죠. 그런데 혹시 이런 궁금증 가져보신 적 있으신가요?

*   "어떤 객체는 `for` 루프를 돌릴 수 있고, 어떤 객체는 안 되는 걸까?"
*   "내부적으로 `for` 루프는 어떻게 동작하는 걸까?"
*   "제너레이터(Generator)와는 또 뭐가 다른 걸까?"

오늘 우리는 이 모든 질문의 핵심인 **이터러블(Iterable)**과 **이터레이터(Iterator)**에 대해 깊이 있게 파헤쳐 볼 거예요. 이 두 개념을 제대로 이해하면 파이썬의 동작 원리를 더 잘 이해하고, 효율적인 코드를 작성하는 데 큰 도움이 될 겁니다. 초보자분들도 쉽게 이해할 수 있도록 친절하게 설명해 드릴 테니, 걱정 말고 따라오세요!

---

## 1. 이터러블(Iterable): "반복 가능한" 모든 것

가장 먼저 이터러블부터 알아볼까요? 이름 그대로 **이터러블은 "반복할 수 있는(iterable)" 객체**를 의미합니다. 우리가 흔히 `for` 루프를 사용할 수 있는 모든 객체가 바로 이터러블입니다.

예를 들어볼까요?

*   **리스트 (List)**: `[1, 2, 3]`
*   **튜플 (Tuple)**: `(10, 20, 30)`
*   **문자열 (String)**: `'hello'`
*   **딕셔너리 (Dictionary)**: `{'a': 1, 'b': 2}` (키를 반복)
*   **집합 (Set)**: `{1, 2, 3}`

이러한 객체들은 모두 `for` 루프를 사용해 요소를 하나씩 꺼내올 수 있죠.

```python
# 리스트는 이터러블입니다.
my_list = [1, 2, 3]
for item in my_list:
    print(f"리스트 아이템: {item}")

print("-" * 20)

# 문자열도 이터러블입니다.
my_string = "Python"
for char in my_string:
    print(f"문자열 문자: {char}")
```

**그렇다면 어떤 객체가 이터러블이라고 할 수 있을까요?**

파이썬에서 어떤 객체가 이터러블이 되려면, 해당 객체는 `__iter__` 라는 특별한 메서드를 가지고 있어야 합니다. 이 `__iter__` 메서드는 **이터레이터(Iterator) 객체를 반환**합니다.

`hasattr()` 함수를 사용하면 어떤 객체가 특정 메서드를 가지고 있는지 확인할 수 있어요.

```python
my_list = [1, 2, 3]
my_string = "Hello"
my_number = 123

print(f"리스트는 __iter__ 메서드를 가지고 있는가? {hasattr(my_list, '__iter__')}")
print(f"문자열은 __iter__ 메서드를 가지고 있는가? {hasattr(my_string, '__iter__')}")
print(f"정수는 __iter__ 메서드를 가지고 있는가? {hasattr(my_number, '__iter__')}")
```

**결과:**
```
리스트는 __iter__ 메서드를 가지고 있는가? True
문자열은 __iter__ 메서드를 가지고 있는가? True
정수는 __iter__ 메서드를 가지고 있는가? False
```

보시다시피, 정수(`int`)는 `__iter__` 메서드가 없기 때문에 `for` 루프를 돌릴 수 없습니다. `for i in 123:`과 같이 시도하면 오류가 발생할 거예요!

**요약:** 이터러블은 `__iter__` 메서드를 가지고 있어서 이터레이터를 만들어낼 수 있는 객체입니다. 마치 "반복될 준비가 된 데이터 묶음"이라고 생각할 수 있습니다.

---

## 2. 이터레이터(Iterator): "반복을 진행하는" 안내자

이제 이터레이터 차례입니다! 이터러블이 "반복될 수 있는 데이터"라면, **이터레이터는 "실제로 반복 작업을 수행하는 객체"**입니다. 이터레이터는 현재 어디까지 반복했는지 **상태(state)**를 기억하고, 다음 요소를 반환하는 역할을 합니다.

이터레이터가 되려면 두 가지 특별한 메서드를 가지고 있어야 합니다:

1.  `__iter__`: 자신(이터레이터 객체)을 반환합니다. (자기 자신도 이터러블이어야 하기 때문)
2.  `__next__`: 다음 요소를 반환합니다. 더 이상 반환할 요소가 없으면 `StopIteration` 예외를 발생시킵니다.

파이썬의 내장 함수 `iter()`를 사용하면 이터러블로부터 이터레이터를 얻을 수 있습니다. 그리고 `next()` 함수를 사용하면 이터레이터로부터 다음 요소를 수동으로 가져올 수 있습니다.

```python
my_list = [10, 20, 30]

# 1. 이터러블로부터 이터레이터 객체를 얻습니다.
# my_list.__iter__()와 동일
my_iterator = iter(my_list) 
print(f"이터레이터 객체: {my_iterator}")
print(f"이터레이터는 __next__ 메서드를 가지고 있는가? {hasattr(my_iterator, '__next__')}")

# 2. next() 함수를 사용하여 다음 요소를 가져옵니다.
print(f"첫 번째 요소: {next(my_iterator)}") # my_iterator.__next__()와 동일
print(f"두 번째 요소: {next(my_iterator)}")
print(f"세 번째 요소: {next(my_iterator)}")

# 3. 더 이상 요소가 없으면 StopIteration 예외가 발생합니다.
try:
    print(f"네 번째 요소 (오류 발생 예정): {next(my_iterator)}")
except StopIteration:
    print("더 이상 가져올 요소가 없습니다! StopIteration 예외 발생.")
```

**결과:**
```
이터레이터 객체: <list_iterator object at 0x...>
이터레이터는 __next__ 메서드를 가지고 있는가? True
첫 번째 요소: 10
두 번째 요소: 20
세 번째 요소: 30
더 이상 가져올 요소가 없습니다! StopIteration 예외 발생.
```

**요약:** 이터레이터는 `__next__` 메서드를 가지고 있어 다음 요소를 순차적으로 반환하고, 더 이상 요소가 없으면 `StopIteration`을 발생시키는 객체입니다. 마치 "어떤 책에서 현재 읽고 있는 페이지를 기억하고 다음 페이지로 넘겨주는 손가락"과 같다고 생각할 수 있습니다.

## 3. 이터러블과 이터레이터의 관계: `for` 루프는 어떻게 동작할까?

이제 두 개념을 종합해 봅시다. 파이썬의 `for` 루프는 내부적으로 다음과 같은 과정을 거쳐 동작합니다.

1.  `for` 루프가 시작되면, 주어진 **이터러블** (`my_list` 등)의 `__iter__` 메서드를 호출합니다.
2.  `__iter__` 메서드는 **이터레이터** 객체를 반환합니다.
3.  `for` 루프는 이 이터레이터 객체의 `__next__` 메서드를 반복적으로 호출합니다.
4.  `__next__` 메서드가 값을 반환하면, `for` 루프는 그 값을 사용합니다.
5.  `__next__` 메서드가 `StopIteration` 예외를 발생시키면, `for` 루프는 종료됩니다.

이 과정은 마치 다음과 같은 코드로 시뮬레이션해볼 수 있습니다.

```python
# for 루프의 내부 동작 시뮬레이션
my_data = [100, 200, 300] # 이터러블

# 1. 이터러블로부터 이터레이터를 얻음
_iter = iter(my_data) # my_data.__iter__() 호출

while True:
    try:
        # 2. 이터레이터의 다음 요소를 얻음
        item = next(_iter) # _iter.__next__() 호출
        print(f"루프에서 얻은 아이템: {item}")
    except StopIteration:
        # 3. StopIteration 발생 시 루프 종료
        print("모든 아이템을 처리했습니다. 루프 종료!")
        break
```

**결과:**
```
루프에서 얻은 아이템: 100
루프에서 얻은 아이템: 200
루프에서 얻은 아이템: 300
모든 아이템을 처리했습니다. 루프 종료!
```

이해가 되셨나요? 우리가 매일 사용하는 `for` 루프가 이런 과정을 거쳐 동작한다는 사실이 흥미롭지 않나요?

### 이터레이터가 상태를 가진다는 것의 중요성

이터레이터는 `__next__`를 호출할 때마다 다음 위치를 기억하는 **상태 저장(stateful)** 객체입니다. 이 점은 매우 중요합니다.

```python
numbers = [1, 2, 3, 4, 5]

# 동일한 이터러블에서 두 개의 독립적인 이터레이터를 생성
iterator1 = iter(numbers)
iterator2 = iter(numbers)

print(f"이터레이터 1: {next(iterator1)}") # 1
print(f"이터레이터 1: {next(iterator1)}") # 2

print(f"이터레이터 2: {next(iterator2)}") # 1 (iterator2는 독립적으로 시작)
print(f"이터레이터 2: {next(iterator2)}") # 2

print(f"이터레이터 1: {next(iterator1)}") # 3 (iterator1은 계속 진행)
```

두 이터레이터 `iterator1`과 `iterator2`는 서로의 진행 상황에 영향을 주지 않고 독립적으로 동작합니다. 이는 하나의 데이터 셋을 여러 가지 방식으로 동시에 탐색해야 할 때 매우 유용하게 사용될 수 있습니다.

## 4. 나만의 이터러블/이터레이터 만들기

이 개념들을 더 확실히 이해하기 위해 직접 이터러블과 이터레이터를 구현해볼까요? 1부터 특정 숫자까지 세는 `MyCounter` 클래스를 만들어보겠습니다.

```python
class MyCounter:
    def __init__(self, start, end):
        self.start = start
        self.end = end

    # 이터러블이 되기 위한 메서드
    # 이터레이터 객체를 반환해야 함. 여기서는 자기 자신을 이터레이터로 사용
    def __iter__(self):
        self.current = self.start # 이터레이션 시작 시 현재 값을 초기화
        return self # 자기 자신(MyCounter 인스턴스)이 이터레이터 역할도 겸함

    # 이터레이터가 되기 위한 메서드
    def __next__(self):
        if self.current <= self.end:
            value = self.current
            self.current += 1
            return value
        else:
            raise StopIteration # 더 이상 반환할 값이 없으면 예외 발생

# MyCounter는 이제 이터러블입니다!
my_counter_obj = MyCounter(1, 5)

print("--- 첫 번째 루프 ---")
for num in my_counter_obj:
    print(f"카운트: {num}")

print("--- 두 번째 루프 (다시 시작) ---")
# 동일한 객체로 다시 루프를 돌려도 __iter__가 current를 초기화해주기 때문에 잘 동작합니다.
for num in my_counter_obj:
    print(f"카운트: {num}")

print("--- 직접 next() 호출 ---")
another_counter_obj = MyCounter(10, 12)
iter_instance = iter(another_counter_obj) # __iter__ 호출
print(f"다음: {next(iter_instance)}")     # __next__ 호출
print(f"다음: {next(iter_instance)}")
print(f"다음: {next(iter_instance)}")
try:
    print(f"다음 (오류 발생 예정): {next(iter_instance)}")
except StopIteration:
    print("카운트 종료!")
```

**설명:**
*   `MyCounter` 클래스는 `__iter__`와 `__next__` 두 메서드를 모두 가지고 있기 때문에 스스로 이터러블이자 이터레이터가 됩니다.
*   `__iter__`에서는 `self.current`를 초기 `self.start` 값으로 설정하여, 매번 새로운 `for` 루프가 시작될 때마다 카운트를 처음부터 다시 시작할 수 있도록 합니다.
*   `__next__`에서는 `self.current`를 하나씩 증가시키며 값을 반환하고, `self.end` 값을 초과하면 `StopIteration`을 발생시켜 반복을 종료합니다.

이처럼 직접 이터러블과 이터레이터를 만들 수 있다면, 파이썬의 내부 동작에 대한 이해도가 훨씬 높아질 겁니다!

## 5. 핵심 정리

*   **이터러블(Iterable)**: `__iter__` 메서드를 가지고 있어서 이터레이터 객체를 반환할 수 있는 모든 객체입니다. `for` 루프에 직접 사용할 수 있습니다. (예: 리스트, 튜플, 문자열)
*   **이터레이터(Iterator)**: `__iter__` (자신을 반환)와 `__next__` 메서드를 모두 가지고 있는 객체입니다. `next()` 함수를 통해 다음 요소를 순차적으로 반환하며, 더 이상 요소가 없으면 `StopIteration` 예외를 발생시킵니다. 현재 반복 위치를 기억하는 **상태 저장(stateful)** 객체입니다.
*   **관계**: 이터러블은 이터레이터를 **생성**하고, 이터레이터는 실제로 반복 작업을 **수행**합니다. `for` 루프는 이터러블로부터 이터레이터를 얻어 `__next__`를 반복 호출하는 방식으로 동작합니다.
*   **왜 분리될까?**: 주로 메모리 효율성 때문입니다. 모든 요소를 한꺼번에 메모리에 올리지 않고 필요할 때마다 하나씩 생성하여 제공할 수 있습니다. 또한, 동일한 이터러블에 대해 여러 개의 독립적인 반복을 수행할 수 있습니다. (제너레이터도 이 개념을 활용합니다!)
