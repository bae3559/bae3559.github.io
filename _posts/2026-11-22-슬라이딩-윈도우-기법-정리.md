# 슬라이딩 윈도우 기법: 효율적인 데이터 탐색의 비밀

안녕하세요, 개발 블로그 독자 여러분! 🚀

데이터를 다루다 보면, 특히 배열이나 문자열 같은 선형 자료구조에서 '특정 조건을 만족하는 연속된 부분'을 찾아야 할 때가 많습니다. 예를 들어, "가장 합이 큰 연속된 K개의 숫자 찾기"나 "부분 문자열 중 조건에 맞는 가장 긴 것 찾기" 같은 문제들이죠. 이런 문제들을 단순하게 풀려면 보통 중첩 반복문을 사용하게 되는데, 데이터가 많아질수록 성능 저하가 심해지는 비효율적인 방법이 됩니다.

여기서 등장하는 마법 같은 기법이 바로 **슬라이딩 윈도우 (Sliding Window)** 입니다. 마치 창문이 미끄러지듯 움직이면서 데이터를 효율적으로 탐색하는 이 기법, 오늘 저와 함께 파헤쳐 볼까요? 초보자도 쉽게 이해할 수 있도록 친절하게 설명해 드릴게요!

---

## 1. 슬라이딩 윈도우란 무엇인가요?

슬라이딩 윈도우 기법은 **배열이나 리스트, 문자열 같은 선형 자료구조에서 고정되거나 가변적인 크기의 '부분(window)'을 정하고, 이 '부분'을 마치 미끄러지듯 이동시키면서 문제를 해결하는 알고리즘**입니다.

조금 더 쉽게 비유해 볼까요?

여러분 앞에 길게 늘어선 사진들이 있다고 상상해 보세요. 이 사진들 중에서 '특정 크기의 연속된 3장의 사진'을 보고 싶습니다. 여러분은 처음 3장을 보고, 다음에는 첫 장을 버리고 네 번째 장을 추가해서 3장을 봅니다. 이렇게 한 장씩 추가하고 빼면서 3장의 사진 묶음을 계속 이동시켜 볼 수 있겠죠?

![Sliding Window Analogy](https://i.imgur.com/k4pLhE0.png)

이때 '3장의 사진 묶음'이 바로 '윈도우(Window)'이고, 한 장씩 밀면서 이동하는 과정이 '슬라이딩(Sliding)'입니다. 이 기법의 핵심은 **이전 계산 결과를 재활용하여 불필요한 중복 계산을 줄이는 것**에 있습니다.

---

## 2. 왜 슬라이딩 윈도우를 사용해야 할까요? (장점)

슬라이딩 윈도우 기법의 가장 큰 장점은 바로 **효율성**입니다.

*   **시간 복잡도 개선:** 보통 `O(N^2)` (N의 제곱) 이나 `O(N*K)` (N 곱하기 K) 에 해결해야 할 문제를 `O(N)` (N) 이나 `O(N log N)` 등 더 효율적인 시간 복잡도로 해결할 수 있게 해줍니다. 데이터의 양이 많아질수록 이 효율성의 차이는 어마어마해집니다.
*   **중복 계산 방지:** 윈도우가 이동할 때마다 전체를 다시 계산하는 대신, 윈도우에서 벗어나는 요소는 빼고 새로 들어오는 요소만 더하는 방식으로 계산을 업데이트합니다.

---

## 3. 슬라이딩 윈도우 동작 방식 (두 개의 포인터)

슬라이딩 윈도우는 보통 두 개의 포인터(`start`, `end` 또는 `left`, `right`)를 사용해서 구현합니다.

1.  **윈도우 확장:** `end` 포인터를 오른쪽으로 이동시키면서 윈도우 크기를 늘립니다.
2.  **윈도우 처리:** 윈도우 내의 데이터를 가지고 필요한 계산(합계, 개수, 최댓값 등)을 수행합니다.
3.  **윈도우 축소 (또는 이동):**
    *   **고정 크기 윈도우:** 윈도우 크기가 정해져 있다면, `end` 포인터가 한 칸 이동할 때마다 `start` 포인터도 한 칸 이동시켜 윈도우 크기를 유지합니다. (가장 왼쪽 요소를 빼고, 가장 오른쪽 요소를 추가)
    *   **가변 크기 윈도우:** 윈도우 내의 조건이 깨지거나, 특정 조건을 만족할 때까지 `start` 포인터를 오른쪽으로 이동시켜 윈도우 크기를 줄입니다.

자, 그럼 실제 코드 예제를 통해 더 자세히 알아볼까요?

---

## 4. 코드 예제 1: 고정 크기 슬라이딩 윈도우 (Fixed Size Sliding Window)

**문제:** 주어진 정수 배열 `arr`에서 길이가 `K`인 연속된 부분 배열 중 합이 가장 큰 것을 찾아 그 합을 반환하세요.

**예시:** `arr = [1, 4, 2, 10, 2, 3, 1, 0, 20]`, `K = 3`
결과: `[2, 10, 2]`의 합인 `14` (또는 `[1, 0, 20]`의 합인 `21`)

### 🙅‍♀️ 나쁜 예시 (Naive Approach)

`O(N*K)`의 시간 복잡도를 가집니다.

```python
def max_subarray_sum_naive(arr, k):
    max_sum = 0
    # 모든 가능한 길이 K의 부분 배열을 순회
    for i in range(len(arr) - k + 1):
        current_sum = 0
        for j in range(i, i + k):
            current_sum += arr[j]
        max_sum = max(max_sum, current_sum)
    return max_sum

# 예제 실행
arr = [1, 4, 2, 10, 2, 3, 1, 0, 20]
k = 3
print(f"나이브 방식으로 찾은 최대 부분 배열 합: {max_subarray_sum_naive(arr, k)}")
```

### 🧑‍💻 슬라이딩 윈도우로 해결하기

`O(N)`의 시간 복잡도로 훨씬 효율적입니다.

```python
def max_subarray_sum_sliding_window(arr, k):
    # 예외 처리: K가 배열 길이보다 크면 유효하지 않음
    if k > len(arr):
        return -1 # 혹은 0, 또는 에러 발생 등 문제 조건에 따라 처리

    # 1. 첫 번째 윈도우의 합을 계산 (초기 윈도우 설정)
    window_sum = sum(arr[:k])
    max_sum = window_sum # 현재까지의 최대 합을 저장

    # 2. 윈도우를 한 칸씩 이동 (슬라이딩)
    # arr[k] 부터 배열 끝까지 순회
    for i in range(k, len(arr)):
        # 윈도우 이동:
        # 새로 추가되는 요소 (arr[i])는 더하고,
        # 윈도우에서 빠져나가는 요소 (arr[i-k])는 뺀다.
        window_sum += arr[i] - arr[i - k]
        
        # 최대 합 업데이트
        max_sum = max(max_sum, window_sum)

    return max_sum

# 예제 실행
arr = [1, 4, 2, 10, 2, 3, 1, 0, 20]
k = 3
print(f"슬라이딩 윈도우로 찾은 최대 부분 배열 합: {max_subarray_sum_sliding_window(arr, k)}")

arr_2 = [2, 3, 4, 1, 5]
k_2 = 2
print(f"슬라이딩 윈도우로 찾은 최대 부분 배열 합 (예제2): {max_subarray_sum_sliding_window(arr_2, k_2)}")
```

### 코드 해설

1.  **초기 윈도우 설정:** 먼저 `arr`의 첫 `K`개 요소의 합을 `window_sum`에 저장합니다. 이것이 우리의 첫 번째 윈도우입니다. `max_sum`도 이 값으로 초기화합니다.
2.  **윈도우 슬라이딩:** `for i in range(k, len(arr))` 루프를 돌면서 윈도우를 한 칸씩 오른쪽으로 이동시킵니다.
    *   `arr[i]`는 새로 윈도우 안으로 들어오는 요소입니다. `window_sum`에 더해줍니다.
    *   `arr[i - k]`는 윈도우의 가장 왼쪽에서 빠져나가는 요소입니다. `window_sum`에서 빼줍니다.
    *   이렇게 하면 윈도우가 통째로 움직여도 `window_sum`을 매번 처음부터 계산할 필요 없이, `O(1)` (상수 시간)에 업데이트할 수 있습니다.
3.  **최대값 갱신:** `window_sum`이 업데이트될 때마다 `max_sum`과 비교하여 더 큰 값으로 갱신합니다.
4.  **반환:** 모든 윈도우를 탐색한 후 `max_sum`을 반환합니다.

## 5. 코드 예제 2: 가변 크기 슬라이딩 윈도우 (Variable Size Sliding Window)

**문제:** 양의 정수 배열 `arr`와 정수 `K`가 주어졌을 때, 합이 `K` 이하가 되는 연속된 부분 배열 중 가장 긴 것의 길이를 반환하세요.

**예시:** `arr = [3, 1, 2, 7, 4, 2, 1, 1, 5]`, `K = 8`
결과: `[7, 4]` (합 11 > 8), `[4, 2, 1, 1]` (합 8 <= 8), 길이가 4.

### 🧑‍💻 슬라이딩 윈도우로 해결하기

`O(N)`의 시간 복잡도를 가집니다.

```python
def longest_subarray_sum_at_most_k(arr, k):
    start = 0        # 윈도우의 시작 인덱스 (왼쪽 포인터)
    window_sum = 0   # 현재 윈도우 내 요소들의 합
    max_length = 0   # 찾은 가장 긴 부분 배열의 길이

    # end 포인터를 배열 끝까지 이동시키면서 윈도우를 확장
    for end in range(len(arr)):
        window_sum += arr[end] # end 요소를 윈도우에 추가

        # 윈도우의 합이 K를 초과하면, 윈도우를 축소 (start 포인터 이동)
        while window_sum > k:
            window_sum -= arr[start] # start 요소를 윈도우에서 제거
            start += 1               # start 포인터 이동 (윈도우 축소)
        
        # 현재 윈도우는 유효한 상태 (합 <= K)이므로, 길이를 업데이트
        # 윈도우의 현재 길이 = end - start + 1
        max_length = max(max_length, end - start + 1)
                
    return max_length

# 예제 실행
arr = [3, 1, 2, 7, 4, 2, 1, 1, 5]
k = 8
print(f"합이 {k} 이하인 가장 긴 부분 배열의 길이: {longest_subarray_sum_at_most_k(arr, k)}") # 기대 출력: 4 ([4, 2, 1, 1])

arr_2 = [1, 2, 3, 4, 5]
k_2 = 10
print(f"합이 {k_2} 이하인 가장 긴 부분 배열의 길이 (예제2): {longest_subarray_sum_at_most_k(arr_2, k_2)}") # 기대 출력: 4 ([1, 2, 3, 4] 또는 [2, 3, 4, 5])
```

### 코드 해설

1.  **변수 초기화:**
    *   `start`: 윈도우의 시작 인덱스를 나타내는 포인터 (왼쪽 포인터). `0`으로 시작합니다.
    *   `window_sum`: 현재 윈도우 안의 숫자들의 합. `0`으로 시작합니다.
    *   `max_length`: 조건을 만족하는 가장 긴 부분 배열의 길이. `0`으로 시작합니다.
2.  **윈도우 확장 (`end` 포인터 이동):** `for end in range(len(arr))` 루프를 사용하여 `end` 포인터를 배열의 시작부터 끝까지 이동시킵니다.
    *   `window_sum += arr[end]`: `end`가 가리키는 요소를 윈도우에 추가하고 `window_sum`에 더합니다.
3.  **윈도우 축소 (`while window_sum > k`):**
    *   `window_sum`이 `K`를 초과하면, 현재 윈도우는 조건을 만족하지 못합니다.
    *   `while` 루프를 통해 `start` 포인터를 오른쪽으로 이동시키면서 윈도우를 축소합니다.
    *   `window_sum -= arr[start]`: `start`가 가리키는 요소를 윈도우에서 제거하고 `window_sum`에서 뺍니다.
    *   `start += 1`: `start` 포인터를 한 칸 이동시킵니다.
    *   이 `while` 루프는 `window_sum`이 `K` 이하가 될 때까지 반복됩니다.
4.  **최대 길이 갱신:** `while` 루프를 빠져나오면, 현재 `start`부터 `end`까지의 윈도우는 조건을 만족하는 상태(`window_sum <= k`)입니다.
    *   `max_length = max(max_length, end - start + 1)`: 현재 윈도우의 길이(`end - start + 1`)와 `max_length`를 비교하여 더 큰 값으로 갱신합니다.
5.  **반환:** 모든 배열을 탐색한 후, `max_length`를 반환합니다.
