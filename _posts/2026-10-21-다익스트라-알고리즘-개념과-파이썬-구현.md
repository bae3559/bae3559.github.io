# 길 찾기의 마법사, 다익스트라 알고리즘 파헤치기 (개념부터 파이썬 구현까지)

안녕하세요, 개발 블로그 독자 여러분! 🚗💨

복잡한 도시에서 목적지까지 가장 빠른 길을 찾을 때, 혹은 네트워크 상에서 데이터가 최소한의 시간으로 전송될 경로를 정할 때, 여러분은 어떤 방법이 사용될 것이라고 생각하시나요? 바로 이러한 '최단 경로(Shortest Path)' 문제를 해결하는 데 가장 널리 사용되는 알고리즘 중 하나가 바로 **다익스트라(Dijkstra) 알고리즘**입니다!

오늘은 이 다익스트라 알고리즘이 무엇인지, 어떤 원리로 동작하는지, 그리고 파이썬으로 어떻게 구현할 수 있는지 쉽고 친절하게 알아보는 시간을 가지겠습니다. 알고리즘이 어렵게 느껴졌던 초보 개발자분들도 충분히 이해하실 수 있도록 비유를 들어 설명해 드릴게요!

---

## 💡 다익스트라 알고리즘, 넌 누구니?

다익스트라 알고리즘은 1956년 컴퓨터 과학자 에츠허르 다익스트라(Edsger W. Dijkstra)가 고안한 알고리즘으로, **하나의 시작점으로부터 그래프 내의 다른 모든 노드까지의 최단 경로를 찾는 알고리즘**입니다. 마치 내비게이션 앱이 현재 위치에서 목적지까지 가장 빠른 길을 알려주는 것과 똑같은 원리라고 생각하시면 됩니다.

### 핵심 아이디어: 그리디(Greedy)하게 최단 경로 확장!

다익스트라 알고리즘은 '탐욕적(Greedy)'이라는 단어로 설명할 수 있습니다. 각 단계에서 현재까지 발견된 가장 가까운, 방문하지 않은 노드를 선택하여 그 노드를 통해 다른 노드들의 거리를 갱신하는 방식으로 작동합니다. 마치 매번 "지금 갈 수 있는 곳 중에 제일 가까운 곳은 어디지?"라고 물어보고 그곳으로 이동하는 것과 같습니다.

### 준비물: 그래프와 우선순위 큐

다익스트라 알고리즘을 이해하기 위해 몇 가지 용어를 알아봅시다.

*   **그래프 (Graph):** 노드(Node, 정점)와 간선(Edge, 연결선)으로 이루어진 자료구조입니다.
    *   **노드:** 도시, 장소 등을 의미합니다.
    *   **간선:** 도시들을 잇는 도로를 의미합니다.
    *   **가중치 (Weight):** 간선마다 붙어있는 값으로, 거리를 나타냅니다. 예를 들어, A 도시에서 B 도시까지 가는 데 걸리는 시간이나 비용이 될 수 있습니다. (다익스트라는 음수 가중치는 처리하지 못합니다.)
*   **우선순위 큐 (Priority Queue):** 데이터를 삽입할 때 우선순위를 정해서, 가장 우선순위가 높은 데이터를 먼저 꺼내는 자료구조입니다. 다익스트라에서는 '현재까지 발견된 최단 거리가 가장 짧은 노드'를 우선순위로 사용합니다. 이를 통해 항상 가장 효율적인 경로를 탐색할 수 있습니다.

### 👣 다익스트라 알고리즘의 동작 방식 (단계별 설명)

1.  **시작점 설정 및 거리 초기화:**
    *   출발 노드를 정합니다. 출발 노드에서 출발 노드까지의 거리는 `0`으로 설정합니다.
    *   나머지 모든 노드까지의 거리는 일단 `무한대(Infinity)`로 설정합니다. (아직 경로를 모르니까요!)
    *   모든 노드는 '방문하지 않음' 상태입니다.
    *   우선순위 큐에 `(0, 시작 노드)`를 넣습니다. (거리, 노드)

2.  **가장 가까운 미방문 노드 선택:**
    *   우선순위 큐에서 거리가 가장 짧은 노드(즉, 우선순위가 가장 높은 노드)를 꺼냅니다. 이 노드를 `현재 노드`라고 합시다.

3.  **거리 갱신:**
    *   만약 `현재 노드`까지의 거리가 이미 기록된 최단 거리보다 길다면, 이 경로는 더 이상 최단 경로가 아니므로 무시합니다. (이전에 더 짧은 경로를 찾았다는 뜻)
    *   그렇지 않다면, `현재 노드`를 '방문함'으로 표시합니다.
    *   `현재 노드`와 연결된 모든 `인접 노드`들을 살펴봅니다.
    *   `현재 노드`를 거쳐 `인접 노드`로 가는 새로운 경로의 거리를 계산합니다. (`현재 노드`까지의 최단 거리 + `현재 노드`에서 `인접 노드`까지의 간선 가중치)
    *   만약 이 새로운 경로의 거리가 `인접 노드`에 현재 기록된 거리보다 더 짧다면, `인접 노드`의 거리를 이 새로운 거리로 업데이트하고, `(새로운 거리, 인접 노드)`를 우선순위 큐에 넣습니다.

4.  **반복:**
    *   우선순위 큐가 빌 때까지 (즉, 모든 노드에 대한 최단 경로를 찾을 때까지) 2~3단계를 반복합니다.

## 🐍 파이썬으로 구현하는 다익스트라 알고리즘

이제 다익스트라 알고리즘을 파이썬 코드로 구현해 봅시다. 그래프는 인접 리스트(Adjacency List) 방식으로 표현하고, 우선순위 큐는 파이썬의 `heapq` 모듈을 활용할 것입니다.

```python
import heapq

def dijkstra(graph, start):
    # 1. 시작 노드 설정 및 거리 초기화
    # 모든 노드까지의 거리를 무한대로 초기화 (아직 모른다는 뜻)
    # 시작 노드까지의 거리는 0
    distances = {node: float('inf') for node in graph}
    distances[start] = 0

    # 우선순위 큐 초기화 (거리, 노드)
    # 시작 노드를 (0, start)로 큐에 추가
    priority_queue = [(0, start)] # (distance, node)

    # 큐에 노드가 있는 동안 반복
    while priority_queue:
        # 2. 가장 가까운 미방문 노드 선택
        # 우선순위 큐에서 가장 거리가 짧은 노드를 꺼냄
        current_distance, current_node = heapq.heappop(priority_queue)

        # 3. 거리 갱신
        # 현재 큐에서 꺼낸 거리가 이미 저장된 거리(더 짧은 경로)보다 길다면,
        # 더 이상 탐색할 필요가 없음 (이미 더 좋은 경로를 찾았다는 뜻)
        if current_distance > distances[current_node]:
            continue

        # 현재 노드와 연결된 인접 노드들을 탐색
        for neighbor, weight in graph[current_node].items():
            # 현재 노드를 거쳐 인접 노드로 가는 새로운 거리 계산
            distance = current_distance + weight

            # 새로운 거리가 인접 노드에 기록된 거리보다 더 짧다면, 업데이트
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                # 업데이트된 인접 노드를 우선순위 큐에 추가
                heapq.heappush(priority_queue, (distance, neighbor))

    return distances

# 그래프 예시 (인접 리스트 형태, {노드: {인접노드: 가중치}})
graph = {
    'A': {'B': 8, 'C': 1, 'D': 2},
    'B': {},
    'C': {'B': 5, 'D': 2},
    'D': {'E': 3, 'F': 5},
    'E': {'F': 1},
    'F': {'A': 5}
}

# 'A'에서 시작하여 다른 모든 노드까지의 최단 경로를 찾습니다.
start_node = 'A'
shortest_paths = dijkstra(graph, start_node)

print(f"'{start_node}'에서 각 노드까지의 최단 거리:")
for node, distance in shortest_paths.items():
    print(f"  {start_node} -> {node}: {distance}")

```

### 코드 해설

1.  **`import heapq`**: 파이썬의 `heapq` 모듈은 최소 힙(Min-Heap) 기능을 제공하여 우선순위 큐를 구현하는 데 매우 효율적입니다.
2.  **`dijkstra(graph, start)` 함수**: 그래프와 시작 노드를 인자로 받습니다.
3.  **`distances` 딕셔너리**: 각 노드까지의 최단 거리를 저장합니다. 처음에는 시작 노드만 `0`이고 나머지는 `float('inf')` (무한대)로 초기화합니다.
4.  **`priority_queue` 리스트**: `(거리, 노드)` 형태의 튜플을 저장하는 최소 힙입니다. `heapq.heappush()`로 요소를 추가하고 `heapq.heappop()`으로 가장 작은 요소를 꺼냅니다.
5.  **`while priority_queue:`**: 큐가 비어있지 않은 동안 계속해서 탐색합니다.
6.  **`current_distance, current_node = heapq.heappop(priority_queue)`**: 큐에서 가장 짧은 거리를 가진 노드를 꺼냅니다.
7.  **`if current_distance > distances[current_node]: continue`**: 이 조건문이 중요합니다! 우선순위 큐에는 같은 노드에 대한 여러 경로가 들어갈 수 있는데, 이미 더 짧은 경로를 찾아서 `distances`에 업데이트된 상태라면, 현재 꺼낸 경로는 무시하고 다음 것을 탐색합니다.
8.  **`for neighbor, weight in graph[current_node].items():`**: 현재 노드의 모든 인접 노드를 살펴봅니다.
9.  **`distance = current_distance + weight`**: 현재 노드를 거쳐 인접 노드로 가는 새로운 총 거리를 계산합니다.
10. **`if distance < distances[neighbor]:`**: 만약 새로 계산한 거리가 기존에 기록된 `neighbor`까지의 거리보다 짧다면, `distances`를 업데이트하고 `(distance, neighbor)`를 다시 큐에 넣어줍니다.
11. **반환**: 모든 탐색이 끝나면 `distances` 딕셔너리에 시작 노드로부터 각 노드까지의 최단 거리가 담겨 반환됩니다.

### 실행 결과

```
'A'에서 각 노드까지의 최단 거리:
  A -> A: 0
  A -> B: 6
  A -> C: 1
  A -> D: 2
  A -> E: 5
  A -> F: 6
```

## ⏱️ 다익스트라 알고리즘의 시간 복잡도

다익스트라 알고리즘의 시간 복잡도는 그래프의 구현 방식과 우선순위 큐의 구현 방식에 따라 달라집니다. 일반적으로 `O(E log V)` 또는 `O(E + V log V)`로 표현됩니다. 여기서 `V`는 노드의 개수, `E`는 간선의 개수입니다. `heapq`와 같은 이진 힙(Binary Heap) 기반의 우선순위 큐를 사용할 때 이 효율적인 시간 복잡도를 가집니다.

## ⚠️ 다익스트라 알고리즘의 한계

다익스트라 알고리즘은 **간선의 가중치가 음수인 경우에는 올바르게 동작하지 않습니다.** 음수 가중치가 있는 그래프에서는 벨만-포드(Bellman-Ford) 알고리즘이나 SPFA(Shortest Path Faster Algorithm)와 같은 다른 알고리즘을 사용해야 합니다.
