# 초보자를 위한 다익스트라 알고리즘: 개념부터 파이썬 구현까지

안녕하세요! 길을 찾는 알고리즘, 그 중에서도 특히 '최단 경로'를 찾아주는 마법 같은 알고리즘을 배워볼 시간입니다. 여러분이 GPS 앱을 사용하거나, 네트워크에서 데이터가 가장 빠르게 전달되는 경로를 찾거나, 게임에서 캐릭터가 목적지까지 가장 효율적으로 이동하는 방법을 결정할 때, 바로 이 알고리즘이 핵심적인 역할을 합니다. 오늘 우리가 함께 알아볼 주인공은 바로 **다익스트라(Dijkstra) 알고리즘**입니다!

다익스트라 알고리즘은 단일 출발점에서 다른 모든 노드까지의 최단 경로를 찾아주는 강력한 도구입니다. 이름이 조금 어렵게 느껴질 수도 있지만, 걱정 마세요! 초보자도 이해할 수 있도록 친절하게 개념부터 파이썬 코드로 직접 구현하는 방법까지 자세히 설명해 드릴게요.

---

## 🧭 다익스트라 알고리즘이란 무엇인가요?

다익스트라 알고리즘은 **가중치가 있는 방향 또는 무방향 그래프**에서 **하나의 출발 노드로부터 다른 모든 노드까지의 최단 경로**를 찾는 알고리즘입니다. 여기서 '가중치'는 간선(두 노드를 연결하는 선)을 따라 이동하는 데 드는 비용이나 시간 등을 의미하며, 음수 가중치는 허용하지 않습니다.

가장 쉽게 이해할 수 있는 비유는 바로 '가장 저렴한 길 찾아가기'입니다. 마치 새로운 도시에서 택시를 타고 목적지까지 가장 싼 경로를 찾아가는 것과 비슷합니다. 택시 운전사는 매번 갈림길에서 '지금까지 가장 비용이 적게 드는 길'을 선택하며 나아갈 것입니다.

### 🌟 다익스트라 알고리즘의 핵심 아이디어

다익스트라 알고리즘은 기본적으로 **탐욕적인(Greedy) 방식**으로 작동합니다.
1.  **출발점에서 가장 가까운, 아직 방문하지 않은 노드**를 선택합니다.
2.  선택된 노드를 통해 갈 수 있는 이웃 노드들의 최단 거리를 **갱신**합니다.
3.  이 과정을 모든 노드를 방문하거나, 더 이상 갱신할 수 없을 때까지 반복합니다.

이 과정에서 "가장 가까운 노드"를 효율적으로 찾기 위해 **우선순위 큐(Priority Queue)**라는 자료구조가 사용됩니다. 우선순위 큐는 항상 가장 작은 값을 먼저 꺼내주는 자료구조로, 다익스트라 알고리즘의 효율성을 책임지는 핵심 요소입니다.

### 🧩 주요 구성 요소

*   **그래프(Graph):** 노드(정점)와 간선(엣지)으로 이루어진 네트워크 구조.
*   **가중치(Weight):** 간선에 할당된 비용 (시간, 거리 등). 양수여야 합니다.
*   **거리 정보(Distances):** 출발점에서 각 노드까지의 최단 거리를 저장하는 배열 또는 딕셔너리. 초기에는 출발 노드를 제외한 모든 노드의 거리를 무한대로 설정합니다.
*   **방문 여부(Visited Set):** 이미 최단 경로가 확정된 노드를 표시하는 집합 또는 배열. 중복 계산을 방지합니다.
*   **우선순위 큐(Priority Queue):** (거리, 노드) 쌍을 저장하며, 항상 거리가 가장 짧은 노드를 먼저 반환합니다. 파이썬에서는 `heapq` 모듈을 사용해 구현할 수 있습니다.

## 🚀 다익스트라 알고리즘 작동 방식 (단계별 설명)

다익스트라 알고리즘은 다음과 같은 단계를 거쳐 최단 경로를 찾아냅니다.

1.  **초기화:**
    *   출발 노드에서 출발 노드까지의 거리는 `0`으로 설정합니다.
    *   나머지 모든 노드까지의 거리는 `무한대(infinity)`로 설정합니다.
    *   우선순위 큐에 `(거리 0, 출발 노드)`를 넣습니다.

2.  **반복:** 우선순위 큐가 빌 때까지 다음을 반복합니다.
    *   **가장 짧은 노드 선택:** 우선순위 큐에서 가장 거리가 짧은 노드와 그 거리를 꺼냅니다. (`current_distance`, `current_node`)
    *   **방문 확인:** 만약 이미 이 `current_node`에 대해 더 짧은 최단 경로가 발견된 적이 있다면 (즉, 큐에서 꺼낸 `current_distance`가 현재 `distances[current_node]`보다 크다면), 이 경로는 최단 경로가 아니므로 무시하고 다음 반복으로 넘어갑니다. (이 부분은 큐에 중복된 경로가 들어갈 수 있기 때문에 중요합니다!)
    *   **이웃 노드 갱신:** `current_node`와 연결된 모든 이웃 노드들을 살펴봅니다.
        *   `new_distance = current_distance + current_node`에서 `이웃 노드`까지의 간선 가중치
        *   만약 `new_distance`가 `distances[이웃 노드]`에 기록된 현재 거리보다 짧다면, 거리를 `new_distance`로 **업데이트**하고 `(new_distance, 이웃 노드)`를 우선순위 큐에 넣습니다.

3.  **종료:** 우선순위 큐가 비게 되면, `distances` 딕셔너리에는 출발 노드로부터 다른 모든 노드까지의 최단 거리가 저장됩니다.

## 💻 파이썬으로 다익스트라 알고리즘 구현하기

이제 이론을 바탕으로 파이썬 코드를 작성해 볼 시간입니다! 우리는 그래프를 딕셔너리의 딕셔너리 형태로 표현하고, `heapq` 모듈을 사용하여 우선순위 큐를 구현할 것입니다.

```python
import heapq

def dijkstra(graph, start):
    # 1. 거리 정보 초기화: 모든 노드까지의 거리를 무한대로 설정
    #    출발 노드까지의 거리는 0으로 설정
    distances = {node: float('inf') for node in graph}
    distances[start] = 0

    # 2. 우선순위 큐 초기화: (거리, 노드) 형태로 저장하며, 거리가 짧은 노드가 우선
    #    힙(heap) 자료구조를 사용하여 우선순위 큐를 구현합니다.
    priority_queue = [(0, start)] # (거리, 노드)

    # 3. 우선순위 큐가 빌 때까지 반복
    while priority_queue:
        # 가장 거리가 짧은 노드 정보 (거리, 노드)를 큐에서 꺼냅니다.
        current_distance, current_node = heapq.heappop(priority_queue)

        # 현재 노드까지의 거리가 이미 기록된 최단 거리보다 길다면,
        # 이 경로는 최단 경로가 아니므로 무시합니다. (중복 경로 처리)
        if current_distance > distances[current_node]:
            continue

        # 현재 노드와 연결된 모든 이웃 노드를 탐색합니다.
        for neighbor, weight in graph[current_node].items():
            # 현재 노드를 거쳐 이웃 노드까지 가는 새로운 거리 계산
            distance = current_distance + weight

            # 새로운 거리가 기존에 알려진 이웃 노드까지의 거리보다 짧다면,
            # 거리 정보를 업데이트하고 우선순위 큐에 추가합니다.
            if distance < distances[neighbor]:
                distances[neighbor] = distance
                heapq.heappush(priority_queue, (distance, neighbor))

    return distances

# --- 예제 그래프 정의 ---
# 그래프는 딕셔너리로 표현합니다.
# 각 노드에 대해 이웃 노드와 해당 간선의 가중치를 또 다른 딕셔너리로 저장합니다.
graph = {
    'A': {'B': 1, 'C': 4},
    'B': {'A': 1, 'C': 2, 'D': 5},
    'C': {'A': 4, 'B': 2, 'D': 1},
    'D': {'B': 5, 'C': 1}
}

# --- 다익스트라 알고리즘 실행 ---
start_node = 'A'
shortest_paths = dijkstra(graph, start_node)

# --- 결과 출력 ---
print(f"출발 노드 '{start_node}'로부터 각 노드까지의 최단 거리:")
for node, distance in shortest_paths.items():
    if distance == float('inf'):
        print(f"  {node}: 도달 불가능")
    else:
        print(f"  {node}: {distance}")

# 다른 출발 노드로 테스트
print("\n--- 출발 노드 'B'로 변경 ---")
start_node_B = 'B'
shortest_paths_B = dijkstra(graph, start_node_B)
print(f"출발 노드 '{start_node_B}'로부터 각 노드까지의 최단 거리:")
for node, distance in shortest_paths_B.items():
    if distance == float('inf'):
        print(f"  {node}: 도달 불가능")
    else:
        print(f"  {node}: {distance}")
```

### 🧐 코드 설명

1.  **`import heapq`**: 파이썬의 `heapq` 모듈은 최소 힙(min-heap) 기능을 제공하여 우선순위 큐를 쉽게 구현할 수 있도록 돕습니다. `heapq.heappush()`는 원소를 힙에 추가하고, `heapq.heappop()`은 힙에서 가장 작은 원소를 꺼냅니다.
2.  **`distances` 초기화**: 모든 노드에 대한 거리를 `float('inf')` (무한대)로 설정하고, 시작 노드만 `0`으로 설정합니다. `float('inf')`는 어떤 숫자보다도 큰 값을 의미합니다.
3.  **`priority_queue` 초기화**: 시작 노드와 그 거리(`(0, start)`)를 튜플 형태로 우선순위 큐에 추가합니다. `heapq`는 튜플의 첫 번째 요소를 기준으로 정렬하기 때문에 `(거리, 노드)` 순서로 넣는 것이 중요합니다.
4.  **`while priority_queue:`**: 큐가 비어있지 않은 동안 반복합니다. 즉, 아직 탐색할 경로가 남아있는 동안 계속 진행합니다.
5.  **`current_distance, current_node = heapq.heappop(priority_queue)`**: 큐에서 현재까지 발견된 가장 짧은 거리와 해당 노드를 꺼냅니다.
6.  **`if current_distance > distances[current_node]: continue`**: 이 부분은 매우 중요합니다! 우선순위 큐에는 같은 노드에 대한 여러 경로가 다른 거리 값으로 들어갈 수 있습니다. 이 조건문은 이미 더 짧은 경로를 찾았을 경우, 큐에서 꺼낸 오래되거나 비효율적인 경로를 무시하도록 합니다.
7.  **`for neighbor, weight in graph[current_node].items():`**: 현재 노드에 연결된 모든 이웃 노드를 순회합니다.
8.  **`distance = current_distance + weight`**: 현재 노드를 거쳐 이웃 노드까지 가는 새로운 경로의 총 거리를 계산합니다.
9.  **`if distance < distances[neighbor]:`**: 새로 계산한 거리가 현재 `distances`에 기록된 이웃 노드까지의 최단 거리보다 짧다면, `distances`를 업데이트하고 새로운 `(거리, 노드)` 쌍을 우선순위 큐에 추가합니다.

## 💡 다익스트라 알고리즘의 시간 복잡도와 제약 사항

*   **시간 복잡도**: 일반적으로 우선순위 큐(힙)를 사용할 경우, `O(E log V)` 또는 `O(E + V log V)`의 시간 복잡도를 가집니다. 여기서 `V`는 노드의 개수, `E`는 간선의 개수입니다. 이는 대부분의 경우 매우 효율적인 성능을 보여줍니다.
*   **제약 사항**: 다익스트라 알고리즘은 **음수 가중치를 가진 간선이 있는 그래프에서는 올바르게 작동하지 않습니다.** 음수 가중치 간선이 있는 경우에는 벨만-포드(Bellman-Ford) 알고리즘과 같은 다른 알고리즘을 사용해야 합니다.
