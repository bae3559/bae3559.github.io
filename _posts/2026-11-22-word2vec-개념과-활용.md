# Word2Vec, 단어의 숨겨진 의미를 찾아 떠나는 여정

안녕하세요, 여러분! 자연어 처리(Natural Language Processing, NLP)의 세계에 오신 것을 환영합니다.
우리는 매일 언어를 사용하며 소통하지만, 컴퓨터는 우리가 쓰는 '말'을 어떻게 이해할까요? 컴퓨터는 숫자로만 생각한다는 사실을 알고 계신가요? "사과"라는 단어가 "바나나"와 어떻게 비슷한지, "왕"에서 "남자"를 빼고 "여자"를 더하면 왜 "여왕"이 되는지 컴퓨터는 알지 못합니다.

하지만 인공지능이 우리 말을 이해하고 추론할 수 있다면 어떨까요? 추천 시스템, 챗봇, 번역기 등 수많은 멋진 기술들이 가능해지겠죠. 오늘 우리는 컴퓨터가 단어의 의미를 파악하고, 단어들 간의 관계를 수치로 표현할 수 있게 해준 혁신적인 기술, 바로 **Word2Vec**에 대해 이야기해보려 합니다.

초보자분들도 쉽게 이해하실 수 있도록, Word2Vec이 무엇인지부터 어떻게 동작하는지, 그리고 실제 코드로 어떻게 활용하는지까지 친절하게 설명해 드릴게요!

---

## 1. Word2Vec, 왜 필요할까요? (단어는 어떻게 표현되었을까?)

과거에는 단어를 컴퓨터에게 알려주기 위해 '원-핫 인코딩(One-Hot Encoding)'이라는 방법을 주로 사용했습니다. 예를 들어, 우리 사전(corpus)에 "사과", "바나나", "코끼리" 세 단어가 있다고 해볼게요.

- 사과: `[1, 0, 0]`
- 바나나: `[0, 1, 0]`
- 코끼리: `[0, 0, 1]`

각 단어는 고유한 자리에 1을 가지는 벡터로 표현됩니다. 간단하죠? 하지만 이 방법에는 치명적인 단점이 있습니다.
1.  **희소성(Sparsity):** 단어의 수가 많아질수록 벡터의 길이가 엄청나게 길어지고 대부분 0으로 채워집니다. 이는 비효율적입니다.
2.  **의미 관계 부재:** "사과"와 "바나나"는 둘 다 '과일'이라는 공통점이 있지만, 위 벡터로는 둘 사이에 어떤 관계도 알 수 없습니다. 그저 서로 다른 단어일 뿐이죠. 이는 컴퓨터가 단어의 의미를 이해하고 추론하는 데 큰 걸림돌이 됩니다.

Word2Vec은 이러한 한계를 극복하고 단어의 '의미'를 효과적으로 표현하기 위해 등장했습니다.

---

## 2. Word2Vec은 무엇일까요? (핵심 아이디어!)

Word2Vec의 핵심 아이디어는 매우 간단하면서도 강력합니다.

> **"비슷한 문맥(Context)에 나타나는 단어들은 비슷한 의미를 가진다."**

이 아이디어를 통해 Word2Vec은 각 단어를 **밀집 벡터(Dense Vector)**, 혹은 **단어 임베딩(Word Embedding)**이라고 불리는 숫자들의 배열로 변환합니다. 이 벡터는 단어의 여러 특징을 함축하고 있는 '좌표'와 같다고 생각하시면 됩니다.

예를 들어, "사과"라는 단어는 "새콤하다", "달콤하다", "빨갛다", "과일" 같은 특징들을 가지고 있겠죠? Word2Vec이 만들어내는 벡터는 이러한 특징들을 여러 차원의 숫자로 표현합니다. 이 벡터 공간에서 의미적으로 유사한 단어들은 서로 가까운 곳에 위치하게 됩니다.

더 나아가, Word2Vec은 단어들 간의 복잡한 의미 관계까지 포착합니다. 유명한 예시로는 다음과 같은 관계식이 있습니다.

`King - Man + Woman = Queen`

"왕"을 나타내는 벡터에서 "남자" 벡터를 빼고 "여자" 벡터를 더하면, 놀랍게도 "여왕"을 나타내는 벡터와 매우 유사한 벡터가 나타난다는 것이죠! 이것은 Word2Vec이 단순한 유사성을 넘어, 단어들 사이의 '관계'까지도 학습한다는 것을 보여줍니다.

---

## 3. Word2Vec은 어떻게 동작할까요? (아주 살짝 엿보기)

Word2Vec은 사실 아주 간단한 신경망 모델을 사용합니다. 크게 두 가지 학습 방식이 있습니다.

1.  **CBOW (Continuous Bag of Words):** 주변 단어들을 보고 중간에 올 단어를 예측하는 방식입니다.
    *   예시: `[나는, ___를, 좋아한다]` 에서 `사과`를 예측
2.  **Skip-gram:** 특정 단어를 보고 주변에 어떤 단어들이 올지 예측하는 방식입니다. (가장 흔하게 사용됩니다.)
    *   예시: `사과`를 보고 `[나는, ___를, 좋아한다]` 에서 `나는`, `를`, `좋아한다`를 예측

이 신경망은 단어 예측을 잘 수행하도록 학습되면서, 부수적으로 각 단어의 '숨겨진 의미'를 담고 있는 벡터(임베딩)를 만들어냅니다. 학습이 끝나면, 우리는 이 신경망의 가중치(weight)에서 각 단어에 해당하는 벡터를 추출하여 사용하게 됩니다.

이 과정에서 수많은 단어들이 서로의 문맥을 통해 학습되기 때문에, 최종적으로 얻어진 단어 벡터들은 풍부한 의미 정보를 담게 됩니다.

## 4. Word2Vec 실전 활용 (코드 예제)

자, 이제 파이썬의 `gensim` 라이브러리를 사용하여 Word2Vec 모델을 직접 만들어보고 활용해봅시다. `gensim`은 Word2Vec을 비롯한 다양한 토픽 모델링 및 워드 임베딩 기능을 제공하는 강력한 라이브러리입니다.

먼저, `gensim` 라이브러리가 없다면 설치해주세요.
```bash
pip install gensim
```

다음은 간단한 예제 코드입니다.

```python
from gensim.models import Word2Vec
import numpy as np

# 1. 학습할 문장 데이터 준비 (토큰화된 형태)
# 각 문장을 단어 리스트로 나누는 '토큰화' 과정이 필요합니다.
sentences = [
    "저는 사과를 좋아합니다",
    "바나나는 맛있어요",
    "과일은 건강에 좋습니다",
    "코끼리는 동물입니다",
    "사자는 야생 동물이에요",
    "강아지는 귀여운 동물입니다",
    "개와 고양이는 반려동물입니다"
]

# 텍스트 전처리: 각 문장을 띄어쓰기 기준으로 단어 리스트로 분리 (토큰화)
tokenized_sentences = [s.split() for s in sentences]
print("토큰화된 문장:", tokenized_sentences)

# 2. Word2Vec 모델 학습
# vector_size: 임베딩 벡터의 차원 (단어를 몇 차원으로 표현할 것인가? 보통 50~300 사이)
# window: 주변 단어를 몇 개까지 볼 것인가? (타겟 단어 기준 앞뒤로 몇 칸)
# min_count: 최소 등장 횟수 (이 횟수 미만으로 등장한 단어는 학습에서 제외)
# workers: 학습에 사용할 스레드(CPU 코어) 수 (병렬 처리)
# sg: 0이면 CBOW, 1이면 Skip-gram (여기서는 Skip-gram 선택)
model = Word2Vec(tokenized_sentences, vector_size=50, window=2, min_count=1, workers=4, sg=1)

# 모델 학습 완료 후 단어 벡터에 접근
print("\n학습된 단어의 수:", len(model.wv.index_to_key))

# 3. 결과 확인

# '사과' 단어의 벡터 확인 (50차원 벡터)
# 이 벡터는 '사과'의 의미를 숫자로 표현한 것입니다.
print("\n'사과' 단어의 벡터 (일부):\n", model.wv['사과'][:5], "...") # 너무 길어서 앞부분만 출력

# 두 단어 간의 유사도 확인 (0~1 사이 값, 1에 가까울수록 유사)
print("\n'사과'와 '바나나'의 유사도:", model.wv.similarity('사과', '바나나'))
print("'사과'와 '동물'의 유사도:", model.wv.similarity('사과', '동물'))
print("'강아지'와 '고양이'의 유사도:", model.wv.similarity('강아지', '고양이'))
print("'개'와 '강아지'의 유사도:", model.wv.similarity('개', '강아지'))


# 특정 단어와 가장 유사한 단어들을 찾아보기
# 우리가 정의한 짧은 문장들로 학습했기 때문에, 아주 정확하지는 않지만
# '동물'과 관련된 단어들이 나오는 것을 볼 수 있습니다.
print("\n'동물'과 가장 유사한 단어들:", model.wv.most_similar('동물'))
print("\n'과일'과 가장 유사한 단어들:", model.wv.most_similar('과일'))

# (선택사항) 존재하지 않는 단어 처리
# 학습되지 않은 단어를 조회하면 KeyError가 발생합니다.
try:
    print("\n'자동차' 단어의 벡터:\n", model.wv['자동차'])
except KeyError:
    print("\n'자동차' 단어는 학습된 단어 사전에 없습니다. (min_count 기준 미달 또는 존재하지 않는 단어)")

```

**코드 해설:**

1.  **데이터 준비:** `sentences` 리스트는 Word2Vec이 학습할 텍스트 데이터입니다. 각 문장을 `split()` 함수를 이용해 단어 단위로 분리(토큰화)하여 `tokenized_sentences`를 만듭니다. Word2Vec은 단어 리스트의 리스트 형태를 입력으로 받습니다.
2.  **모델 학습:**
    *   `Word2Vec()` 객체를 생성하고 `tokenized_sentences`를 넣어 학습을 시작합니다.
    *   `vector_size=50`: 각 단어를 50차원의 벡터로 표현하겠다는 의미입니다. 숫자가 클수록 더 많은 의미를 담을 수 있지만, 학습 시간이 길어지고 많은 데이터가 필요합니다.
    *   `window=2`: 타겟 단어 주변으로 앞뒤 2개 단어를 문맥으로 고려하겠다는 의미입니다.
    *   `min_count=1`: 최소 1번 이상 등장한 단어만 학습에 포함합니다. 등장 횟수가 너무 적은 단어는 의미 있는 벡터를 만들기 어렵기 때문에 보통 더 높은 값을 사용합니다.
    *   `sg=1`: Skip-gram 방식을 사용하겠다는 의미입니다. `sg=0`으로 설정하면 CBOW 방식을 사용합니다.
3.  **결과 확인:**
    *   `model.wv['단어']`: 특정 단어의 벡터를 얻을 수 있습니다.
    *   `model.wv.similarity('단어1', '단어2')`: 두 단어의 코사인 유사도(cosine similarity)를 계산하여 의미적 유사성을 숫자로 보여줍니다.
    *   `model.wv.most_similar('단어')`: 특정 단어와 가장 유사한 단어들을 리스트로 반환합니다.

**주의:** 위 예제는 매우 적은 데이터로 학습했기 때문에, "사과"와 "바나나"의 유사도가 기대만큼 높지 않거나, "동물"과 가장 유사한 단어들이 직관적이지 않을 수 있습니다. 실제 서비스에서는 훨씬 방대한 양의 텍스트 데이터(수십만~수백만 문장)로 학습해야 의미 있는 결과를 얻을 수 있습니다.

## 5. Word2Vec, 어디에 활용될까요?

Word2Vec이 만들어내는 단어 임베딩은 다양한 NLP 태스크에서 강력한 성능을 발휘합니다.

*   **추천 시스템 (Recommendation Systems):** 사용자가 좋아한 영화/상품의 단어 벡터와 유사한 다른 영화/상품을 추천.
*   **감성 분석 (Sentiment Analysis):** 긍정/부정 단어의 벡터를 분석하여 텍스트의 감성을 파악.
*   **기계 번역 (Machine Translation):** 언어 간의 단어 의미를 연결하여 번역 품질 향상.
*   **챗봇, 질의응답 시스템 (Chatbots, Q&A Systems):** 질문의 의도를 파악하고 적절한 답변을 찾는 데 활용.
*   **텍스트 분류 (Text Classification):** 이메일 스팸 분류, 뉴스 기사 카테고리 분류 등.

---

## 마무리하며

오늘은 Word2Vec이 무엇인지, 왜 필요한지, 그리고 어떻게 동작하는지 개념부터 간단한 코드 예제까지 살펴보았습니다. Word2Vec은 컴퓨터가 단어의 숨겨진 의미를 파악하고, 단어들 간의 복잡한 관계를 이해할 수 있게 해준 혁신적인 기술입니다.

물론 Word2Vec 이후에도 FastText, GloVe, 그리고 BERT, GPT 같은 더 복잡하고 강력한 언어 모델들이 많이 등장했습니다. 하지만 Word2Vec은 단어 임베딩의 개념을 대중화하고, 현대 자연어 처리의 기반을 다진 중요한 기술임에 틀림없습니다.

이 글이 여러분이 자연어 처리의 첫걸음을 떼는 데 도움이 되었기를 바랍니다. Word2Vec은 단어의 의미를 수치화하여 컴퓨터가 이해하게 만드는 첫걸음입니다. 여러분도 자신만의 텍스트 데이터를 가지고 Word2Vec의 마법을 경험해보세요!
