## 🧐 플로이드-워셜 알고리즘, 넌 누구냐?

플로이드-워셜 알고리즘은 그래프에서 **'모든 정점 쌍' 간의 최단 경로**를 찾는 알고리즘입니다. 다른 최단 경로 알고리즘인 다익스트라(Dijkstra)나 벨만-포드(Bellman-Ford)가 특정 시작점에서 다른 모든 정점으로의 최단 경로를 찾는 것과는 다르게, 플로이드-워셜은 출발점과 도착점의 모든 조합에 대한 최단 경로를 한 번에 계산해냅니다.

이 알고리즘의 핵심 아이디어는 **'경유지(intermediate node)'**를 하나씩 늘려가면서 최단 거리를 갱신하는 **동적 계획법(Dynamic Programming)** 방식입니다.

조금 더 쉽게 설명해볼게요.
서울에서 부산으로 가는 최단 경로를 찾는다고 가정해봅시다. 처음에는 서울에서 부산으로 직접 가는 길(직항)이 있을 수도 있고, 아니면 대구로 경유해서 가는 길, 대전으로 경유해서 가는 길 등 여러 가지 방법이 있겠죠? 플로이드-워셜은 모든 도시(정점)를 한 번씩 '경유지'로 사용하면서, 현재까지 알아낸 최단 경로보다 더 짧은 경로가 있는지 확인하고 갱신하는 과정을 반복합니다.

### 핵심 아이디어: `dist[i][j]` = `min(dist[i][j], dist[i][k] + dist[k][j])`

이 한 줄이 플로이드-워셜 알고리즘의 모든 것을 담고 있다고 해도 과언이 아닙니다.
*   `dist[i][j]`: 현재까지 `i`에서 `j`로 가는 최단 거리.
*   `dist[i][k]`: `i`에서 `k`로 가는 최단 거리.
*   `dist[k][j]`: `k`에서 `j`로 가는 최단 거리.

이 식의 의미는 이렇습니다.
"**`i`에서 `j`로 가는 최단 경로는, 현재 알고 있는 `i`에서 `j`로의 최단 경로와, `k`라는 정점을 경유하여 `i`에서 `k`를 거쳐 `j`로 가는 경로 중 더 짧은 것으로 갱신한다!**"

여기서 `k`는 0부터 시작하여 그래프의 모든 정점을 하나씩 '경유지'로 활용하게 됩니다.

## 🛠️ 알고리즘 동작 방식 (단계별 설명)

플로이드-워셜 알고리즘은 크게 두 단계로 나뉩니다.

### 1. 초기화 (Initialization)

*   `N x N` 크기의 2차원 배열 `dist`를 만듭니다. `dist[i][j]`는 `i`에서 `j`로 가는 최단 거리를 저장할 공간입니다.
*   **자기 자신으로의 거리:** `dist[i][i]`는 항상 `0`으로 초기화합니다. (자기 자신으로 가는 데 드는 비용은 없으니까요!)
*   **직접 연결된 간선:** `i`에서 `j`로 직접 연결된 간선이 있다면, 그 간선의 가중치(비용)로 `dist[i][j]`를 초기화합니다.
*   **연결되지 않은 간선:** `i`에서 `j`로 직접 연결된 간선이 없다면, `dist[i][j]`를 `무한대(Infinity)`로 초기화합니다. (아직 갈 수 있는 길을 찾지 못했다는 의미입니다.)

### 2. 최단 거리 갱신 (Core Logic)

이제 모든 정점 `k`를 '경유지'로 사용하며 최단 거리를 갱신합니다. 이 과정은 **3중 for 문**으로 이루어집니다.

```
for k from 0 to N-1:  // k: 경유지 (intermediate node)
    for i from 0 to N-1:  // i: 출발점 (source node)
        for j from 0 to N-1:  // j: 도착점 (destination node)
            // i에서 k를 거쳐 j로 가는 경로가 현재 i에서 j로 가는 경로보다 짧다면 갱신
            dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
```

**중요 포인트:** `k` 루프가 가장 바깥쪽에 있어야 합니다!
`k`가 가장 바깥에 있다는 것은, 0번 정점을 경유지로 사용할 수 있는 모든 경우를 먼저 계산하고, 그 다음 1번 정점을 경유지로 사용할 수 있는 모든 경우를 계산... 하는 식으로 진행된다는 의미입니다. 이렇게 해야 `dist[i][k]`와 `dist[k][j]` 값들이 항상 최신의, 즉 `k`까지의 경유 정점들을 고려한 최단 거리 값이 되기 때문입니다.

## ✅ 플로이드-워셜의 장점과 단점

### 장점
*   **모든 쌍 최단 경로:** 한 번의 실행으로 모든 정점 쌍 간의 최단 경로를 얻을 수 있습니다.
*   **구현 간편:** 3중 for 문이라는 간단한 구조로 구현이 직관적입니다.
*   **음수 가중치 간선 처리:** 벨만-포드처럼 음수 가중치를 가진 간선도 처리할 수 있습니다. (음수 사이클만 아니라면)
*   **음수 사이클 감지:** 그래프에 음수 사이클이 존재하는 경우, `dist[i][i]` 값이 음수가 되는 것을 통해 이를 감지할 수 있습니다.

### 단점
*   **시간 복잡도:** `O(N^3)`으로, 정점의 개수 `N`이 많아질수록 계산 시간이 급격히 늘어납니다. (보통 N <= 400~500 정도에서 사용하기 적합)
*   **공간 복잡도:** `O(N^2)`로, `N`이 크면 많은 메모리가 필요할 수 있습니다.

## 💻 파이썬으로 구현하는 플로이드-워셜 알고리즘 예제

이제 파이썬 코드로 직접 구현해보면서 이해를 더 확실히 해볼까요?

```python
# 무한대를 나타내는 값 (연결되지 않은 간선)
INF = float('inf')

def floyd_warshall(graph):
    """
    플로이드-워셜 알고리즘을 사용하여 모든 정점 쌍 간의 최단 경로를 계산합니다.

    Args:
        graph (list[list[int]]): 인접 행렬 형태의 그래프.
                                 graph[i][j]는 i에서 j로 가는 직접 간선의 가중치.
                                 연결되어 있지 않으면 INF.

    Returns:
        list[list[int]]: 모든 정점 쌍 간의 최단 거리를 담은 2차원 배열.
    """
    n = len(graph)
    
    # 거리 테이블 초기화: graph를 그대로 복사
    # 파이썬의 리스트 복사에 주의 (깊은 복사 필요)
    dist = [[graph[i][j] for j in range(n)] for i in range(n)]

    # k: 경유하는 노드 (intermediate node)
    for k in range(n):
        # i: 출발 노드 (source node)
        for i in range(n):
            # j: 도착 노드 (destination node)
            for j in range(n):
                # i -> k -> j 경로가 현재 i -> j 경로보다 짧은지 확인
                # 무한대 + 어떤 수는 무한대이므로, 무한대 경로를 거치지 않도록 조건 추가
                if dist[i][k] != INF and dist[k][j] != INF:
                    dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])
    
    # 음수 사이클 감지 (선택 사항)
    # 자기 자신으로 돌아오는 경로가 음수가 되었다면, 해당 노드를 포함하는 음수 사이클이 존재한다는 뜻
    for i in range(n):
        if dist[i][i] < 0:
            print(f"경고: 노드 {i}를 포함하는 음수 사이클이 감지되었습니다.")
            # 음수 사이클이 있는 경우 최단 경로가 정의되지 않으므로,
            # 특정 처리를 해주거나 에러를 발생시킬 수 있습니다.
            # 이 예제에서는 경고 메시지만 출력합니다.

    return dist

# --- 예제 그래프 ---
# 0번 노드부터 3번 노드까지 총 4개의 노드
# 값은 가중치 (비용), INF는 연결되지 않음을 의미
# graph[i][j]는 i에서 j로 가는 직접 경로의 가중치
example_graph = [
    [0, 1, INF, INF],     # 0 -> 0 (0), 0 -> 1 (1)
    [INF, 0, 1, INF],     # 1 -> 1 (0), 1 -> 2 (1)
    [INF, INF, 0, 1],     # 2 -> 2 (0), 2 -> 3 (1)
    [2, INF, INF, 0]      # 3 -> 0 (2), 3 -> 3 (0)
]

print("--- 초기 그래프 (인접 행렬) ---")
for row in example_graph:
    print([val if val != INF else 'INF' for val in row])

# 플로이드-워셜 알고리즘 실행
shortest_paths = floyd_warshall(example_graph)

print("\n--- 모든 쌍 최단 경로 결과 ---")
for r_idx, row in enumerate(shortest_paths):
    for c_idx, val in enumerate(row):
        if val == INF:
            print(f"{r_idx} -> {c_idx}: INF", end='\t')
        else:
            print(f"{r_idx} -> {c_idx}: {val}", end='\t')
    print()

print("\n--- 결과 테이블 ---")
for row in shortest_paths:
    print([val if val != INF else 'INF' for val in row])

# --- 음수 가중치 및 음수 사이클 예제 ---
print("\n--- 음수 가중치 및 사이클 예제 ---")
negative_cycle_graph = [
    [0, 1, INF],
    [INF, 0, -2],
    [-1, INF, 0] # 2 -> 0 (-1), 원래 0 -> 1 (1), 1 -> 2 (-2) => 0 -> 1 -> 2 -> 0 의 사이클이 -2이다.
]

print("\n--- 초기 그래프 (음수 사이클 포함) ---")
for row in negative_cycle_graph:
    print([val if val != INF else 'INF' for val in row])

shortest_paths_neg = floyd_warshall(negative_cycle_graph)

print("\n--- 모든 쌍 최단 경로 결과 (음수 사이클 포함) ---")
for r_idx, row in enumerate(shortest_paths_neg):
    for c_idx, val in enumerate(row):
        if val == INF:
            print(f"{r_idx} -> {c_idx}: INF", end='\t')
        else:
            print(f"{r_idx} -> {c_idx}: {val}", end='\t')
    print()
print("\n--- 결과 테이블 (음수 사이클 포함) ---")
for row in shortest_paths_neg:
    print([val if val != INF else 'INF' for val in row])
```

### 코드 설명:
1.  **`INF = float('inf')`**: 파이썬에서 무한대를 나타내는 편리한 방법입니다.
2.  **`dist` 초기화**: 입력 `graph`를 `dist` 배열로 복사합니다. 이때 리스트의 깊은 복사를 사용해야 원본 `graph`가 변경되지 않습니다. `[[graph[i][j] for j in range(n)] for i in range(n)]` 이 구문이 깊은 복사를 수행합니다.
3.  **3중 루프**: `k`, `i`, `j` 순서대로 반복문을 돌며 최단 거리를 갱신합니다.
4.  **`if dist[i][k] != INF and dist[k][j] != INF:`**: 이 조건문은 매우 중요합니다. 만약 `dist[i][k]`나 `dist[k][j]`가 `INF`라면, 해당 경로는 아직 발견되지 않은 길이거나 너무 멀어서 유효하지 않습니다. `INF + 어떤 값`은 여전히 `INF`이지만, 실수로 `INF`가 아닌 값으로 계산되는 것을 방지하고, 불필요한 계산을 줄이는 효과도 있습니다.
5.  **`dist[i][j] = min(dist[i][j], dist[i][k] + dist[k][j])`**: 앞서 설명한 핵심 로직입니다.
6.  **음수 사이클 감지**: 알고리즘 실행 후 `dist[i][i]` 값이 0보다 작아졌다면, 이는 `i`를 포함하는 음수 사이클이 존재한다는 것을 의미합니다. 실제 최단 경로는 음수 사이클이 있는 경우 정의되지 않으므로, 이를 감지하고 적절히 처리해야 합니다.
