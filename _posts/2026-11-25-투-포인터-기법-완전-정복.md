# 투 포인터 기법 완전 정복: 효율적인 알고리즘의 비밀 무기

오늘은 코딩 테스트나 알고리즘 문제 풀이에서 여러분의 문제 해결 능력을 한 단계 업그레이드해 줄 마법 같은 기법, 바로 '투 포인터(Two Pointers)'에 대해 이야기해보려 합니다. 이 기법을 제대로 이해하고 나면, "와, 이렇게 간단하게 해결할 수 있다고?"라는 감탄사가 절로 나올 거예요. 초보자분들도 쉽게 이해할 수 있도록 친절하고 자세하게 설명해 드릴 테니, 걱정 말고 저와 함께 투 포인터의 세계로 떠나봅시다!

## 💡 투 포인터(Two Pointers) 기법이란?

투 포인터 기법은 이름 그대로 두 개의 포인터(또는 인덱스)를 사용하여 배열, 리스트, 문자열과 같은 순차적인 데이터 구조에서 특정 조건을 만족하는 요소를 찾거나, 데이터를 조작하는 알고리즘 패턴입니다. 마치 두 손가락으로 책을 읽거나, 두 명의 탐정이 협력해서 범인을 추적하듯이, 두 포인터가 서로 다른 위치에서 데이터를 탐색하며 문제를 효율적으로 해결하는 것이죠.

**왜 효율적일까요?**
일반적으로 배열에서 특정 조건을 만족하는 쌍을 찾거나 조작할 때, 우리는 이중 반복문(nested loops)을 사용하는 경우가 많습니다. 예를 들어, `n`개의 요소가 있는 배열에서 두 요소를 조합하는 경우 O(N^2)의 시간 복잡도가 발생하죠. 하지만 투 포인터 기법을 사용하면 대부분의 경우 O(N)의 시간 복잡도로 문제를 해결할 수 있습니다. 이는 특히 대규모 데이터 처리에서 엄청난 차이를 만들어냅니다!

투 포인터 기법은 크게 두 가지 패턴으로 나눌 수 있습니다.

1.  **양 끝에서 시작하여 가운데로 이동하는 포인터 (Opposite Direction Pointers)**
2.  **동일한 방향으로 이동하는 포인터 (Same Direction Pointers)**

각 패턴별로 예시 코드를 통해 자세히 알아보겠습니다.

---

## 1. 양 끝에서 시작하여 가운데로 이동하는 포인터

이 패턴은 주로 정렬된 배열이나 리스트에서 특정 조건을 만족하는 두 요소를 찾거나, 배열 전체를 뒤집는 등의 작업을 할 때 유용합니다. `left` 포인터는 배열의 시작(인덱스 0)에서, `right` 포인터는 배열의 끝(인덱스 `len(arr) - 1`)에서 시작하여 서로를 향해 이동합니다.

### 예시 1: 리스트 뒤집기 (Reverse a List)

가장 간단하면서도 직관적인 예시입니다. 리스트의 양 끝 값을 서로 교환하며 포인터를 이동시키면 리스트를 뒤집을 수 있습니다.

**문제:** `[1, 2, 3, 4, 5]`를 `[5, 4, 3, 2, 1]`로 뒤집으시오.

```python
def reverse_list(arr):
    left = 0              # 왼쪽 포인터는 0에서 시작
    right = len(arr) - 1  # 오른쪽 포인터는 리스트의 마지막 인덱스에서 시작

    while left < right:   # 왼쪽 포인터가 오른쪽 포인터보다 작을 때까지 (서로 엇갈리기 전까지)
        # 두 포인터가 가리키는 값을 교환 (swap)
        arr[left], arr[right] = arr[right], arr[left]
        
        left += 1         # 왼쪽 포인터는 오른쪽으로 한 칸 이동
        right -= 1        # 오른쪽 포인터는 왼쪽으로 한 칸 이동
    return arr

# 예시 사용
my_list = [1, 2, 3, 4, 5]
print(f"원본 리스트: {my_list}")
reversed_list = reverse_list(my_list)
print(f"뒤집은 리스트: {reversed_list}")

my_another_list = ['a', 'b', 'c', 'd']
print(f"원본 리스트: {my_another_list}")
reversed_another_list = reverse_list(my_another_list)
print(f"뒤집은 리스트: {reversed_another_list}")
```

**설명:**
`left`와 `right`가 서로 만나거나 엇갈리기 전까지, `left`가 가리키는 값과 `right`가 가리키는 값을 교환하고 각 포인터를 한 칸씩 이동시킵니다. 이 과정을 통해 전체 리스트를 O(N) 시간 복잡도로 뒤집을 수 있습니다.

### 예시 2: 팰린드롬 문자열 확인 (Check Palindrome String)

팰린드롬이란 앞으로 읽으나 뒤로 읽으나 동일한 문자열(예: "racecar", "madam")을 의미합니다. 투 포인터를 사용하여 효율적으로 확인할 수 있습니다.

**문제:** 주어진 문자열이 팰린드롬인지 확인하시오.

```python
def is_palindrome(s):
    left = 0              # 왼쪽 포인터는 문자열의 시작
    right = len(s) - 1    # 오른쪽 포인터는 문자열의 끝

    while left < right:   # 왼쪽 포인터가 오른쪽 포인터보다 작을 때까지
        if s[left] != s[right]: # 양 끝의 문자가 다르면 팰린드롬이 아님
            return False
        left += 1         # 왼쪽 포인터 이동
        right -= 1        # 오른쪽 포인터 이동
    return True           # 모든 문자가 동일했으므로 팰린드롬

# 예시 사용
print(f"'racecar' 팰린드롬인가요? {is_palindrome('racecar')}")
print(f"'hello' 팰린드롬인가요? {is_palindrome('hello')}")
print(f"'level' 팰린드롬인가요? {is_palindrome('level')}")
```

**설명:**
`left`와 `right` 포인터가 가리키는 문자를 계속 비교하며 이동합니다. 만약 단 한 번이라도 두 문자가 다르다면 바로 `False`를 반환하고, 모든 비교를 마쳤는데도 `False`가 반환되지 않았다면 `True`를 반환합니다. 이 역시 O(N) 시간 복잡도로 해결 가능합니다.

## 2. 동일한 방향으로 이동하는 포인터

이 패턴은 주로 배열 내에서 부분 배열(sub-array) 또는 부분 수열(subsequence)을 찾거나, 중복을 제거하거나, 특정 조건에 따라 요소를 재배치할 때 사용됩니다. 보통 `slow` (또는 `write`) 포인터와 `fast` (또는 `read`) 포인터를 사용하며, 두 포인터가 같은 방향으로 이동하지만 속도나 목적이 다릅니다.

### 예시: 정렬된 배열에서 중복 제거 (Remove Duplicates from Sorted Array)

LeetCode 등에서 자주 등장하는 고전적인 문제입니다. 정렬된 배열에서 중복된 요소를 제거하고, 중복이 제거된 배열의 새 길이를 반환하는 문제입니다. (단, 배열은 제자리(in-place)에서 수정되어야 하며, 추가적인 배열을 사용할 수 없습니다.)

**문제:** `[0, 0, 1, 1, 1, 2, 2, 3, 3, 4]` 배열에서 중복을 제거하고, `[0, 1, 2, 3, 4, _, _, _, _, _]`와 같이 만든 후, 새 길이 `5`를 반환하시오. (언더바는 상관 없는 값)

```python
def remove_duplicates(nums):
    if not nums: # 배열이 비어있다면 0 반환
        return 0
    
    # slow 포인터: 고유한(unique) 요소의 다음 위치를 가리킴
    # 초기값 1은 첫 번째 요소(nums[0])는 항상 고유하다고 가정하고,
    # 그 다음 고유한 요소가 들어갈 위치를 의미합니다.
    slow = 1 
    
    # fast 포인터: 배열의 모든 요소를 순회하며 고유한 요소를 찾음
    for fast in range(1, len(nums)):
        # fast 포인터가 가리키는 현재 요소가 바로 이전 요소와 다르다면 (고유하다면)
        if nums[fast] != nums[fast - 1]:
            # slow 포인터가 가리키는 위치에 현재 fast 포인터의 요소를 저장
            nums[slow] = nums[fast]
            slow += 1 # slow 포인터를 다음 고유한 요소가 들어갈 위치로 이동

    # slow 포인터의 최종 위치가 고유한 요소의 개수(새로운 배열의 길이)가 됩니다.
    return slow

# 예시 사용
nums1 = [0, 0, 1, 1, 1, 2, 2, 3, 3, 4]
print(f"원본 배열: {nums1}")
new_length1 = remove_duplicates(nums1)
print(f"중복 제거 후 (새 길이: {new_length1}): {nums1[:new_length1]}")

nums2 = [1, 1, 2]
print(f"원본 배열: {nums2}")
new_length2 = remove_duplicates(nums2)
print(f"중복 제거 후 (새 길이: {new_length2}): {nums2[:new_length2]}")
```

**설명:**
1.  `slow` 포인터는 고유한 요소들로 채워질 새로운 배열의 '다음' 인덱스를 가리킵니다.
2.  `fast` 포인터는 원본 배열을 처음부터 끝까지 순회합니다.
3.  `fast`가 가리키는 현재 요소(`nums[fast]`)가 `fast`의 바로 이전 요소(`nums[fast - 1]`)와 다르면 (즉, 새로운 고유한 요소가 발견되면), 이 요소를 `slow`가 가리키는 위치(`nums[slow]`)에 복사합니다.
4.  그리고 `slow` 포인터를 한 칸 이동시켜 다음 고유한 요소를 받을 준비를 합니다.
5.  `fast`는 계속 이동합니다. 만약 중복된 요소(`nums[fast] == nums[fast - 1]`)라면, `slow` 포인터는 움직이지 않고 `fast`만 계속 전진합니다. 이렇게 함으로써 중복된 요소는 `slow` 포인터 뒤쪽으로 밀려나게 됩니다.
6.  모든 순회가 끝나면 `slow` 포인터의 최종 값이 중복이 제거된 배열의 길이가 됩니다.

이 기법은 배열을 한 번만 순회하므로 O(N)의 시간 복잡도를 가지며, 추가적인 공간을 사용하지 않으므로 O(1)의 공간 복잡도를 가집니다.

## 투 포인터 기법, 언제 사용하면 좋을까요?

*   **정렬된 배열/리스트에서 특정 조건을 만족하는 쌍을 찾아야 할 때:** (예: 합이 특정 값인 두 수 찾기)
*   **배열/리스트를 뒤집거나 특정 조건에 따라 재배치해야 할 때:** (예: 팰린드롬 확인, 중복 제거)
*   **O(N)의 시간 복잡도와 O(1)의 공간 복잡도로 문제를 해결해야 할 때:** 이중 반복문(O(N^2))을 피하고 싶을 때 좋은 대안이 됩니다.
*   **부분 배열/부분 수열의 조건을 만족하는 것을 찾아야 할 때:** (특히 '슬라이딩 윈도우'와 결합하여 사용)
