# Vim, 이것만 알아도 개발이 편해져요! 초보자를 위한 Vim 기초 사용법 정리

안녕하세요, 개발자 여러분! 오늘 여러분께 소개해 드릴 도구는 바로 'Vim'입니다. Vim은 터미널 환경에서 사용할 수 있는 강력한 텍스트 편집기로, 처음 접하면 조금 어렵게 느껴질 수 있지만, 익숙해지고 나면 여러분의 코딩 속도와 효율을 비약적으로 향상시켜 줄 마법 같은 도구입니다. '마우스 없이 키보드만으로 개발한다'는 말, 혹시 들어보셨나요? Vim이 바로 그 경험을 현실로 만들어 줍니다.

이 글은 Vim을 단 한 번도 사용해보지 않았거나, 잠깐 시도했다가 어려워서 포기했던 분들을 위해 작성되었습니다. 가장 핵심적인 기능들만 뽑아 쉽고 친절하게 설명해 드릴 테니, 함께 Vim의 매력에 빠져볼 준비가 되셨나요?

## 1. Vim, 왜 배워야 할까요?

Vim은 가볍고 빠르며, 거의 모든 리눅스/유닉스 시스템에 기본으로 설치되어 있습니다. 서버 작업을 하거나 원격 환경에서 파일을 편집해야 할 때 Vim은 선택이 아닌 필수인 경우가 많죠. 또한, Vim의 독특한 '모드(Mode)' 기반 편집 방식은 손가락의 움직임을 최소화하여 장시간 코딩 시 피로도를 줄여주고 생산성을 극대화해줍니다. 한 번 익숙해지면 Vim 없는 환경에서는 답답함을 느낄 정도랍니다!

## 2. Vim의 핵심 개념: 모드(Mode) 이해하기

Vim이 처음 어렵게 느껴지는 가장 큰 이유는 바로 '모드' 때문입니다. 일반적인 텍스트 편집기는 키보드를 누르면 바로 글자가 입력되지만, Vim은 현재 어떤 '모드'에 있느냐에 따라 키보드 입력이 다르게 동작합니다.

Vim에는 주로 4가지 모드가 있습니다:

1.  **노멀 모드 (Normal Mode / 명령 모드)**: Vim을 실행하면 기본적으로 이 모드입니다. 텍스트를 입력하는 대신, 커서 이동, 복사, 붙여넣기, 삭제 등 다양한 '명령'을 내릴 수 있습니다. Vim의 진정한 힘은 이 모드에서 나옵니다.
2.  **입력 모드 (Insert Mode)**: 우리가 흔히 생각하는 텍스트 편집기의 모드입니다. 키보드를 누르면 화면에 글자가 입력됩니다.
3.  **비주얼 모드 (Visual Mode)**: 텍스트 블록을 선택(드래그)하는 모드입니다. 선택된 텍스트에 대해 복사, 삭제 등의 명령을 내릴 수 있습니다.
4.  **명령줄 모드 (Command-line Mode / Last-line Mode)**: 파일 저장, 종료, 검색, 바꾸기 등 좀 더 복잡한 명령을 입력하는 모드입니다. 콜론(`:`)을 누르면 진입합니다.

**가장 중요한 규칙**: 다른 모드에 있다가 노멀 모드로 돌아오려면 언제든지 `Esc` 키를 누르면 됩니다! `Esc` 키는 Vim의 '탈출구'라고 생각하시면 편합니다.

### 모드 전환 방법 예시

```python
# Vim 실행 (기본적으로 노멀 모드)

# 노멀 모드에서 입력 모드로 전환
# i: 현재 커서 위치에 입력 시작
# a: 현재 커서 다음 위치에 입력 시작
# o: 현재 줄 아래에 새 줄을 만들고 입력 시작 (대문자 O는 윗줄)

# 입력 모드에서 노멀 모드로 전환
# Esc: 언제든지 Esc 키를 눌러 노멀 모드로 돌아옵니다.

# 노멀 모드에서 비주얼 모드로 전환
# v: 일반 비주얼 모드 (문자 단위 선택)
# V: 줄 단위 비주얼 모드 (줄 전체 선택)
# Ctrl+v: 블록 비주얼 모드 (사각형 블록 선택)

# 노멀 모드에서 명령줄 모드로 전환
# : (콜론): 콜론을 누르면 화면 하단에 명령 프롬프트가 나타납니다.
```

## 3. 노멀 모드: Vim의 핵심 조작법

이제 노멀 모드에서 자주 사용되는 명령들을 알아볼까요?

### 3.1. 커서 이동

마우스 없이 키보드만으로 빠르고 정확하게 커서를 움직이는 것이 Vim의 핵심입니다.

```python
# 방향키 대신 h, j, k, l 사용
# h: 왼쪽 (←)
# j: 아래 (↓)
# k: 위 (↑)
# l: 오른쪽 (→)

# 단어 단위 이동
# w: 다음 단어의 시작으로 이동 (word)
# b: 이전 단어의 시작으로 이동 (back)
# e: 현재 단어의 끝으로 이동 (end)

# 줄 단위 이동
# 0 (숫자 0): 현재 줄의 맨 앞으로 이동
# ^: 현재 줄의 첫 번째 비어있지 않은 문자 위치로 이동
# $: 현재 줄의 맨 끝으로 이동

# 파일 단위 이동
# gg: 파일의 맨 위로 이동
# G: 파일의 맨 아래로 이동
# 5gg 또는 5G: 5번째 줄로 이동
```

**예제**: 아래 텍스트에서 `j`, `w`, `$` 등을 연습해보세요.

```python
This is the first line.
This is the second line.
This is the third line.
```

### 3.2. 텍스트 편집 (삭제, 복사, 붙여넣기, 되돌리기)

```python
# 삭제 (Delete)
# x: 현재 커서의 문자 하나 삭제
# dw: 현재 커서부터 단어 끝까지 삭제 (delete word)
# dd: 현재 줄 전체 삭제 (delete line)
# d$: 현재 커서부터 줄 끝까지 삭제

# 복사 (Yank - Vim에서는 'yank'라고 부릅니다)
# yw: 현재 커서부터 단어 끝까지 복사 (yank word)
# yy: 현재 줄 전체 복사 (yank line)
# y$: 현재 커서부터 줄 끝까지 복사

# 붙여넣기 (Paste)
# p: 현재 커서 뒤에 붙여넣기 (소문자 p)
# P: 현재 커서 앞에 붙여넣기 (대문자 P)

# 되돌리기 (Undo) / 다시 실행 (Redo)
# u: 마지막 작업 되돌리기 (undo)
# Ctrl+r: 되돌린 작업 다시 실행 (redo)

# 교체 (Replace)
# r: 현재 커서의 문자 하나를 다른 문자로 교체 (r 다음에 교체할 문자 입력)
```

**예제**:

```python
# 다음 줄에서 'Hello'를 'Hi'로 바꾸고, 'World'를 삭제한 후, 'Vim'을 추가해보세요.
# 'Hello World!'
# 1. 'H'에 커서 이동 -> 'r' -> 'H' -> 'i' (Hiello World!)
# 2. 'W'에 커서 이동 -> 'dw' (Hiello!)
# 3. '!' 뒤에 커서 이동 -> 'a' (입력 모드) -> ' Vim' -> 'Esc' (Hiello Vim!)

# 다음 줄 전체를 복사해서 아래에 붙여넣어 보세요.
# 'This line will be duplicated.'
# 1. 해당 줄에 커서 이동 -> 'yy'
# 2. 새 줄에 커서 이동 -> 'p'
```

## 4. 명령줄 모드: 파일 저장, 종료, 검색

콜론(`:`)을 눌러 진입하는 명령줄 모드입니다.

```python
# 파일 저장 및 종료
# :w: 현재 파일 저장 (write)
# :q: 현재 파일 종료 (quit)
# :wq: 저장 후 종료 (write & quit)
# :x: 저장 후 종료 (수정된 경우에만 저장)
# ZZ (노멀 모드에서): :x와 동일

# 강제 종료 (수정사항 저장 없이)
# :q!: 저장하지 않고 강제 종료 (quit force)

# 다른 이름으로 저장
# :w new_file_name.txt: 현재 파일을 'new_file_name.txt'로 저장

# 검색
# /검색어: 현재 커서부터 아래 방향으로 '검색어' 찾기
# ?검색어: 현재 커서부터 위 방향으로 '검색어' 찾기
# n: 다음 검색 결과로 이동
# N: 이전 검색 결과로 이동
```

**예제**:

```python
# Vim을 실행한 후, 아무 내용이나 입력하고 저장해봅시다.
# 1. vim test.txt (터미널에서)
# 2. i -> "Hello, Vim World!" 입력 -> Esc
# 3. :wq (저장 후 종료)

# 다시 vim test.txt -> "/Vim" 검색 -> n, N 눌러보기
```
