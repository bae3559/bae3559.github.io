# 앙상블 학습, 그게 뭔데? 배깅, 부스팅, 스태킹으로 완벽 정리!

안녕하세요! 여러분의 머신러닝 여정에 늘 함께하는 개발 블로그 작가입니다. 오늘은 머신러닝 모델의 성능을 한 단계 업그레이드할 수 있는 아주 강력한 기법, 바로 **앙상블 학습(Ensemble Learning)**에 대해 이야기해보려 합니다.

혹시 '집단지성'이라는 말 들어보셨나요? 여러 사람의 의견을 모아 하나의 결론을 내릴 때, 개개인의 판단보다 더 정확하고 현명한 결과가 나올 때가 많죠. 머신러닝에서도 이 집단지성의 힘을 빌려 모델의 성능을 향상시키는 방법이 있습니다. 바로 '앙상블 학습'입니다!

앙상블 학습은 여러 개의 약한 모델(Weak Learners)을 결합하여 하나의 강력한 모델(Strong Learner)을 만드는 기법입니다. 이를 통해 단일 모델로는 얻기 어려운 높은 예측 정확도와 안정성을 확보할 수 있습니다. 오늘은 앙상블 학습의 대표적인 세 가지 방법인 **배깅(Bagging)**, **부스팅(Boosting)**, **스태킹(Stacking)**에 대해 초보자도 이해할 수 있도록 친절하게 설명해 드릴게요!

---

## 1. 앙상블 학습이란 무엇인가요?

본격적인 방법에 들어가기 전에, 앙상블 학습의 핵심 아이디어를 다시 한번 짚어보겠습니다.

단일 모델은 특정 데이터 패턴에 과적합(Overfitting)되거나, 반대로 너무 단순해서 데이터의 복잡한 패턴을 제대로 학습하지 못하는(Underfitting) 경우가 생길 수 있습니다. 앙상블 학습은 이러한 단점을 극복하기 위해 다음과 같은 방식으로 접근합니다.

1.  **다양한 모델 준비**: 여러 종류의 모델 또는 같은 종류라도 학습 방식에 차이를 둔 모델을 준비합니다.
2.  **결과 통합**: 각 모델이 예측한 결과를 단순 평균, 가중 평균, 투표, 혹은 또 다른 모델을 통해 종합하여 최종 결정을 내립니다.

이렇게 함으로써 모델의 **분산(Variance)**을 줄여 과적합을 방지하고, **편향(Bias)**을 줄여 다양한 패턴을 학습할 수 있게 됩니다.

---

## 2. 배깅 (Bagging): 독립적인 전문가들의 다수결

**배깅(Bagging)**은 "Bootstrap Aggregating"의 줄임말입니다. 이름에서 알 수 있듯이, **부트스트랩(Bootstrap)** 샘플링과 **취합(Aggregating)**이라는 두 가지 핵심 개념으로 이루어져 있습니다.

### 개념 설명

배깅은 여러 개의 모델을 **독립적으로** 학습시킨 후, 그 결과들을 평균 내거나 투표하여 최종 예측을 하는 방식입니다.

1.  **부트스트랩 샘플링**: 원본 학습 데이터셋에서 복원 추출(Replacement) 방식으로 여러 개의 새로운 학습 데이터셋을 만듭니다. 각 데이터셋은 원본 데이터셋과 같은 크기를 가지지만, 구성하는 데이터 포인트는 조금씩 다릅니다. (어떤 데이터는 여러 번 포함되고, 어떤 데이터는 아예 포함되지 않을 수도 있습니다.)
2.  **독립적인 모델 학습**: 이렇게 만들어진 각 데이터셋으로 독립적인 모델(예: 의사결정나무)을 학습시킵니다.
3.  **결과 취합**:
    *   **회귀 문제**: 각 모델의 예측값을 평균 내어 최종 예측값으로 사용합니다.
    *   **분류 문제**: 각 모델의 예측값에 대해 다수결 투표를 통해 가장 많은 표를 얻은 클래스를 최종 예측값으로 사용합니다.

**비유**: 마치 여러 명의 전문가에게 같은 질문을 던진 후, 각자의 의견을 듣고 다수결(분류)이나 평균(회귀)으로 결정하는 것과 비슷하죠. 각 전문가는 서로 다른 관점(부트스트랩 샘플링)에서 문제를 분석하지만, 서로에게 영향을 주지는 않습니다.

**장점**: 모델의 분산(Variance)을 줄여 과적합을 방지하는 데 효과적입니다. 대표적인 알고리즘으로 **랜덤 포레스트(Random Forest)**가 있습니다.

### 코드 예제 (RandomForestClassifier)

`sklearn` 라이브러리의 `RandomForestClassifier`는 대표적인 배깅 기반 앙상블 모델입니다.

```python
import numpy as np
from sklearn.datasets import make_classification
from sklearn.model_selection import train_test_split
from sklearn.ensemble import RandomForestClassifier
from sklearn.metrics import accuracy_score

# 1. 예제 데이터 생성
# n_samples: 데이터 포인트 수, n_features: 특성(피처) 수
# n_informative: 유용한 특성 수, n_redundant: 중복 특성 수
X, y = make_classification(n_samples=1000, n_features=20, n_informative=10, n_redundant=10, random_state=42)

# 학습 세트와 테스트 세트로 분리
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)

# 2. 랜덤 포레스트 모델 생성 및 학습
# n_estimators: 사용할 의사결정나무(기본 모델)의 개수
# random_state: 재현성을 위한 시드값
rf_model = RandomForestClassifier(n_estimators=100, random_state=42)
rf_model.fit(X_train, y_train)

# 3. 예측 및 평가
y_pred_rf = rf_model.predict(X_test)
accuracy_rf = accuracy_score(y_test, y_pred_rf)

print(f"Random Forest 정확도: {accuracy_rf:.4f}")
```

## 3. 부스팅 (Boosting): 실수를 개선해나가는 학습

**부스팅(Boosting)**은 배깅과는 다르게 모델들을 **순차적으로** 학습시키는 방식입니다. 이전 모델이 예측하기 어려웠던(즉, 오류를 범했던) 데이터에 더 큰 가중치를 부여하여 다음 모델이 학습하도록 합니다.

### 개념 설명

1.  **초기 모델 학습**: 첫 번째 모델은 전체 학습 데이터로 학습합니다.
2.  **오류 가중치 부여**: 첫 번째 모델이 예측에 실패한(틀린) 데이터 포인트에 더 높은 가중치를 부여합니다.
3.  **다음 모델 학습**: 가중치가 조정된 데이터셋으로 두 번째 모델을 학습시킵니다. 이 모델은 첫 번째 모델이 틀렸던 부분을 더 잘 맞추려고 노력합니다.
4.  **반복**: 이 과정을 미리 정해진 횟수만큼 반복합니다. 매 단계마다 새로운 모델은 이전 모델들의 오류를 보완하는 방향으로 학습됩니다.
5.  **최종 예측**: 모든 모델의 예측 결과를 가중치와 함께 결합하여 최종 예측을 수행합니다. 일반적으로 성능이 좋은 모델에 더 높은 가중치가 부여됩니다.

**비유**: 마치 학생이 오답노트를 작성하며 틀린 문제를 다시 풀고, 그 부분에 더 집중해서 공부하는 것과 비슷합니다. 선생님(새로운 모델)은 학생(이전 모델)이 어려워하는 문제(오류가 컸던 데이터)를 중심으로 가르쳐주는 것이죠.

**장점**: 모델의 편향(Bias)을 줄여서 매우 높은 예측 정확도를 달성할 수 있습니다. 대표적인 알고리즘으로 **AdaBoost, Gradient Boosting Machine (GBM), XGBoost, LightGBM** 등이 있습니다.

### 코드 예제 (GradientBoostingClassifier)

`sklearn`의 `GradientBoostingClassifier`는 부스팅 기반 앙상블 모델의 좋은 예시입니다.

```python
from sklearn.ensemble import GradientBoostingClassifier
from sklearn.metrics import accuracy_score

# 데이터는 위에서 생성한 X_train, X_test, y_train, y_test를 사용합니다.

# 1. 그레디언트 부스팅 모델 생성 및 학습
# n_estimators: 사용할 기본 모델(약한 학습기, 주로 의사결정나무)의 개수
# learning_rate: 각 기본 모델의 기여도를 조절하는 학습률
gb_model = GradientBoostingClassifier(n_estimators=100, learning_rate=0.1, random_state=42)
gb_model.fit(X_train, y_train)

# 2. 예측 및 평가
y_pred_gb = gb_model.predict(X_test)
accuracy_gb = accuracy_score(y_test, y_pred_gb)

print(f"Gradient Boosting 정확도: {accuracy_gb:.4f}")
```

## 4. 스태킹 (Stacking): 전문가들의 예측을 종합하는 메타 전문가

**스태킹(Stacking)**은 배깅이나 부스팅과는 또 다른 방식으로 앙상블을 수행합니다. 여러 개의 기본 모델(Base Models)의 예측 결과를 또 다른 최종 모델(Meta Model 또는 Level-1 Model)의 입력으로 사용하여 최종 예측을 수행하는 방식입니다.

### 개념 설명

1.  **기본 모델 학습 (Level-0 Models)**: 여러 종류의 기본 모델(예: 로지스틱 회귀, SVM, 의사결정나무 등)을 학습 데이터로 각각 학습시킵니다.
2.  **기본 모델 예측 (새로운 특성 생성)**: 학습된 각 기본 모델은 학습 데이터를 예측합니다. 이때, **교차 검증(Cross-validation)**을 사용하여 기본 모델들이 학습에 사용되지 않은 데이터에 대한 예측값을 생성하는 것이 중요합니다. 이 예측값들이 메타 모델의 새로운 입력 특성(Feature)이 됩니다.
3.  **메타 모델 학습 (Level-1 Model)**: 기본 모델들이 생성한 예측값(새로운 특성)을 입력으로 받아 최종 예측을 수행할 메타 모델(예: 로지스틱 회귀, 랜덤 포레스트)을 학습시킵니다.
4.  **최종 예측**: 테스트 데이터에 대해서도 기본 모델들이 예측을 수행하고, 이 예측값들을 메타 모델에 넣어 최종 예측을 얻습니다.

**비유**: 각 분야의 전문가(기본 모델)들이 의견을 내면, 이 의견들을 종합하여 최종 결정을 내리는 '총괄 전문가' (메타 모델)가 있는 회의와 같습니다. 총괄 전문가는 어떤 전문가의 의견을 더 중요하게 받아들여야 할지 스스로 학습하는 것이죠.

**장점**: 다양한 기본 모델들의 강점을 조합하여, 단일 모델이나 단순 투표/평균 방식보다 더 높은 성능을 달성할 수 있습니다. 모델 간의 복잡한 상호작용을 학습할 수 있습니다.

### 코드 예제 (StackingClassifier)

`sklearn`의 `StackingClassifier`는 스태킹을 쉽게 구현할 수 있도록 도와줍니다.

```python
from sklearn.linear_model import LogisticRegression
from sklearn.tree import DecisionTreeClassifier
from sklearn.svm import SVC
from sklearn.ensemble import StackingClassifier
from sklearn.metrics import accuracy_score

# 데이터는 위에서 생성한 X_train, X_test, y_train, y_test를 사용합니다.

# 1. 기본 모델 (Level-0 Models) 정의
# 리스트 안에 (이름, 모델 인스턴스) 형태로 튜플을 넣어줍니다.
estimators = [
    ('lr', LogisticRegression(random_state=42)),
    ('dt', DecisionTreeClassifier(random_state=42)),
    ('svc', SVC(probability=True, random_state=42)) # probability=True는 predict_proba()를 사용하기 위함
]

# 2. 스태킹 분류기 생성 및 학습
# estimators: 기본 모델들
# final_estimator: 메타 모델 (여기서는 LogisticRegression을 사용)
st_model = StackingClassifier(estimators=estimators, final_estimator=LogisticRegression(), cv=5)
st_model.fit(X_train, y_train)

# 3. 예측 및 평가
y_pred_st = st_model.predict(X_test)
accuracy_st = accuracy_score(y_test, y_pred_st)

print(f"Stacking 정확도: {accuracy_st:.4f}")
```

## 5. 어떤 앙상블 방법을 사용해야 할까요?

각 방법은 고유한 특징과 장단점을 가지고 있습니다.

*   **배깅 (Random Forest)**: 모델의 **분산(Variance)을 줄이는 데 효과적**입니다. 과적합 위험이 높은 복잡한 모델(예: 의사결정나무)에 특히 유리하며, 병렬 처리가 가능하여 학습 속도가 빠른 편입니다.
*   **부스팅 (Gradient Boosting, XGBoost 등)**: 모델의 **편향(Bias)을 줄이는 데 효과적**입니다. 일반적으로 매우 높은 예측 정확도를 달성하지만, 순차적인 학습으로 인해 병렬 처리가 어려워 학습 시간이 더 걸릴 수 있고, 과적합에 더 취약할 수 있습니다(세심한 하이퍼파라미터 튜닝 필요).
*   **스태킹**: 여러 **다양한 종류의 모델 강점**을 조합하고자 할 때 유용합니다. 가장 복잡하고 강력한 앙상블 기법 중 하나이지만, 그만큼 구현과 튜닝이 어렵고 학습 시간도 오래 걸립니다.

실제 문제에서는 이 세 가지 방법 중 하나만 사용하는 것이 아니라, 데이터와 문제의 특성에 따라 가장 적합한 방법을 선택하거나, 때로는 여러 방법을 조합하여 시도해보는 것이 중요합니다.
