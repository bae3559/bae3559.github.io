# Vim, 개발자의 손과 발이 되는 에디터: 첫걸음 떼기

안녕하세요, 여러분! 코드를 작성하고 수정하는 일은 개발자의 일상과 같습니다. 수많은 에디터와 IDE가 있지만, 오늘은 개발자들 사이에서 전설처럼 회자되는 강력한 텍스트 에디터, **Vim**에 대한 이야기를 해보려고 합니다. 처음 Vim을 접하면 "이게 뭐야?"라는 반응이 나올 수 있습니다. 마우스도 잘 안 쓰고, 방향키도 안 먹히는 듯한 낯선 환경에 당황하기 쉽죠. 하지만 조금만 익숙해지면 Vim은 여러분의 코딩 속도를 비약적으로 향상시켜 줄 마법 같은 도구가 될 수 있습니다.

이 글은 Vim을 처음 접하는 분들을 위해, 왜 Vim이 특별한지부터 시작하여 기본적인 사용법까지 친절하게 안내해 드릴 예정입니다. 저와 함께 Vim의 세계로 첫걸음을 내디뎌 볼까요?

## 1. Vim, 왜 배워야 할까요?

Vim은 'Vi IMproved'의 약자로, 터미널 환경에서 가장 강력하고 효율적인 텍스트 편집기 중 하나로 손꼽힙니다. 마우스 없이 키보드만으로 모든 작업을 처리하도록 설계되어, 손목 움직임을 최소화하고 오직 키보드만으로 놀라운 속도를 낼 수 있습니다.

**Vim의 장점:**

*   **극강의 효율성:** 한 번 익숙해지면 마우스보다 훨씬 빠르게 텍스트를 편집할 수 있습니다.
*   **어디서나 사용 가능:** SSH를 통해 원격 서버에 접속했을 때도 Vim은 기본적으로 설치되어 있어 편리합니다.
*   **커스터마이징:** 방대한 플러그인과 설정으로 자신만의 에디터를 구축할 수 있습니다.
*   **생산성 향상:** 개발 흐름을 방해하지 않고 오직 코드에만 집중할 수 있게 돕습니다.

물론, 초기 학습 곡선이 가파르다는 단점이 있지만, 그 벽을 넘어서면 여러분의 개발 생산성은 한 단계 더 도약할 것입니다.

## 2. Vim의 핵심 개념: 모드(Mode) 이해하기

Vim이 낯선 가장 큰 이유는 바로 '모드' 때문입니다. 일반적인 에디터는 항상 텍스트를 입력하는 모드지만, Vim은 상황에 따라 다른 '모드'를 가집니다. 이 모드들을 이해하는 것이 Vim 사용의 첫걸음이자 핵심입니다.

Vim의 주요 모드는 다음과 같습니다.

1.  **노말 모드 (Normal Mode):**
    *   Vim을 실행하면 가장 먼저 진입하는 기본 모드입니다.
    *   텍스트를 직접 입력할 수는 없으며, 파일 내에서 이동하거나, 텍스트를 복사, 삭제, 붙여넣기, 검색하는 등의 '명령'을 수행하는 데 사용됩니다.
    *   마치 키보드가 명령어 입력 장치처럼 작동합니다.
    *   다른 모드에서 `Esc` 키를 누르면 노말 모드로 돌아옵니다.

2.  **입력 모드 (Insert Mode):**
    *   우리가 흔히 아는 텍스트 에디터처럼, 텍스트를 직접 입력할 수 있는 모드입니다.
    *   노말 모드에서 `i`, `a`, `o` 등의 키를 눌러 진입합니다.
    *   입력을 마쳤다면 반드시 `Esc` 키를 눌러 다시 노말 모드로 돌아와야 합니다.

3.  **비주얼 모드 (Visual Mode):**
    *   텍스트를 블록 단위로 선택하는 모드입니다. 선택된 텍스트에 대해 복사, 삭제 등의 명령을 내릴 수 있습니다.
    *   노말 모드에서 `v`, `V`, `<C-v>` 등의 키를 눌러 진입합니다.

4.  **명령 모드 (Command-Line Mode / Ex Mode):**
    *   파일 저장, 종료, 검색, 문자열 치환 등 좀 더 복잡한 명령어를 입력할 때 사용합니다.
    *   노말 모드에서 `:` (콜론)을 누르면 화면 하단에 콜론이 나타나고 명령어를 입력할 수 있습니다.

이 모드들 간의 전환이 처음에는 헷갈릴 수 있지만, `Esc` 키가 항상 노말 모드로 돌아가는 '피난처'라는 것을 기억하면 좋습니다.

## 3. Vim 시작하기: 기본 조작법

이제 가장 기본적인 조작법들을 알아보겠습니다. Vim을 실행하는 방법은 터미널에 `vim` 또는 `vi`를 입력하고 엔터를 치는 것입니다. 특정 파일을 열고 싶다면 `vim 파일이름.txt`처럼 입력합니다.

### 3.1. 노말 모드: 이동의 달인 되기

노말 모드에서는 텍스트를 입력하는 대신, 키보드를 이용해 커서를 효율적으로 이동할 수 있습니다. 전통적인 방향키 대신 `h, j, k, l`을 사용해 보세요.

```python
# h : 왼쪽으로 한 칸 이동 (Left)
# j : 아래로 한 줄 이동 (Down)
# k : 위로 한 줄 이동 (Up)
# l : 오른쪽으로 한 칸 이동 (Right)

# w : 다음 단어의 시작으로 이동 (word)
# b : 현재 단어 또는 이전 단어의 시작으로 이동 (backward)
# e : 현재 단어 또는 다음 단어의 끝으로 이동 (end)

# 0 : 현재 줄의 맨 앞으로 이동 (숫자 0)
# $ : 현재 줄의 맨 뒤로 이동

# gg : 파일의 맨 처음으로 이동
# G  : 파일의 맨 마지막으로 이동

# 5gg 또는 5G : 5번째 줄로 이동
```

처음엔 불편하겠지만, 손이 홈 포지션(ASDF-JKL;)에서 멀어지지 않아 훨씬 빠르고 효율적인 이동이 가능합니다.

### 3.2. 입력 모드: 텍스트 입력하기

노말 모드에서 다음 키들을 눌러 입력 모드로 진입할 수 있습니다.

```python
# i : 현재 커서 위치에 삽입 (insert)
# a : 현재 커서 위치 다음 칸에 삽입 (append)
# o : 현재 커서 위치 아래에 새로운 줄을 만들고 삽입 (open line below)
# O : 현재 커서 위치 위에 새로운 줄을 만들고 삽입 (open line above)

# I : 현재 줄의 맨 앞으로 이동하여 삽입
# A : 현재 줄의 맨 뒤로 이동하여 삽입
```

입력 모드에서 텍스트를 모두 입력했다면, 반드시 `Esc` 키를 눌러 다시 노말 모드로 돌아와야 합니다.

### 3.3. 노말 모드: 텍스트 수정 및 삭제

노말 모드에서는 한 글자부터 여러 줄까지 다양한 단위로 텍스트를 삭제, 복사, 붙여넣기 할 수 있습니다.

```python
# x : 현재 커서 위치의 한 글자 삭제 (del_char)
# dw : 현재 커서 위치부터 단어 끝까지 삭제 (delete word)
# dd : 현재 줄 전체 삭제 (delete line)
# D  : 현재 커서 위치부터 줄 끝까지 삭제

# yy : 현재 줄 전체 복사 (yank line)
# yw : 현재 커서 위치부터 단어 끝까지 복사 (yank word)

# p : 현재 커서 뒤에 붙여넣기 (paste)
# P : 현재 커서 앞에 붙여넣기 (Paste)

# u : 마지막 변경사항 취소 (undo)
# Ctrl + r : 취소한 변경사항 다시 실행 (redo)
```

예를 들어, "Hello, Vim!"이라는 문장에서 `, Vim!`을 삭제하고 싶다면, `H`에 커서를 두고 `dw`를 여러 번 누르거나, `d`를 누른 후 `$`를 눌러 줄 끝까지 삭제할 수 있습니다. `dd`로 한 줄을 삭제하고 `p`를 눌러 다른 곳에 붙여넣는 식으로 활용합니다.

## 4. Vim 종료 및 저장하기: 명령 모드 활용

파일을 저장하거나 Vim을 종료할 때는 명령 모드를 사용합니다. 노말 모드에서 `:` (콜론)을 누르면 화면 하단에 명령어를 입력할 수 있는 상태가 됩니다.

```python
# :w  <- 현재 파일 저장 (write)
# :q  <- Vim 종료 (quit)
# :wq <- 저장 후 종료 (write and quit)
# :x  <- 저장 후 종료 (파일이 변경되었을 때만 저장 후 종료)

# :q! <- 변경사항을 저장하지 않고 강제 종료 (quit without saving)
```

만약 실수로 파일을 수정했는데 저장하고 싶지 않다면, `:q!`를 사용하여 강제로 종료할 수 있습니다.

## 5. 텍스트 검색하기

찾고자 하는 단어가 있을 때는 명령 모드에서 `/`를 사용합니다.

```python
# /찾을_단어 <- 현재 커서 위치부터 아래로 '찾을_단어' 검색
# ?찾을_단어 <- 현재 커서 위치부터 위로 '찾을_단어' 검색

# n <- 다음 검색 결과로 이동
# N <- 이전 검색 결과로 이동
```

예를 들어, `:vscode`라고 입력하고 엔터를 치면 문서 내에서 "vscode"라는 단어를 찾아줍니다.

## 마치며

오늘 우리는 Vim의 기본 개념인 모드부터 시작하여, 기본적인 이동, 입력, 수정, 삭제, 저장 및 종료, 그리고 검색까지 다양한 기능을 알아보았습니다. 처음에는 낯설고 불편하게 느껴질 수 있지만, 이 기초적인 명령들을 꾸준히 연습하다 보면 어느새 키보드 위에서 자유롭게 춤추는 자신을 발견하게 될 것입니다.

Vim은 단순히 텍스트 에디터가 아니라, 개발자의 생산성을 극대화하는 강력한 도구입니다. 이 글이 여러분이 Vim에 대한 두려움을 극복하고, 그 무한한 잠재력을 탐험하는 즐거움을 느끼는 데 도움이 되었기를 바랍니다. 다음번에는 더 심화된 Vim 사용법으로 찾아오겠습니다. Happy Vimming!
