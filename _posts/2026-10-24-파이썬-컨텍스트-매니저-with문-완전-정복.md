# 파이썬 with문, 컨텍스트 매니저 완전 정복: 자원 관리를 우아하게!

안녕하세요, 여러분! 파이썬 개발 블로그 작가 개발자 키다리입니다.

## 1. `with` 문, 도대체 뭘까요? 왜 써야 할까요?

파이썬으로 프로그래밍을 하다 보면 파일을 열거나, 데이터베이스에 연결하거나, 특정 Lock을 획득하는 등 **"자원(Resource)"**을 사용하는 경우가 많습니다. 이런 자원들은 사용 후에는 반드시 **"해제(Release)"**해 주어야 합니다. 그렇지 않으면 메모리 누수, 데이터 손상, 또는 다른 프로그램이 해당 자원을 사용하지 못하는 문제 등이 발생할 수 있죠.

가장 흔한 예시인 파일 입출력을 살펴볼까요?

**`with` 문을 사용하지 않았을 때:**

```python
# 'my_file.txt' 파일을 쓰기 모드로 엽니다.
file = open('my_file.txt', 'w', encoding='utf-8')
try:
    file.write('안녕하세요, with문이 없던 시절의 코드입니다.\n')
    file.write('저는 자원을 열었으면 반드시 닫아주어야 합니다.\n')
    # 혹시 여기에 에러가 발생한다면...?
    # 1 / 0 # 고의로 에러 발생!
except Exception as e:
    print(f"파일 작업 중 예외 발생: {e}")
finally:
    # 에러가 나든 안 나든, 무조건 파일을 닫아야 합니다!
    file.close()
    print("파일이 성공적으로 닫혔습니다.")

print("--- 파일 내용 확인 ---")
with open('my_file.txt', 'r', encoding='utf-8') as f:
    print(f.read())
```

위 코드처럼 `try...finally` 블록을 사용하면 `file.close()`가 확실히 호출되도록 보장할 수 있습니다. 하지만 코드가 길어지고, 자원을 여러 개 다룰 때는 `try...finally`가 반복되어 코드가 복잡해지고 가독성이 떨어집니다. 게다가 만약 `close()`를 깜빡한다면... 끔찍하죠!

**`with` 문을 사용했을 때:**

```python
with open('my_file.txt', 'w', encoding='utf-8') as file:
    file.write('안녕하세요, with문과 함께라면 걱정 없죠!\n')
    file.write('자동으로 자원을 관리해 준답니다.\n')
    # 1 / 0 # 여기에 에러가 발생해도 괜찮아요!
print("파일이 성공적으로 닫혔습니다.") # with 블록을 벗어나면 파일은 자동으로 닫힙니다.

print("\n--- 파일 내용 확인 ---")
with open('my_file.txt', 'r', encoding='utf-8') as f:
    print(f.read())
```

어떤가요? 훨씬 깔끔하고 읽기 쉽지 않나요? `with` 문은 `open()` 함수가 반환하는 파일 객체를 `file` 변수에 할당하고, `with` 블록이 끝나는 순간(정상 종료든, 예외 발생이든 상관없이) 자동으로 파일을 닫아줍니다. 개발자가 일일이 `close()`를 호출할 필요가 없어지는 거죠!

이것이 바로 `with` 문을 사용하는 가장 큰 이유이자 장점입니다. **자원의 안전한 획득과 해제를 보장하여 코드를 간결하고 견고하게 만들어줍니다.**

## 2. `with` 문 뒤에 숨겨진 비밀: 컨텍스트 매니저 (Context Manager)

그렇다면 `with` 문은 어떻게 이런 마법 같은 자원 관리를 해주는 걸까요? 그 비밀은 바로 **컨텍스트 매니저(Context Manager)**라는 개념에 있습니다.

컨텍스트 매니저는 파이썬 객체 중 `__enter__`와 `__exit__`라는 특별한 메서드를 가지고 있는 객체를 말합니다. `with` 문은 이 두 메서드를 이용해서 자원 관리 작업을 수행합니다.

1.  **`__enter__(self)` 메서드:**
    *   `with` 블록이 시작될 때 호출됩니다.
    *   이 메서드는 자원을 획득하거나 초기화하는 로직을 수행합니다.
    *   획득한 자원(예: 파일 객체, DB 연결)을 반환하며, 이 반환 값은 `as` 키워드 뒤의 변수(예: `with open(...) as file:` 에서의 `file`)에 할당됩니다.

2.  **`__exit__(self, exc_type, exc_val, exc_tb)` 메서드:**
    *   `with` 블록이 끝날 때 (정상적으로 종료되든, 예외가 발생하든 상관없이) 호출됩니다.
    *   이 메서드는 자원을 해제하거나 정리하는 로직을 수행합니다.
    *   `exc_type`, `exc_val`, `exc_tb` 인자는 `with` 블록 내에서 발생한 예외에 대한 정보를 담고 있습니다. (예외 타입, 예외 값, 트레이스백)
        *   만약 `__exit__` 메서드가 `True`를 반환하면, `with` 블록 내에서 발생한 예외가 외부로 전파되지 않고 *억제*됩니다. (보통은 `False`를 반환하거나 아무것도 반환하지 않아 예외가 전파되도록 합니다.)

간단히 말해, `with` 문은 다음과 같은 과정을 거칩니다:

1.  `with` 문의 대상 객체(예: `open()`이 반환한 객체)의 `__enter__()` 메서드를 호출합니다.
2.  `__enter__()` 메서드가 반환하는 값을 `as` 키워드 뒤의 변수에 할당합니다.
3.  `with` 블록 내부의 코드를 실행합니다.
4.  `with` 블록이 끝나면 (정상 종료든, 예외 발생이든) 대상 객체의 `__exit__()` 메서드를 호출합니다.

마치 호텔에 체크인(자원 획득)하고, 방을 이용하다가, 체크아웃(자원 해제)하는 과정과 비슷하다고 생각하시면 됩니다!

## 3. 나만의 컨텍스트 매니저 만들기

이제 `with` 문과 컨텍스트 매니저의 원리를 알았으니, 직접 나만의 컨텍스트 매니저를 만들어 봅시다! 크게 두 가지 방법이 있습니다.

### 방법 1: 클래스를 이용한 컨텍스트 매니저 (기본 원리 이해)

`__enter__`와 `__exit__` 메서드를 직접 구현하는 방식입니다. 자원의 획득과 해제를 명확하게 제어할 수 있습니다.

예시: 코드 블록의 실행 시간을 측정하는 `Timer` 컨텍스트 매니저

```python
import time

class Timer:
    def __enter__(self):
        self.start_time = time.time()
        print("💡 타이머 시작!")
        # with ... as timer: 형태로 사용될 경우, timer 변수에 이 객체(self)가 할당됩니다.
        return self

    def __exit__(self, exc_type, exc_val, exc_tb):
        end_time = time.time()
        duration = end_time - self.start_time
        if exc_type: # 예외가 발생했다면
            print(f"🚨 타이머 실행 중 예외 발생: {exc_val}")
            # 여기서 예외를 처리하고 싶다면 True를 반환하여 예외 전파를 막을 수 있습니다.
            # 하지만 일반적으로는 False를 반환하거나 아무것도 반환하지 않아 예외가 전파되도록 합니다.
        print(f"🏁 타이머 종료. 경과 시간: {duration:.4f} 초")

# Timer 컨텍스트 매니저 사용 예시
print("--- 첫 번째 작업 ---")
with Timer():
    print("  복잡한 계산을 수행 중...")
    time.sleep(0.5) # 0.5초 대기
    print("  계산 완료!")

print("\n--- 두 번째 작업 (예외 발생) ---")
with Timer():
    print("  짧은 작업을 시작합니다...")
    time.sleep(0.2)
    raise ValueError("앗! 예상치 못한 에러 발생!") # 고의로 예외 발생
    print("  이 메시지는 보이지 않습니다.")

print("\n--- 모든 작업 완료 ---")
```

위 코드를 실행해 보면, `with` 블록이 시작될 때 "타이머 시작!" 메시지가 출력되고, 블록이 끝날 때 "타이머 종료. 경과 시간: X.XXXX 초" 메시지가 출력되는 것을 볼 수 있습니다. 심지어 두 번째 작업처럼 중간에 예외가 발생하더라도 `__exit__` 메서드는 호출되어 시간을 측정하고 예외 발생 사실을 알려줍니다. 이것이 바로 `with` 문의 강력함입니다!

### 방법 2: `contextlib` 모듈과 `@contextmanager` 데코레이터 (더 간편한 방법)

매번 `__enter__`, `__exit__` 메서드를 가진 클래스를 만드는 것이 번거로울 때가 있습니다. 이럴 때 파이썬 표준 라이브러리의 `contextlib` 모듈에 있는 `@contextmanager` 데코레이터를 사용하면 훨씬 간편하게 컨텍스트 매니저를 만들 수 있습니다. 제너레이터(generator)와 `yield` 키워드를 활용합니다.

`@contextmanager` 데코레이터는 다음과 같은 방식으로 작동합니다:
*   `yield` 키워드 이전의 코드는 `__enter__` 메서드의 역할을 합니다.
*   `yield` 키워드가 반환하는 값은 `as` 키워드 뒤의 변수에 할당됩니다.
*   `yield` 키워드 이후의 코드는 `__exit__` 메서드의 역할을 합니다.

예시: 간단한 로깅 컨텍스트 매니저

```python
from contextlib import contextmanager
import time

@contextmanager
def my_logger(tag):
    print(f"[{tag}] 🚀 블록 진입 준비 중...") # __enter__ 역할
    start_time = time.time()
    try:
        yield f"작업_{tag}" # 'as' 변수에 전달될 값
    except Exception as e:
        print(f"[{tag}] 🚨 블록 내에서 예외 발생: {e}")
        # 여기서 예외를 처리하고 싶다면 추가 로직 작성
        # raise # 예외를 외부로 다시 발생시키려면 이 줄의 주석을 해제
    finally:
        end_time = time.time()
        duration = end_time - start_time
        print(f"[{tag}] ✅ 블록 종료 처리 완료. 총 {duration:.4f}초 소요.") # __exit__ 역할

# my_logger 컨텍스트 매니저 사용 예시
print("--- 작업 A ---")
with my_logger("A") as task_id:
    print(f"  {task_id} 실행 중...")
    time.sleep(0.3)
    print(f"  {task_id} 성공적으로 완료.")

print("\n--- 작업 B (예외 발생) ---")
with my_logger("B") as task_id_b:
    print(f"  {task_id_b} 실행 중...")
    time.sleep(0.1)
    1 / 0 # 고의로 ZeroDivisionError 발생!
    print(f"  {task_id_b} 완료 메시지는 보이지 않음.") # 이 줄은 실행되지 않습니다.

print("\n--- 모든 컨텍스트 작업 완료 ---")
```

`@contextmanager` 데코레이터를 사용하면 클래스 없이 함수 형태로 컨텍스트 매니저를 정의할 수 있어, 코드가 훨씬 간결해지고 직관적으로 보입니다. `try...finally` 블록으로 예외 처리까지 깔끔하게 할 수 있죠.

## 4. `with` 문은 어디에 활용할 수 있을까요? (실용적인 예시)

`with` 문과 컨텍스트 매니저는 파일 처리 외에도 파이썬 생태계 전반에서 광범위하게 사용됩니다. 몇 가지 대표적인 예시를 살펴볼까요?

*   **파일 입출력 (`open`)**: 가장 기본적인 용도이며, 위에서 설명했습니다.
*   **스레드/프로세스 동기화 (`threading.Lock`, `multiprocessing.Lock`)**:
    ```python
    import threading

    lock = threading.Lock()

    def critical_section():
        with lock: # Lock 획득 (__enter__), 블록 종료 시 Lock 해제 (__exit__)
            print(f"[{threading.current_thread().name}] 중요한 작업을 수행합니다.")
            time.sleep(0.1)
        print(f"[{threading.current_thread().name}] 작업을 마쳤습니다.")

    # 여러 스레드에서 critical_section 함수 호출
    threads = []
    for i in range(5):
        thread = threading.Thread(target=critical_section, name=f"Thread-{i}")
        threads.append(thread)
        thread.start()

    for thread in threads:
        thread.join()
    ```
*   **데이터베이스 커넥션**: 대부분의 데이터베이스 라이브러리는 컨텍스트 매니저를 지원하여 커넥션 풀 관리나 트랜잭션을 간편하게 처리합니다.
    ```python
    # (가상의 데이터베이스 연결 객체)
    # class DBConnection:
    #     def __enter__(self):
    #         self.conn = connect_to_db()
    #         return self.conn
    #     def __exit__(self, exc_type, exc_val, exc_tb):
    #         self.conn.close()

    # with DBConnection() as db:
    #     cursor = db.cursor()
    #     cursor.execute("SELECT * FROM users")
    #     results = cursor.fetchall()
    #     print(results)
    ```
*   **Decimal 컨텍스트 (`decimal.localcontext`)**: 정밀한 부동소수점 연산이 필요할 때 사용되는 `decimal` 모듈에서 컨텍스트를 일시적으로 변경하는 데 사용됩니다.
    ```python
    from decimal import Decimal, localcontext, getcontext

    print(f"기본 정밀도: {getcontext().prec}") # 기본 정밀도 확인

    with localcontext() as ctx:
        ctx.prec = 10 # 블록 안에서만 정밀도를 10으로 설정
        result = Decimal('1') / Decimal('3')
        print(f"블록 내 정밀도: {ctx.prec}, 결과: {result}")

    print(f"블록 밖 정밀도 (원래대로): {getcontext().prec}") # 원래 정밀도로 돌아옴
    ```
*   **테스트 시 Mock 객체 사용 (`unittest.mock.patch`)**: 테스트 코드에서 특정 함수나 객체를 임시로 대체할 때 유용합니다.

이처럼 `with` 문과 컨텍스트 매니저는 자원 관리가 필요한 거의 모든 곳에서 빛을 발하며, 파이썬 코드를 더욱 안전하고 간결하게 만들어주는 핵심 도구입니다.

## 결론

오늘은 파이썬의 `with` 문과 컨텍스트 매니저에 대해 자세히 알아보았습니다.
*   `with` 문은 자원(파일, DB 연결, 락 등)을 **안전하고 자동으로 관리**해주는 파이썬의 문법입니다.
*   그 뒤에는 `__enter__`와 `__exit__` 메서드를 가진 **컨텍스트 매니저** 객체가 숨어 있습니다.
*   클래스를 만들거나 `@contextmanager` 데코레이터를 사용하여 **나만의 컨텍스트 매니저**를 만들 수 있습니다.

이제 여러분은 `with` 문이 단지 파일을 닫아주는 단순한 구문이 아니라, 파이썬의 자원 관리 철학이 담긴 강력한 도구라는 것을 이해하셨을 겁니다. 앞으로 코드를 작성할 때, "이 자원은 사용 후에 꼭 닫아야 하는데..."라는 생각이 든다면, 주저하지 말고 `with` 문과 컨텍스트 매니저를 활용하여 더 견고하고 우아한 파이썬 코드를 작성해 보세요!
