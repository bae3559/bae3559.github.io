# 파이썬 이터레이터(Iterator)와 이터러블(Iterable), 그 미묘한 차이점 완전 정복!

안녕하세요, 개발 블로그 독자 여러분!

파이썬을 사용하면서 `for` 루프는 정말 많이 사용하시죠? 리스트, 튜플, 문자열 등 다양한 데이터 묶음을 손쉽게 반복하며 원하는 작업을 수행할 수 있도록 해주는 아주 강력한 도구입니다. 하지만 그 이면에 숨겨진 `이터러블(Iterable)`과 `이터레이터(Iterator)`라는 개념에 대해 명확히 이해하고 계신가요?

오늘은 이 두 가지 개념의 차이점을 명확히 알아보고, 실제 코드 예시를 통해 어떻게 동작하는지 함께 살펴보겠습니다. 이 글을 통해 여러분의 파이썬 코드를 더욱 파이썬답게, 그리고 효율적으로 만들 수 있는 통찰력을 얻어가시길 바랍니다!

## 1. 이터러블(Iterable)이란?

먼저 `이터러블(Iterable)`부터 이야기해볼까요?
이름 그대로 '반복(iterate)할 수 있는(able) 것'을 의미합니다. 쉽게 말해, `for` 루프를 사용해서 하나씩 꺼내어 볼 수 있는 모든 것이 이터러블입니다.

우리가 흔히 사용하는 파이썬의 자료구조 대부분이 이터러블에 해당합니다.
*   **리스트(list)**: `[1, 2, 3]`
*   **튜플(tuple)**: `(1, 2, 3)`
*   **문자열(string)**: `"hello"`
*   **딕셔너리(dictionary)**: `{'a': 1, 'b': 2}` (키를 반복)
*   **세트(set)**: `{1, 2, 3}`
*   **range() 객체**: `range(5)`

이러한 객체들은 공통적으로 `__iter__()`라는 특별한 메서드를 가지고 있습니다. 이 `__iter__()` 메서드는 바로 '이터레이터(Iterator)' 객체를 반환하는 역할을 합니다.

개념적으로 **이터러블은 "데이터의 묶음" 또는 "반복 가능한 컨테이너"**라고 생각할 수 있습니다. 마치 서랍 속에 여러 물건이 담겨 있는 것처럼요.

간단한 코드 예시를 볼까요?

```python
# 리스트는 이터러블입니다.
my_list = [10, 20, 30, 40]
for item in my_list:
    print(f"리스트 항목: {item}")

print("-" * 20)

# 문자열도 이터러블입니다.
my_string = "Python"
for char in my_string:
    print(f"문자열 문자: {char}")

print("-" * 20)

# range 객체도 이터러블입니다.
my_range = range(3)
for num in my_range:
    print(f"range 숫자: {num}")

# 이터러블인지 확인하는 한 가지 방법: __iter__ 메서드 존재 여부
print(f"my_list에 __iter__ 메서드가 있나요? {'__iter__' in dir(my_list)}")
```

**실행 결과:**
```
리스트 항목: 10
리스트 항목: 20
리스트 항목: 30
리스트 항목: 40
--------------------
문자열 문자: P
문자열 문자: y
문자열 문자: t
문자열 문자: h
문자열 문자: o
문자열 문자: n
--------------------
range 숫자: 0
range 숫자: 1
range 숫자: 2
my_list에 __iter__ 메서드가 있나요? True
```

## 2. 이터레이터(Iterator)란?

자, 이제 `이터레이터(Iterator)` 차례입니다.
이터러블이 '반복할 수 있는 데이터의 컨테이너'라면, **이터레이터는 이 컨테이너에서 '다음 값을 순서대로 꺼내주는 역할을 하는 객체'**라고 생각할 수 있습니다.

조금 더 쉽게 비유하자면, 이터러블이 책장에 꽂힌 '책들'이라면, 이터레이터는 책을 한 권씩 넘겨가며 읽는 '당신의 손' 또는 '책갈피'와 같습니다. 어디까지 읽었는지(상태)를 기억하고 다음 페이지를 보여주죠.

이터레이터는 다음 두 가지 특별한 메서드를 반드시 가지고 있어야 합니다.
*   `__iter__()`: 자기 자신(self)을 반환합니다. (중요한 점은, 이터레이터도 자기 자신을 반복할 수 있기 때문에 이터러블이기도 합니다!)
*   `__next__()`: 다음 값을 반환합니다. 더 이상 반환할 값이 없으면 `StopIteration` 예외를 발생시킵니다.

우리는 보통 `iter()` 함수를 사용해서 이터러블로부터 이터레이터 객체를 얻을 수 있고, `next()` 함수를 사용해서 이터레이터로부터 다음 값을 얻을 수 있습니다.

코드 예시를 통해 이터레이터의 작동 방식을 이해해봅시다.

```python
my_numbers = [100, 200, 300]

# iter() 함수를 사용하여 이터러블(my_numbers)로부터 이터레이터(my_iterator)를 얻습니다.
my_iterator = iter(my_numbers)

print(f"처음 next(): {next(my_iterator)}") # 100
print(f"두 번째 next(): {next(my_iterator)}") # 200
print(f"세 번째 next(): {next(my_iterator)}") # 300

print("-" * 20)

# 더 이상 값이 없는데 next()를 호출하면 StopIteration 예외가 발생합니다.
try:
    print(f"네 번째 next(): {next(my_iterator)}")
except StopIteration:
    print("더 이상 반환할 값이 없습니다! StopIteration 예외 발생!")

# 이터레이터도 __iter__와 __next__ 메서드를 가지고 있는지 확인
print(f"my_iterator에 __iter__ 메서드가 있나요? {'__iter__' in dir(my_iterator)}")
print(f"my_iterator에 __next__ 메서드가 있나요? {'__next__' in dir(my_iterator)}")
```

**실행 결과:**
```
처음 next(): 100
두 번째 next(): 200
세 번째 next(): 300
--------------------
더 이상 반환할 값이 없습니다! StopIteration 예외 발생!
my_iterator에 __iter__ 메서드가 있나요? True
my_iterator에 __next__ 메서드가 있나요? True
```

## 3. 이터러블과 이터레이터, 그 차이와 관계

이제 이터러블과 이터레이터의 핵심적인 차이점과 관계를 명확히 이해할 시간입니다.

가장 중요한 차이점은 **`상태(State)` 유지 여부**입니다.
*   **이터러블**: `__iter__()` 메서드를 가지고 있으며, 이 메서드를 호출할 때마다 **새로운 이터레이터 객체**를 반환합니다. 이터러블 자체는 반복의 '상태'를 기억하지 않습니다.
*   **이터레이터**: `__iter__()` (자신을 반환)와 `__next__()` 메서드를 모두 가지고 있으며, **자신이 반복 어디까지 진행되었는지 '상태'를 기억**합니다.

쉽게 말해, 이터러블은 '데이터를 제공할 준비가 된 공장' 같고, 이터레이터는 '공장에서 생산된, 다음 데이터를 꺼낼 수 있는 장치' 같습니다. 공장(이터러블)은 여러 대의 장치(이터레이터)를 만들 수 있지만, 각 장치는 독립적으로 동작하며 자신의 상태를 가집니다.

파이썬의 `for` 루프는 내부적으로 다음과 같이 동작합니다.
1.  `for` 루프는 이터러블(`my_list` 등)의 `__iter__()` 메서드를 호출하여 **이터레이터 객체**를 얻습니다.
2.  이후 루프가 돌 때마다 이 이터레이터의 `__next__()` 메서드를 호출하여 다음 값을 가져옵니다.
3.  `__next__()`가 `StopIteration` 예외를 발생시키면, `for` 루프는 반복을 종료합니다.

이러한 관계 때문에, 이터러블은 여러 번 반복해도 항상 처음부터 시작할 수 있습니다. 왜냐하면 `for` 루프가 돌 때마다 `__iter__()`를 통해 새로운 이터레이터 객체를 만들기 때문입니다. 하지만 이미 소진된 이터레이터는 다시 시작할 수 없습니다.

다음 코드 예시를 통해 이 차이를 명확히 확인해봅시다.

```python
my_data = [1, 2, 3] # 이터러블

# 1. for 루프는 매번 새로운 이터레이터를 생성합니다.
print("--- for 루프를 사용한 첫 번째 반복 ---")
for item in my_data:
    print(item) # 1, 2, 3

print("\n--- for 루프를 사용한 두 번째 반복 ---")
for item in my_data: # my_data.__iter__()가 다시 호출되어 새로운 이터레이터 생성
    print(item) # 다시 1, 2, 3

print("-" * 30)

# 2. 이터레이터를 직접 만들어서 사용하면 상태를 기억합니다.
my_iter1 = iter(my_data) # 새로운 이터레이터 생성
my_iter2 = iter(my_data) # 또 다른 새로운 이터레이터 생성 (my_iter1과 독립적)

print(f"my_iter1의 첫 번째 값: {next(my_iter1)}") # 1
print(f"my_iter2의 첫 번째 값: {next(my_iter2)}") # 1 (my_iter1과는 무관하게 다시 시작)

print(f"my_iter1의 두 번째 값: {next(my_iter1)}") # 2 (my_iter1은 다음 값으로 진행)
print(f"my_iter2의 두 번째 값: {next(my_iter2)}") # 2

# my_iter1을 계속 소진
print(f"my_iter1의 세 번째 값: {next(my_iter1)}") # 3

try:
    print(f"my_iter1의 네 번째 값: {next(my_iter1)}")
except StopIteration:
    print("my_iter1은 더 이상 값이 없습니다.")

# my_iter2는 아직 값이 남아있습니다.
print(f"my_iter2의 세 번째 값: {next(my_iter2)}") # 3
```

**실행 결과:**
```
--- for 루프를 사용한 첫 번째 반복 ---
1
2
3

--- for 루프를 사용한 두 번째 반복 ---
1
2
3
------------------------------
my_iter1의 첫 번째 값: 1
my_iter2의 첫 번째 값: 1
my_iter1의 두 번째 값: 2
my_iter2의 두 번째 값: 2
my_iter1의 세 번째 값: 3
my_iter1은 더 이상 값이 없습니다.
my_iter2의 세 번째 값: 3
```

위 예시에서 볼 수 있듯이, `my_data` (이터러블)는 여러 번 반복해도 항상 처음부터 값을 제공하지만, `my_iter1`과 `my_iter2` (이터레이터)는 각자 독립적인 반복 상태를 유지하며 다음 값을 기억합니다.

## 4. 왜 이런 구조가 중요할까요? (실용적인 이점)

이터러블과 이터레이터를 분리하는 이러한 파이썬의 디자인은 여러 가지 강력한 이점을 제공합니다.

1.  **메모리 효율성 (Memory Efficiency)**:
    이터레이터는 모든 데이터를 한 번에 메모리에 로드하지 않고, `next()` 메서드가 호출될 때마다 필요할 때만 다음 값을 생성하거나 읽어옵니다. 이는 대용량 파일 처리, 데이터베이스 쿼리 결과 처리, 또는 무한한 데이터 스트림을 다룰 때 매우 중요합니다. 전체 데이터를 메모리에 올릴 필요가 없으므로 메모리 사용량을 크게 줄일 수 있습니다.

2.  **무한 시퀀스 처리 (Infinite Sequences)**:
    이터레이터는 값을 미리 생성해두는 것이 아니므로, 이론적으로 무한한 길이의 시퀀스도 표현하고 처리할 수 있습니다. 예를 들어, `itertools.count()`는 무한히 숫자를 세는 이터레이터를 반환합니다.

3.  **코드의 재사용성 및 유연성**:
    이터러블을 통해 여러 이터레이터를 생성할 수 있으므로, 동일한 데이터 원본을 가지고 여러 독립적인 반복 작업을 수행할 수 있습니다.

4.  **제너레이터(Generator)의 기반**:
    파이썬의 `yield` 키워드를 사용해 아주 쉽게 이터레이터를 만들 수 있는 특별한 함수가 바로 '제너레이터'입니다. 제너레이터는 이터레이터 개념을 기반으로 하며, 이터레이터를 훨씬 더 간결하게 작성할 수 있게 해줍니다.

5.  **'파이썬다운(Pythonic)' 코드**:
    이 개념들을 이해하고 활용하면 파이썬의 많은 부분이 더 명확해지고, 더 효율적이고 간결한 코드를 작성할 수 있는 통찰력을 얻게 됩니다.

## 결론

자, 이제 파이썬의 이터러블과 이터레이터에 대한 이해가 한층 깊어지셨기를 바랍니다.

**이터러블(Iterable)**은 '반복 가능한 데이터 묶음' (예: 리스트, 문자열), 그리고 **이터레이터(Iterator)**는 '그 데이터 묶음에서 다음 값을 꺼내주는 상태 유지 객체' (예: `iter()`로 얻은 객체)라고 기억하시면 됩니다.

`for` 루프는 내부적으로 이터러블에서 이터레이터를 얻어 `next()`를 반복 호출하는 방식으로 작동하며, 이로 인해 파이썬은 대규모 데이터를 처리하거나 효율적인 반복 작업을 수행할 수 있는 강력한 능력을 가지게 됩니다.

이러한 기본적인 개념들을 잘 활용하여 더욱 견고하고 효율적인 파이썬 코드를 작성하시길 응원합니다! 다음 포스팅에서는 제너레이터에 대해 더 깊이 알아보는 시간을 가져보겠습니다.
