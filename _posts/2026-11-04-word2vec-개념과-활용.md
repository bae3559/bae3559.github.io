# AI 시대의 언어 이해: Word2Vec 개념부터 활용까지

안녕하세요, 개발 블로그 독자 여러분! 🚀 오늘은 자연어 처리(NLP) 분야에서 혁혁한 공을 세운, 아주 중요한 개념인 **Word2Vec**에 대해 이야기해보려 합니다. 마치 컴퓨터가 사람처럼 단어의 의미를 이해하고, 단어들 사이의 관계를 파악하게 돕는 마법 같은 기술이죠.

'Word2Vec'이라는 이름이 조금 어렵게 느껴질 수도 있지만, 걱정 마세요! 초보자도 쉽게 이해할 수 있도록 친절하게 설명하고, 간단한 코드 예제까지 함께 살펴보겠습니다. 자, 그럼 언어의 심오한 세계로 함께 떠나볼까요?

## 1. 컴퓨터는 어떻게 단어를 이해할까요? (Word2Vec의 등장 배경)

우리는 '사과'라는 단어를 들으면 빨갛고 둥근 과일을 떠올리고, '사랑'이라는 단어를 들으면 따뜻하고 포근한 감정을 생각합니다. 하지만 컴퓨터는 그저 문자열(string)로 인식할 뿐이죠.

초기에는 컴퓨터에게 단어를 알려주기 위해 '원-핫 인코딩(One-Hot Encoding)'이라는 방식을 사용했습니다. 예를 들어, 전체 단어가 1000개라면, '사과'는 1000개의 숫자 중 사과에 해당하는 위치만 1이고 나머지는 모두 0인 긴 배열로 표현하는 식입니다.

```
사과: [0, 0, 0, 1, 0, ..., 0]
바나나: [0, 0, 0, 0, 1, ..., 0]
```

이 방식은 각 단어를 고유하게 식별할 수 있지만, 몇 가지 치명적인 단점이 있었습니다.

1.  **의미를 담지 못함:** '사과'와 '바나나'는 둘 다 과일이라는 공통점이 있지만, 원-핫 인코딩에서는 이 둘 사이에 어떤 유사성도 표현하지 못합니다. 모든 단어는 서로 독립적인 관계를 가집니다.
2.  **차원의 저주:** 단어의 개수가 많아질수록 벡터의 길이(차원)가 기하급수적으로 늘어나, 계산 효율이 떨어지고 데이터 희소성(sparsity) 문제가 발생합니다.

이러한 문제들을 해결하기 위해 등장한 것이 바로 **Word2Vec**입니다.

## 2. Word2Vec, 단어에 '의미'를 부여하다

Word2Vec은 2013년 구글에서 발표한 기술로, 단어를 단순히 텍스트가 아닌, **의미를 내포한 '벡터(vector)'**로 변환하는 방법을 제시합니다. 여기서 벡터는 여러 개의 숫자가 나열된 배열을 의미합니다.

핵심 아이디어는 다음과 같습니다.

> **"비슷한 문맥에서 사용되는 단어들은 비슷한 의미를 가질 것이다." (Distributional Hypothesis)**

즉, "나는 맛있는 **사과**를 먹었다"와 "나는 맛있는 **바나나**를 먹었다"라는 문장에서 '사과'와 '바나나'는 '맛있는' 것을 '먹는'다는 비슷한 문맥에 등장합니다. Word2Vec은 이러한 문맥 정보를 학습하여, '사과'와 '바나나'의 벡터를 벡터 공간에서 서로 가깝게 위치하도록 만듭니다.

### 2.1. 어떻게 작동할까요? (아주 쉽게!)

Word2Vec에는 크게 두 가지 학습 모델이 있습니다.

1.  **CBOW (Continuous Bag of Words):** 주변 단어들을 보고 중간의 단어를 예측합니다.
    *   예: "나는 [?] 맛있는 [?] 먹었다" -> "나는 **사과** 맛있는 **를** 먹었다" 에서 물음표에 들어갈 단어를 예측.
2.  **Skip-gram:** 중간 단어를 보고 주변 단어들을 예측합니다. (가장 널리 사용)
    *   예: "[?] 맛있는 [?] 먹었다" -> **사과**라는 단어를 보고 주변에 '나는', '맛있는', '를', '먹었다' 같은 단어들이 올 것이라고 예측.

이 모델들은 아주 간단한 인공신경망(Neural Network)을 사용하여, 대량의 텍스트 데이터를 학습하면서 각 단어에 대한 최적의 벡터(임베딩)를 찾아냅니다. 중요한 것은 이 신경망 자체가 어떤 작업을 수행하기 위함이 아니라, **단어 임베딩을 학습하기 위한 도구**로 사용된다는 점입니다.

### 2.2. Word2Vec의 놀라운 능력: 벡터 연산

단어가 의미 있는 벡터로 변환되면, 우리는 이 벡터들을 가지고 수학적인 연산을 할 수 있습니다. 가장 유명한 예시는 다음과 같습니다.

`vec(왕) - vec(남자) + vec(여자) ≈ vec(여왕)`

즉, '왕'이라는 단어 벡터에서 '남자'의 특징을 빼고, '여자'의 특징을 더하면 '여왕'과 가장 유사한 벡터를 얻을 수 있다는 것입니다. 이는 Word2Vec이 단순히 단어를 숫자로 바꾼 것을 넘어, 단어들 간의 복잡한 의미론적 관계까지 포착해낸다는 것을 보여줍니다.

## 3. Word2Vec 활용: Python Gensim으로 직접 경험하기

이제 이론을 바탕으로 실제 코드를 통해 Word2Vec을 사용해보는 시간을 갖겠습니다. Python의 `gensim` 라이브러리는 Word2Vec을 아주 쉽게 구현할 수 있도록 도와줍니다.

먼저, `gensim` 라이브러리가 설치되어 있지 않다면 아래 명령어로 설치해주세요.

```bash
pip install gensim
```

그리고 아래 파이썬 코드를 실행해봅시다.

```python
from gensim.models import Word2Vec
from konlpy.tag import Okt # 한국어 형태소 분석을 위해 사용, 설치 필요: pip install konlpy

# 1. 텍스트 데이터 준비 (간단한 예시)
# 실제 사용 시에는 대량의 문서(뉴스 기사, 소설 등)를 사용합니다.
corpus = [
    "나는 사과를 좋아한다.",
    "사과는 맛있고 건강에 좋다.",
    "바나나도 과일이지만 사과와는 다르다.",
    "나는 컴퓨터 프로그래밍을 배우고 있다.",
    "인공지능과 머신러닝은 재미있다.",
    "개발자는 코딩을 잘해야 한다.",
    "사과와 바나나는 모두 과일이다."
]

# 2. 텍스트 전처리: 토큰화 (단어 단위로 분리)
# 한국어는 띄어쓰기만으로는 단어 구분이 어려워 형태소 분석기를 사용합니다.
okt = Okt()
tokenized_data = []
for sentence in corpus:
    # 형태소 분석 후 명사, 동사, 형용사 등 필요한 품사만 추출하거나 모두 사용
    # 여기서는 모든 형태소를 사용하겠습니다.
    tokens = okt.morphs(sentence)
    tokenized_data.append(tokens)

print("--- 토큰화된 데이터 ---")
for tokens in tokenized_data:
    print(tokens)
print("\n")

# 3. Word2Vec 모델 학습
# vector_size: 단어 벡터의 차원 (단어를 표현할 숫자의 개수)
# window: 주변 단어를 몇 개까지 볼 것인지
# min_count: 최소한 이 횟수 이상 등장하는 단어만 학습에 사용
# workers: 학습에 사용할 CPU 코어 수
# sg: 0이면 CBOW, 1이면 Skip-gram (Skip-gram이 더 좋은 성능을 보이는 경우가 많음)
model = Word2Vec(sentences=tokenized_data, vector_size=100, window=5, min_count=1, workers=4, sg=1)

# 4. 학습된 모델 활용

print("--- '사과'와 가장 유사한 단어들 ---")
# most_similar() 함수로 특정 단어와 유사한 단어들을 찾을 수 있습니다.
# topn은 보여줄 개수
similar_words = model.wv.most_similar('사과', topn=5)
for word, score in similar_words:
    print(f"{word}: {score:.4f}")
print("\n")

print("--- '컴퓨터'의 단어 벡터 ---")
# 특정 단어의 벡터를 직접 확인할 수도 있습니다.
print(model.wv['컴퓨터'])
print("\n")

print("--- '남자'와 '여자'의 유사도 (데이터에 남자, 여자 단어가 없어 예시로 대체) ---")
# 두 단어 간의 유사도 (코사인 유사도)를 계산합니다.
# 현재 데이터셋에는 '남자', '여자' 단어가 없으므로,
# '사과'와 '바나나', '컴퓨터'와 '인공지능'의 유사도를 측정해봅시다.
similarity_apple_banana = model.wv.similarity('사과', '바나나')
print(f"'사과'와 '바나나'의 유사도: {similarity_apple_banana:.4f}")

similarity_computer_ai = model.wv.similarity('컴퓨터', '인공지능')
print(f"'컴퓨터'와 '인공지능'의 유사도: {similarity_computer_ai:.4f}")
print("\n")


# 5. 벡터 연산을 통한 단어 관계 추론 (데이터셋이 작아 정확도가 떨어질 수 있음)
# '왕 - 남자 + 여자 = 여왕'과 같은 연산을 시도해봅니다.
# 우리 데이터셋에 맞는 예시로 '사과 - 맛있 + 건강'을 해볼까요?
# '맛있'는 형용사이지만, 여기서는 단순한 단어 벡터 연산의 예시입니다.
# 데이터셋이 작고 단순하여 완벽한 결과를 기대하기는 어렵습니다.
try:
    result = model.wv.most_similar(positive=['사과', '건강'], negative=['맛있'], topn=1)
    print("--- '사과' + '건강' - '맛있' = ? ---")
    for word, score in result:
        print(f"가장 유사한 단어: {word} (유사도: {score:.4f})")
except KeyError as e:
    print(f"단어 '{e}'가 모델에 없습니다. 다른 단어로 시도해보세요.")

```

### 코드 설명:

1.  **데이터 준비 및 전처리:**
    *   간단한 문장들로 `corpus`를 만들었습니다. 실제로는 훨씬 방대한 텍스트 데이터를 사용합니다.
    *   `konlpy` 라이브러리의 `Okt` (Open Korean Text) 형태소 분석기를 사용하여 문장을 단어(정확히는 형태소) 단위로 분리(토큰화)합니다. 한국어는 띄어쓰기만으로 단어를 완벽히 구분하기 어렵기 때문에 이러한 과정이 필수적입니다.
2.  **Word2Vec 모델 학습:**
    *   `Word2Vec()` 객체를 생성하면서 `sentences`에는 토큰화된 문장 리스트를 전달합니다.
    *   `vector_size=100`: 각 단어를 100차원의 벡터로 표현하겠다는 의미입니다.
    *   `window=5`: 현재 단어의 앞뒤로 5개 단어까지를 문맥으로 고려하겠다는 의미입니다.
    *   `min_count=1`: 최소 1번 이상 등장한 단어만 모델 학습에 포함시킵니다.
    *   `sg=1`: Skip-gram 모델을 사용하겠다는 설정입니다.
3.  **학습된 모델 활용:**
    *   `model.wv.most_similar('사과', topn=5)`: '사과'와 의미적으로 가장 유사한 단어 5개를 찾아줍니다.
    *   `model.wv['컴퓨터']`: '컴퓨터' 단어의 실제 벡터 값을 출력합니다.
    *   `model.wv.similarity('사과', '바나나')`: 두 단어 벡터 간의 코사인 유사도를 계산하여 얼마나 비슷한지 숫자로 보여줍니다. 1에 가까울수록 유사합니다.
    *   `model.wv.most_similar(positive=['사과', '건강'], negative=['맛있'], topn=1)`: 벡터 연산 예시입니다. '사과'와 '건강'의 특징을 더하고 '맛있'의 특징을 뺐을 때 어떤 단어와 가장 유사한지 찾아봅니다. (작은 데이터셋에서는 의미 있는 결과가 나오지 않을 수 있습니다.)

## 4. Word2Vec의 다양한 활용 분야

Word2Vec이 학습한 단어 임베딩은 다양한 NLP 태스크에서 강력한 기반이 됩니다.

*   **추천 시스템:** 사용자가 과거에 선호했던 아이템(단어)과 유사한 다른 아이템을 추천합니다.
*   **감성 분석:** 텍스트가 긍정적인지 부정적인지 판단할 때, 단어의 감성적 의미를 파악하는 데 활용됩니다.
*   **기계 번역:** 원어 텍스트의 단어 벡터를 통해 번역될 언어의 단어 벡터를 예측하는 데 도움을 줍니다.
*   **챗봇 및 질의응답 시스템:** 사용자 질문의 의도를 파악하고, 가장 적절한 답변을 찾아내는 데 단어 임베딩이 사용됩니다.
*   **텍스트 분류:** 스팸 메일 분류, 뉴스 기사 카테고리 분류 등 텍스트를 특정 범주로 나누는 작업에 활용됩니다.

## 5. 마무리하며

오늘 우리는 Word2Vec이 어떻게 컴퓨터가 단어의 의미를 이해하도록 돕는지, 그리고 그 원리와 활용법을 살펴보았습니다. 단순히 단어를 숫자로 바꾸는 것을 넘어, 단어들 간의 복잡한 의미 관계까지 포착해내는 Word2Vec은 현대 자연어 처리 분야의 초석이라고 할 수 있습니다.

물론 Word2Vec 이후에도 FastText, GloVe, BERT, GPT 등 더 발전된 임베딩 모델들이 많이 등장했지만, Word2Vec은 여전히 그 기본 개념을 이해하는 데 매우 중요하며, 경량 모델이 필요한 경우에도 유용하게 사용될 수 있습니다.

이 글을 통해 Word2Vec의 개념을 명확히 이해하고, 여러분의 프로젝트에 활용할 수 있는 아이디어를 얻으셨기를 바랍니다. 직접 다양한 데이터로 실험해보면서 Word2Vec의 매력에 푹 빠져보세요!
