# Vim 초보자를 위한 필독서: 핵심 기능 완전 정복

안녕하세요, 개발 블로그 독자 여러분!

개발자에게 있어 생산성은 항상 중요한 화두입니다. 수많은 개발 도구 중에서도 'Vim'이라는 이름은 특히 개발자들 사이에서 전설처럼 회자되곤 합니다. 처음 접하는 사람들에게는 다소 난해하고 불편해 보일 수 있지만, 일단 익숙해지면 마우스 없이 키보드만으로 코드와 텍스트를 자유자재로 편집하는 강력한 생산성을 선사하는 도구죠.

"Vim은 배우기 어렵다"는 선입견 때문에 시작조차 망설이는 분들이 많을 텐데요. 걱정하지 마세요! 오늘 이 글에서는 Vim의 핵심 개념과 가장 기본적인 사용법들을 초보자 눈높이에 맞춰 쉽고 친절하게 설명해 드릴 겁니다. 이 글을 통해 Vim에 대한 두려움을 없애고, 여러분의 개발 워크플로우를 한 단계 업그레이드할 수 있는 첫걸음을 떼시길 바랍니다.

## Vim의 핵심: '모드(Mode)' 이해하기

Vim이 다른 텍스트 에디터와 가장 크게 다른 점은 바로 '모드(Mode)' 개념입니다. 일반적인 에디터에서는 항상 텍스트를 입력할 수 있지만, Vim에서는 현재 어떤 '모드'에 있느냐에 따라 키 입력의 동작이 달라집니다. 이 모드를 이해하는 것이 Vim 숙달의 첫 번째 관문입니다.

주요 모드는 다음과 같습니다.

1.  **일반 모드 (Normal Mode / 명령 모드):**
    *   Vim을 실행하면 가장 먼저 진입하는 기본 모드입니다.
    *   텍스트를 입력하는 모드가 아니라, 파일 내에서 이동하거나, 텍스트를 삭제/복사/붙여넣기 하거나, 다른 모드로 전환하는 등의 '명령'을 수행하는 모드입니다.
    *   거의 모든 Vim 작업의 시작점이자 종착점입니다.

2.  **입력 모드 (Insert Mode):**
    *   이름 그대로 텍스트를 '입력'할 수 있는 모드입니다. 일반적인 텍스트 에디터와 동일하게 작동합니다.
    *   **일반 모드에서 `i`, `a`, `o` 등의 키를 눌러 진입합니다.**
    *   **입력 모드에서 `Esc` 키를 누르면 다시 일반 모드로 돌아옵니다.**

3.  **비주얼 모드 (Visual Mode):**
    *   텍스트를 시각적으로 '선택'하는 모드입니다. 마우스로 드래그하는 것과 유사한 역할을 합니다.
    *   선택된 영역에 대해 특정 명령(삭제, 복사 등)을 실행할 수 있습니다.
    *   **일반 모드에서 `v` (문자 단위), `V` (라인 단위) 키를 눌러 진입합니다.**
    *   **`Esc` 키를 누르면 일반 모드로 돌아옵니다.**

4.  **명령행 모드 (Command-Line Mode / Ex Mode):**
    *   파일 저장, 종료, 검색, 바꾸기 등 고급 명령을 수행할 때 사용합니다.
    *   **일반 모드에서 `:` (콜론) 키를 누르면 화면 하단에 `:` 프롬프트가 나타나며 진입합니다.**
    *   명령을 입력하고 `Enter` 키를 누르면 명령이 실행되고, 다시 일반 모드로 돌아옵니다.

**💡 핵심:** Vim은 대부분의 작업을 **일반 모드**에서 수행하며, 텍스트를 입력할 때만 **입력 모드**로 전환한다는 것을 기억하세요! 그리고 언제든 `Esc` 키를 누르면 일반 모드로 돌아갈 수 있습니다.

## 2. 기본적인 이동 (일반 모드)

Vim에서는 마우스가 필요 없습니다. 다음 키들을 이용해 문서 내를 자유롭게 이동할 수 있습니다.

*   `h`: 왼쪽으로 이동 (←)
*   `j`: 아래로 이동 (↓)
*   `k`: 위로 이동 (↑)
*   `l`: 오른쪽으로 이동 (→)
    *   *(팁: 이 네 개의 키는 오른손 검지, 중지, 약지에 해당하며, 손가락을 홈 포지션에 두고도 쉽게 누를 수 있도록 설계되었습니다.)*
*   `w`: 다음 단어의 시작 부분으로 이동 (word)
*   `b`: 이전 단어의 시작 부분으로 이동 (back)
*   `e`: 현재/다음 단어의 끝 부분으로 이동 (end)
*   `0`: 현재 라인의 가장 처음으로 이동 (공백 포함)
*   `^`: 현재 라인의 가장 처음 글자로 이동 (공백 제외)
*   `$`: 현재 라인의 가장 끝으로 이동
*   `gg`: 파일의 맨 위로 이동
*   `G`: 파일의 맨 아래로 이동
*   `Control + f` (또는 `Ctrl + f`): 한 화면 아래로 이동 (forward)
*   `Control + b` (또는 `Ctrl + b`): 한 화면 위로 이동 (backward)

## 3. 텍스트 편집하기 (일반 모드 & 입력 모드)

이제 텍스트를 입력하고 수정하는 방법을 알아봅시다.

### 3.1. 입력 모드 진입하기

일반 모드에서 다음 키들을 눌러 입력 모드로 진입할 수 있습니다.

*   `i`: 현재 커서 위치에 삽입 (insert)
*   `a`: 현재 커서 다음 위치에 삽입 (append)
*   `o`: 현재 라인 아래에 새로운 라인을 추가하고 삽입 (open new line below)
*   `O`: 현재 라인 위에 새로운 라인을 추가하고 삽입 (open new line above)

입력을 마쳤다면 반드시 `Esc` 키를 눌러 일반 모드로 돌아와야 합니다.

### 3.2. 텍스트 삭제하기 (Delete)

일반 모드에서 다음 키들을 사용해 텍스트를 삭제할 수 있습니다.

*   `x`: 현재 커서에 있는 한 글자 삭제
*   `dw`: 현재 커서부터 다음 단어 끝까지 삭제 (delete word)
*   `dd`: 현재 라인 전체 삭제 (delete line)
*   `D`: 현재 커서부터 라인 끝까지 삭제

```python
# 이 코드를 수정해 봅시다. (일반 모드)

def calculate_sum(val1, val2): # 'val1'에서 'dw'를 누르면 'val1'이 삭제됩니다.
    result = val1 + val2       # 이 라인에서 'dd'를 누르면 라인 전체가 삭제됩니다.
    print("Sum:", result)      # 'result'에서 'D'를 누르면 'result)'부터 라인 끝까지 삭제됩니다.
```

### 3.3. 복사 및 붙여넣기 (Yank & Put)

Vim에서는 '복사'를 'yank'라고 부릅니다.

*   `yy`: 현재 라인 전체 복사 (yank line)
*   `yw`: 현재 커서부터 다음 단어 끝까지 복사
*   `p`: 현재 커서 다음에 붙여넣기 (put)
*   `P`: 현재 커서 이전에 붙여넣기 (Put)

```python
# 다음 라인을 복사해 봅시다. (일반 모드)

def greet_user(name): # 이 라인에서 'yy'를 누르면 라인 전체가 복사됩니다.
    print(f"Hello, {name}!")

# 빈 라인에서 'p'를 누르면 복사된 라인이 여기에 붙여넣어집니다.
# def greet_user(name):
#     print(f"Hello, {name}!")
```

### 3.4. 되돌리기 / 다시 실행 (Undo / Redo)

실수했을 때 유용한 기능입니다.

*   `u`: 이전 작업 되돌리기 (undo)
*   `Ctrl + r`: 되돌린 작업 다시 실행 (redo)

## 4. 파일 저장 및 종료 (명령행 모드)

작업을 마쳤다면 파일을 저장하고 Vim을 종료해야겠죠?

*   `:w`: 현재 파일 저장 (write)
*   `:q`: Vim 종료 (quit)
*   `:wq` 또는 `:x`: 저장 후 종료 (write and quit)
*   `:q!`: 저장하지 않고 강제 종료 (quit and force)
    *   *(팁: 변경사항을 저장하고 싶지 않을 때 유용합니다. 주의해서 사용하세요!)*

## 5. 텍스트 검색 (명령행 모드)

특정 문자열을 찾고 싶을 때 사용합니다.

*   `/검색어`: 현재 커서 위치부터 아래 방향으로 '검색어' 찾기
*   `?검색어`: 현재 커서 위치부터 위 방향으로 '검색어' 찾기
*   `n`: 다음 검색 결과로 이동 (next)
*   `N`: 이전 검색 결과로 이동 (previous)

## 6. 고급 활용 예시: 바꿔치기 (Search and Replace)

명령행 모드에서 `:s` 명령을 사용하면 강력한 검색 및 바꾸기 기능을 활용할 수 있습니다.

*   `:%s/찾을_문자열/바꿀_문자열/g`: 파일 전체에서 '찾을\_문자열'을 '바꿀\_문자열'로 모두 바꾸기 (`%`는 파일 전체, `g`는 한 라인의 모든 일치 항목을 의미)
*   `:%s/old_name/new_name/gc`: 바꾸기 전에 사용자에게 확인 요청 (`c`는 confirm)

```python
# 다음과 같은 코드가 있을 때
class OldNameClass:
    def __init__(self):
        self.old_name_var = 10

# ': %s/OldName/NewName/g' 명령을 실행하면
# 모든 'OldName'이 'NewName'으로 바뀝니다.

class NewNameClass:
    def __init__(self):
        self.new_name_var = 10
```
